# 114. Глубокое копирование (deep copy)

## Определение

**Глубокое копирование** — это способ копирования объекта, при котором создаётся полностью независимая копия, включая все динамически выделенные ресурсы (память, файлы, дескрипторы и т.п.), на которые объект ссылается через указатели или другие владеющие ресурсы. После глубокого копирования оригинал и копия не разделяют никаких общих данных: изменение одного объекта не влияет на другой.

## Сравнение с поверхностным копированием

**Поверхностное копирование (shallow copy)** копирует только значения полей объекта. Если поле — указатель, то копируется сам адрес, и оба объекта начинают указывать на один и тот же блок памяти. Это приводит к проблемам:

- изменение данных через один объект видно через другой;
- **двойное освобождение** памяти (double free) при разрушении обоих объектов;
- **висячие указатели** (dangling pointers), если один объект освободил память.

**Глубокое копирование** решает эти проблемы: для каждого объекта выделяется собственный блок памяти, и в него копируется содержимое.

## Пример на C++

```cpp
#include <cstring>
#include <iostream>

class String {
private:
    char* data;
    size_t size;

public:
    // Конструктор
    String(const char* str) {
        size = std::strlen(str);
        data = new char[size + 1];
        std::strcpy(data, str);
    }

    // Конструктор копирования — ГЛУБОКОЕ копирование
    String(const String& other) {
        size = other.size;
        data = new char[size + 1];      // выделяем новую память
        std::strcpy(data, other.data);  // копируем содержимое
    }

    // Оператор присваивания — ГЛУБОКОЕ копирование
    String& operator=(const String& other) {
        if (this != &other) {           // защита от самоприсваивания
            char* newData = new char[other.size + 1];
            std::strcpy(newData, other.data);
            delete[] data;              // освобождаем старый буфер
            data = newData;
            size = other.size;
        }
        return *this;
    }

    // Деструктор
    ~String() {
        delete[] data;
    }

    const char* c_str() const { return data; }
};

int main() {
    String a("Hello");
    String b = a;        // вызывается конструктор копирования (глубокое копирование)
    String c;
    c = a;               // вызывается оператор присваивания (глубокое копирование)

    std::cout << a.c_str() << " " << b.c_str() << " " << c.c_str() << "\n";
    // a, b, c — три независимых буфера в памяти
}
```

Если бы конструктор копирования был поверхностным (например, `data = other.data`), то при выходе из `main` деструкторы трижды вызвали бы `delete[]` для одного и того же указателя — неопределённое поведение и, скорее всего, аварийное завершение программы.

## Когда требуется глубокое копирование

Глубокое копирование необходимо, когда класс **владеет** ресурсом:

- сырые указатели на динамическую память (`new`/`delete`);
- массивы, выделенные в куче;
- файловые дескрипторы, сокеты, мьютексы;
- `std::unique_ptr` (он некопируемый — требует перемещения);
- другие ресурсы, время жизни которых контролирует объект.

## Правило трёх / пяти / нуля

Если классу нужен собственный деструктор, конструктор копирования или оператор копирующего присваивания — скорее всего, нужны все три (**правило трёх**). В современном C++ (C++11 и позже) к ним добавляются конструктор перемещения и оператор перемещающего присваивания (**правило пяти**). Если же класс не управляет ресурсами напрямую, лучше вообще не писать эти функции, доверив всё стандартным контейнерам и умным указателям (**правило нуля**).

## Современная альтернатива ручному глубокому копированию

В современном C++ вместо сырых указателей используют **RAII-обёртки**, которые реализуют глубокое копирование автоматически:

```cpp
#include <string>
#include <vector>

class Person {
    std::string name;          // string сам делает глубокую копию
    std::vector<int> scores;   // vector сам делает глубокую копию
public:
    Person(std::string n, std::vector<int> s)
        : name(std::move(n)), scores(std::move(s)) {}
    // конструктор копирования, оператор присваивания и деструктор
    // генерируются компилятором и корректно копируют данные
};
```

Здесь `Person` можно копировать без написания собственных функций: `std::string` и `std::vector` уже владеют своей памятью и при копировании выполняют глубокое копирование.

## Итог

| Свойство | Поверхностное копирование | Глубокое копирование |
|---|---|---|
| Что копируется | Значения полей (адреса указателей) | Сами данные + новые блоки памяти |
| Общие данные | Да | Нет |
| Риск double free | Есть | Нет |
| Стоимость | Низкая | Выше (выделение памяти и копирование данных) |
| Когда применять | Объекты без владения ресурсами | Объекты, владеющие динамическими ресурсами |

Глубокое копирование — ключевой приём для корректной работы классов, владеющих ресурсами, и предотвращения ошибок управления памятью в C++.
