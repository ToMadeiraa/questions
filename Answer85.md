# 85. Циклы `for` и range-for в C++

## 1. Классический цикл `for`

### Синтаксис

```cpp
for (инициализация; условие; выражение_итерации)
{
    // тело цикла
}
```

Три части разделяются точкой с запятой:

1. **Инициализация** — выполняется один раз перед первой итерацией (можно объявлять переменную-счётчик; её область видимости ограничена циклом).
2. **Условие** — проверяется перед каждой итерацией; если истинно (`true`), тело выполняется, иначе цикл завершается. Пустое условие эквивалентно `true`.
3. **Выражение итерации** — выполняется после каждой итерации (например, `++i`).

Любую из трёх частей (и даже все сразу) можно опустить:

```cpp
int i = 0;
for (; i < 10; ++i) { /* ... */ }

for (int j = 0; ; ++j) { if (j >= 10) break; }  // «вечный» цикл с break

for (;;) { /* бесконечный цикл */ }
```

### Порядок выполнения

```
инициализация → [условие?] → тело → выражение_итерации → [условие?] → ...
```

### Примеры

```cpp
// Сумма чисел от 1 до 100
int sum = 0;
for (int i = 1; i <= 100; ++i)
    sum += i;

// Обход массива по индексу
int arr[5] = {10, 20, 30, 40, 50};
for (std::size_t i = 0; i < 5; ++i)
    std::cout << arr[i] << ' ';

// Несколько переменных в заголовке
for (int i = 0, j = 10; i < j; ++i, --j)
    std::cout << i << ' ' << j << '\n';
```

### Особенности и подводные камни

- Переменная, объявленная в инициализации (`for (int i = ...`), видна только внутри цикла.
- Изменение счётчика внутри тела — плохая практика, но допустимо (иногда приводит к ошибкам типа off-by-one).
- `break` — досрочно завершает цикл; `continue` — переходит к следующей итерации (перед этим выполняется выражение итерации).
- В C++11 и новее можно использовать `auto` и диапазонные типы, а также объявлять несколько переменных одного типа.

```cpp
for (auto i = 0; i < 10; ++i) { /* ... */ }
```

## 2. Range-for (цикл по диапазону, C++11)

### Синтаксис

```cpp
for (объявление : выражение-диапазон)
{
    // тело цикла
}
```

- **выражение-диапазон** — то, что можно обойти: массив, контейнер STL (`std::vector`, `std::list`, `std::map`...), `std::string`, `std::initializer_list`, объект с методами `begin()`/`end()` и т. д.
- **объявление** — переменная, в которую поочерёдно копируется/привязывается каждый элемент диапазона.

### Как работает

Стандарт определяет range-for примерно как эквивалент:

```cpp
{
    auto&& __range = выражение-диапазон;
    auto __begin = begin(__range);
    auto __end   = end(__range);
    for (; __begin != __end; ++__begin)
    {
        объявление = *__begin;
        // тело цикла
    }
}
```

То есть компилятор сам вызывает `begin()`/`end()` и разыменовывает итератор. Для C-массивов `begin`/`end` берутся из `std::begin`/`std::end` (или встроенной логики).

### Способы объявления переменной

| Форма | Что происходит |
|-------|----------------|
| `for (int x : v)` | **Копия** каждого элемента (для дорогих типов — лишнее копирование) |
| `for (const auto& x : v)` | **Константная ссылка** — без копирования, элемент только для чтения (рекомендуется по умолчанию) |
| `for (auto& x : v)` | **Ссылка** — можно изменять элементы контейнера |
| `for (auto&& x : v)` | Универсальная ссылка (переадресация); удобно, когда не знаешь категорию значений |

### Примеры

```cpp
#include <vector>
#include <string>
#include <iostream>

std::vector<int> v = {1, 2, 3, 4, 5};

// Только чтение
for (const auto& x : v)
    std::cout << x << ' ';

// Изменение элементов
for (auto& x : v)
    x *= 2;                     // удвоили каждый элемент

// Обход std::string
std::string s = "hello";
for (char c : s)
    std::cout << c;

// Обход std::map (элементы — std::pair<const Key, Value>)
std::map<std::string, int> m = {{"a", 1}, {"b", 2}};
for (const auto& [key, value] : m)   // structured bindings, C++17
    std::cout << key << " = " << value << '\n';

// Обход C-массива
int arr[] = {10, 20, 30};
for (int x : arr)
    std::cout << x << ' ';

// initializer_list
for (int x : {1, 2, 3})
    std::cout << x << ' ';
```

### Ограничения и подводные камни

1. **Нельзя легко удалять/вставлять элементы** в контейнер во время обхода — итераторы/ссылки могут инвалидироваться (как и в обычном цикле с итераторами).
2. **Нет доступа к индексу** — если нужен номер элемента, используйте классический `for` или счётчик.
3. **Нельзя обойти «половину» диапазона** или идти в обратном порядке без адаптеров (например, `std::views::reverse` в C++20).
4. **Копирование по значению** — частая ошибка производительности: `for (auto x : bigVector)` копирует каждый элемент. Лучше `const auto&`.
5. **Изменение размера контейнера** внутри цикла — UB (неопределённое поведение) для большинства контейнеров.
6. **Диапазон вычисляется один раз** — выражение после двоеточия вычисляется ровно один раз (важно, если это функция).
7. В C++20 range-for расширен: работает с временными диапазонами и view-адаптерами (`std::ranges`).

```cpp
// C++20: обход через ranges
#include <ranges>
for (int x : v | std::views::filter([](int n){ return n % 2 == 0; })
               | std::views::transform([](int n){ return n * n; }))
    std::cout << x << ' ';
```

## 3. Сравнение

| Критерий | `for` | range-for |
|----------|-------|-----------|
| Доступ к индексу | ✅ да | ❌ нет |
| Изменение элементов | ✅ через индекс/итератор | ✅ через `auto&` |
| Обход контейнеров | ✅ (нужен итератор/индекс) | ✅ проще и безопаснее |
| Обратный проход | ✅ легко (`--i`) | ❌ нужны адаптеры (`views::reverse`) |
| Частичный проход / сложный шаг | ✅ гибко | ❌ ограниченно |
| Читаемость для «обойти всё» | средняя | высокая |
| Риск выхода за границы | есть (ручной индекс) | минимален |

**Рекомендация:** если нужно просто пройти по всем элементам диапазона — используйте range-for (с `const auto&` для чтения и `auto&` для изменения). Если нужен индекс, нестандартный шаг, обратный порядок или модификация структуры — классический `for` (или итераторы).

## 4. Короткий пример «всё вместе»

```cpp
#include <iostream>
#include <vector>

int main()
{
    std::vector<int> v = {1, 2, 3, 4, 5};

    // Классический for: нужен индекс
    for (std::size_t i = 0; i < v.size(); ++i)
        std::cout << "v[" << i << "] = " << v[i] << '\n';

    // range-for: изменение элементов
    for (auto& x : v)
        x += 10;

    // range-for: только чтение
    for (const auto& x : v)
        std::cout << x << ' ';
    std::cout << '\n';
}
```

## Итог

- **`for`** — универсальный цикл с явным управлением счётчиком/итератором; гибкий, но требует аккуратности с границами.
- **range-for** (C++11) — синтаксический сахар для обхода диапазона целиком; безопаснее и читаемее, но менее гибок (нет индекса, сложнее с частичным/обратным обходом).
- Ключевые правила range-for: по умолчанию `const auto&`, для изменения — `auto&`, избегайте копирования по значению и модификации контейнера во время обхода.
