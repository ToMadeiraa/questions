## 161. UID (Unique Identifier)

**UID** (Unique Identifier) — это уникальный идентификатор, который присваивается объекту, сущности или записи для их однозначного различения в рамках определённой системы. В программировании на C++ UID не является встроенным типом языка или частью стандартной библиотеки; это концепция, которая реализуется программистом или берётся из сторонних библиотек в зависимости от задачи.

### Основное назначение

UID позволяет ссылаться на объект и взаимодействовать с ним, не полагаясь на его адрес в памяти или другие изменчивые характеристики. Это особенно важно, когда объекты сериализуются, передаются между компонентами системы или сохраняются на диск .

Ключевое свойство UID — **уникальность в заданном контексте**. В одном случае достаточно уникальности в пределах одного запуска программы (например, счётчик), в другом — глобальной уникальности (например, GUID/UUID) .

### Способы реализации UID в C++

В зависимости от требований к уникальности и области применения, можно выделить несколько подходов.

**1. Указатели как естественные UID**

В пределах одного адресного пространства и времени жизни программы адрес объекта (указатель) сам по себе является уникальным идентификатором. Однако этот подход имеет существенные ограничения: при копировании объектов, перераспределении памяти в контейнерах или возврате из функции адреса могут совпадать или изменяться, что нарушает идентичность .

**2. Статический счётчик**

Простейший способ генерации уникальных числовых идентификаторов — использование статической переменной-счётчика внутри класса. При создании каждого объекта счётчик инкрементируется, и текущее значение сохраняется как UID.

Важные моменты при такой реализации:
- Инкремент должен быть **атомарным**, если объекты могут создаваться из разных потоков.
- Необходимо **запретить копирование и присваивание** (или определить их корректно), чтобы два объекта не получили одинаковый UID .

Этот подход даёт уникальность в пределах одного запуска программы. После перезапуска или при переполнении счётчика значения могут повторяться.

**3. Глобально уникальные идентификаторы (GUID/UUID)**

Если требуется уникальность за пределами одного процесса — например, для данных, сохраняемых на диск или передаваемых по сети, — используются GUID (Globally Unique Identifier) или UUID (Universally Unique Identifier). В C++ их можно генерировать с помощью библиотеки **Boost.UUID** или платформенно-зависимых API .

GUID/UUID обычно представляют собой 128-битные значения, вероятность совпадения которых пренебрежимо мала.

### UID и сериализация

Одна из главных практических причин введения UID — **сериализация объектов**. При сохранении объекта на диск или передачи по сети указатели теряют смысл, поскольку адреса в памяти нового процесса будут другими. UID позволяет сохранить ссылку на объект в форме, независимой от адреса, а при десериализации — восстановить связь между объектами через таблицу соответствия `UID -> новый адрес` .

В этом контексте UID часто ассоциируется с объектом, а не является частью его значения: два объекта могут иметь одинаковое содержимое, но разные UID, и наоборот, один объект сохраняет свой UID на протяжении всего времени жизни, даже если его поля изменяются .

### Пример реализации со статическим счётчиком

```cpp
#include <iostream>

class Identifiable {
private:
    static int nextId;
    int uid;

public:
    Identifiable() : uid(nextId++) {}
    
    // Запрет копирования, чтобы два объекта не имели одинаковый UID
    Identifiable(const Identifiable&) = delete;
    Identifiable& operator=(const Identifiable&) = delete;
    
    int getUid() const { return uid; }
};

int Identifiable::nextId = 0;

int main() {
    Identifiable a;
    Identifiable b;
    std::cout << a.getUid() << " " << b.getUid() << std::endl; // 0 1
    return 0;
}
```

### Резюме

| Аспект | Описание |
|---|---|
| **Что это** | Уникальный идентификатор объекта в заданной области видимости |
| **Встроен ли в C++** | Нет, реализуется программистом или берётся из библиотек |
| **Типичные реализации** | Указатель, статический счётчик, GUID/UUID |
| **Ключевое требование** | Уникальность в рамках контекста использования |
| **Основная практическая ценность** | Сериализация, межпроцессное взаимодействие, персистентность |

Таким образом, UID в C++ — это не языковая конструкция, а проектное решение, выбор которого определяется требованиями к области уникальности, производительности и необходимости сохранения идентичности объектов между запусками программы.
