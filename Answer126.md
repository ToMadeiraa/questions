# 126. Как подсчитать количество элементов в `std::list`

## Краткий ответ

Для подсчёта количества элементов в `std::list` используется метод **`size()`**:

```cpp
#include <list>
#include <iostream>

int main() {
    std::list<int> lst = {1, 2, 3, 4, 5};
    
    std::cout << "Количество элементов: " << lst.size() << std::endl; // 5
    return 0;
}
```

## Подробное объяснение

### Метод `size()`

`std::list` — это двусвязный список, и в отличие от `std::forward_list`, он **хранит счётчик элементов**. Начиная со стандарта **C++11**, метод `size()` гарантированно работает за **константное время O(1)** — он просто возвращает сохранённое значение счётчика, а не пересчитывает элементы.

```cpp
std::list<std::string> names = {"Alice", "Bob", "Charlie"};

std::size_t count = names.size(); // count == 3
```

**Возвращаемый тип:** `size_type` (обычно `std::size_t`).

### Проверка на пустоту

Если нужно просто узнать, пуст ли список, эффективнее (и выразительнее) использовать `empty()`, а не сравнивать `size() == 0`:

```cpp
if (lst.empty()) {
    std::cout << "Список пуст\n";
}
```

### Подсчёт с условием: `std::count` и `std::count_if`

Если нужно посчитать не все элементы, а только удовлетворяющие условию, применяются алгоритмы из `<algorithm>`:

```cpp
#include <list>
#include <algorithm>

std::list<int> lst = {1, 2, 3, 2, 4, 2, 5};

// Количество элементов, равных 2
int twos = std::count(lst.begin(), lst.end(), 2);          // 3

// Количество чётных элементов
int evens = std::count_if(lst.begin(), lst.end(),
                          [](int x) { return x % 2 == 0; }); // 4
```

Оба алгоритма работают за **линейное время O(n)**.

### Альтернатива: `std::distance`

Можно посчитать элементы через расстояние между итераторами:

```cpp
#include <iterator>

auto n = std::distance(lst.begin(), lst.end());
```

> ⚠️ Для `std::list` это **неэффективно**: итераторы списка не поддерживают произвольный доступ, поэтому `std::distance` пройдёт по всем узлам за **O(n)**. Используйте этот способ только если у вас нет доступа к самому контейнеру (например, передан диапазон итераторов), а не для `size()`.

## Сравнение способов

| Способ | Сложность | Когда использовать |
|---|---|---|
| `lst.size()` | O(1) | Основной способ — просто узнать количество элементов |
| `lst.empty()` | O(1) | Проверка «пуст ли список» |
| `std::count(...)` | O(n) | Подсчёт элементов, равных заданному значению |
| `std::count_if(...)` | O(n) | Подсчёт элементов по предикату |
| `std::distance(b, e)` | O(n) для `list` | Когда есть только диапазон итераторов |

## Важные замечания

- В **C++11 и новее** `size()` для `std::list` — **O(1)**. В старых реализациях (до C++11) стандарт разрешал вычисление за линейное время, но современные компиляторы хранят счётчик.
- Для сравнения: у `std::forward_list` метода `size()` **нет** вообще — там приходится использовать `std::distance`.
- Не путайте `size()` (количество элементов) с `capacity()` — у `std::list` понятия ёмкости нет, так как элементы хранятся в отдельных узлах.
