# 159. Pipe (Канал) в C++

**Pipe (канал)** — это механизм межпроцессного взаимодействия (IPC), представляющий собой однонаправленный поток данных, который позволяет передавать информацию от одного процесса к другому. В контексте C++ (и языка C в целом) работа с pipe обычно осуществляется через системные вызовы или функции стандартной библиотеки, предоставляемые операционной системой.

Существует два основных типа каналов: **анонимные (безымянные)** и **именованные (FIFO)**.

## 1. Анонимные каналы (Anonymous Pipes)

Анонимный канал создается внутри программы и не имеет имени в файловой системе. Обычно он используется для связи между родительским и дочерним процессами (например, после вызова `fork()`).

### Как это работает
При создании канала операционная система возвращает два файловых дескриптора:
*   **Дескриптор для чтения** (read end): из него можно только читать данные.
*   **Дескриптор для записи** (write end): в него можно только записывать данные.

Данные, записанные в один конец, читаются из другого в порядке очереди (FIFO — First In, First Out). Канал является **однонаправленным**: для двусторонней связи требуется создать два канала .

### Реализация в Windows (MSVC)
В среде Windows (библиотека CRT) для создания анонимного канала используется функция `_pipe`. Она возвращает два файловых дескриптора в массиве `pfds`: `pfds[0]` для чтения и `pfds[1]` для записи .

```cpp
#include <io.h>
#include <fcntl.h>
#include <stdio.h>

int main() {
    int pfds[2];
    // Создаем канал с буфером 1024 байта в текстовом режиме
    if (_pipe(pfds, 1024, _O_TEXT) == -1) {
        perror("_pipe failed");
        return 1;
    }
    
    // pfds[0] - чтение, pfds[1] - запись
    // ... использование ...
    return 0;
}
```
*Примечание: В Windows анонимные каналы часто используются для перенаправления стандартного ввода/вывода дочерних процессов, как это делает командная строка при использовании оператора `|` .*

### Реализация в Linux / POSIX (GCC / Clang)
В Unix-подобных системах используется системный вызов `pipe()`.

```cpp
#include <unistd.h>
#include <stdio.h>

int main() {
    int fd[2];
    if (pipe(fd) == -1) {
        perror("pipe failed");
        return 1;
    }
    
    // fd[0] - чтение, fd[1] - запись
    // ... использование ...
    return 0;
}
```

## 2. Именованные каналы (Named Pipes / FIFO)

Именованный канал (FIFO) отличается от анонимного тем, что существует в файловой системе как специальный файл. Это позволяет **несвязанным процессам** (не имеющим общего предка) обмениваться данными, открывая этот файл по имени .

*   **В Linux** для создания используется функция `mkfifo()`.
*   **В Windows** существуют именованные каналы (Named Pipes), которые являются более сложным механизмом, поддерживающим двустороннюю связь и сетевой обмен, но они реализуются через другие API (например, `CreateNamedPipe`), а не через функцию `_pipe`.

## Ключевые свойства Pipe

1.  **Однонаправленность**: Данные текут только в одну сторону. Если процессу нужно отправить запрос и получить ответ, создаются два канала .
2.  **Поток байтов**: Канал не сохраняет границы сообщений. Если вы записали 100 байт, а читаете 50, вы получите первые 50 байт, а остальные останутся в буфере до следующего чтения .
3.  **Блокировка**: 
    *   Если процесс пытается **читать** из пустого канала, он блокируется (ждет), пока данные не появятся.
    *   Если процесс пытается **писать** в заполненный канал (буфер ограничен), он блокируется, пока читатель не освободит место .
4.  **Сигналы (POSIX)**: Если процесс пытается записать в канал, у которого закрыт читающий конец, генерируется сигнал `SIGPIPE`. Если читающий конец закрыт, чтение возвращает 0 (EOF) .

## Применение в C++

Хотя в стандартной библиотеке C++ нет встроенного класса для pipe (например, нет `std::pipe`), вы можете использовать:
*   **Наследие C**: функции `pipe()`, `_pipe()`, `popen()` (для запуска команды и чтения её вывода).
*   **Обертки**: Создавать собственные классы-обертки (RAII) для управления дескрипторами, чтобы избежать утечек ресурсов .
*   **Сторонние библиотеки**: Например, Boost.Process или Qt (QProcess) предоставляют более высокоуровневые абстракции для работы с процессами и каналами.
