# 146. Для чего используется маска подсети?

**Маска подсети (subnet mask)** — это 32-битное число (в IPv4), которое используется для разделения IP-адреса на две части: **адрес сети** и **адрес узла (хоста)**. Она определяет, какая часть IP-адреса относится к идентификатору сети, а какая — к идентификатору конкретного устройства внутри этой сети.

## Основные задачи маски подсети

1. **Определение границы сети и хоста.**
   Побитовое умножение (логическое И, AND) IP-адреса на маску даёт адрес сети. Оставшиеся биты — адрес узла. Например:

   ```
   IP-адрес:  192.168.10.25   → 11000000.10101000.00001010.00011001
   Маска:     255.255.255.0   → 11111111.11111111.11111111.00000000
   --------------------------------------------------------------
   Адрес сети:192.168.10.0    → 11000000.10101000.00001010.00000000
   ```

   Здесь первые 24 бита — сеть, последние 8 бит — хост.

2. **Маршрутизация.**
   Устройство сравнивает адрес сети получателя со своим адресом сети. Если сети совпадают — пакет доставляется напрямую внутри локальной сети (по MAC-адресу через ARP), иначе — отправляется на шлюз по умолчанию (маршрутизатор).

3. **Разбиение сети на подсети (subnetting).**
   Позволяет администратору логически делить одну большую сеть на несколько меньших — например, по отделам, этажам, VLAN. Это повышает безопасность, упрощает управление и снижает объём широковещательного трафика (broadcast-домена).

4. **Определение широковещательного адреса и диапазона хостов.**
   Зная маску, можно вычислить:
   - адрес сети (все биты хоста = 0);
   - широковещательный адрес (все биты хоста = 1);
   - количество доступных хостов: `2^(бит хоста) − 2`.

5. **Агрегация маршрутов (supernetting / CIDR).**
   Маска в формате CIDR (например, `/24`) позволяет объединять несколько сетей в один маршрут, сокращая таблицы маршрутизации.

## Форматы записи

- **Десятичный:** `255.255.255.0`
- **CIDR (префикс):** `192.168.10.0/24`, где `/24` — количество единичных бит в маске.
- **Двоичный:** `11111111.11111111.11111111.00000000`

В маске единичные биты всегда идут подряд слева, а нулевые — справа (иначе маска некорректна).

## Пример на C++: вычисление адреса сети

```cpp
#include <iostream>
#include <cstdint>

// ip и mask — в сетевом порядке (big-endian), например, получены из inet_addr()
uint32_t networkAddress(uint32_t ip, uint32_t mask) {
    return ip & mask; // побитовое И
}

int main() {
    // 192.168.10.25 и 255.255.255.0 в виде 32-битных чисел
    uint32_t ip   = (192u << 24) | (168u << 16) | (10u << 8) | 25u;
    uint32_t mask = (255u << 24) | (255u << 16) | (255u << 8) | 0u;

    uint32_t net = networkAddress(ip, mask);

    std::cout << "Адрес сети: "
              << ((net >> 24) & 0xFF) << '.'
              << ((net >> 16) & 0xFF) << '.'
              << ((net >> 8)  & 0xFF) << '.'
              << ( net        & 0xFF) << '\n'; // 192.168.10.0
}
```

## Краткий итог

Маска подсети нужна, чтобы **отделить адрес сети от адреса хоста**. На этом строятся: маршрутизация пакетов, работа ARP, разбиение на подсети, вычисление broadcast-адреса и диапазона допустимых хостов, а также агрегация маршрутов в CIDR.
