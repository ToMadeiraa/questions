# 63. Абстрактный класс в C++

## Определение

**Абстрактный класс** — это класс, который содержит хотя бы одну **чисто виртуальную функцию** (pure virtual function). Такой класс нельзя инстанцировать напрямую — то есть нельзя создать его объект. Он предназначен только для использования в качестве базового класса для других классов.

Чисто виртуальная функция объявляется с помощью синтаксиса `= 0`:

```cpp
class Shape {
public:
    virtual double area() const = 0;   // чисто виртуальная функция
    virtual void draw() const = 0;     // ещё одна чисто виртуальная функция
    virtual ~Shape() = default;        // виртуальный деструктор (важно!)
};
```

Попытка создать объект такого класса приведёт к ошибке компиляции:

```cpp
Shape s;          // Ошибка: нельзя создать объект абстрактного класса
Shape* p = new Shape();  // Тоже ошибка
```

Однако **указатели и ссылки** на абстрактный класс вполне допустимы — через них работает полиморфизм:

```cpp
void printArea(const Shape& s) {
    std::cout << s.area() << '\n';  // вызовется реализация конкретного наследника
}
```

## Как перестать быть абстрактным

Класс-наследник становится **конкретным** (его можно инстанцировать), только если он переопределил **все** унаследованные чисто виртуальные функции. Если хотя бы одна осталась нереализованной — наследник тоже абстрактный.

```cpp
class Circle : public Shape {
public:
    explicit Circle(double r) : r_(r) {}
    double area() const override { return 3.14159 * r_ * r_; }
    void draw() const override { /* ... */ }
private:
    double r_;
};

Circle c(5.0);   // OK — все чисто виртуальные функции реализованы
```

## Зачем нужен абстрактный класс

1. **Задание интерфейса (контракта).** Абстрактный класс описывает, *что* должны уметь объекты, не навязывая *как* это делать. Наследники обязаны реализовать поведение.

2. **Полиморфизм.** Позволяет работать с объектами разных типов через единый базовый интерфейс:
   ```cpp
   std::vector<std::unique_ptr<Shape>> shapes;
   shapes.push_back(std::make_unique<Circle>(2.0));
   shapes.push_back(std::make_unique<Rectangle>(3.0, 4.0));
   for (const auto& s : shapes)
       std::cout << s->area() << '\n';
   ```

3. **Запрет создания «бессмысленного» объекта.** Если базовый класс не имеет смысла сам по себе (например, «Фигура» без конкретной геометрии), абстрактность защищает от ошибок на этапе компиляции.

4. **Общий код + интерфейс.** В отличие от чистого интерфейса, абстрактный класс может содержать и реализованные методы, и поля, переиспользуемые наследниками (например, общий счётчик или вспомогательные функции).

## Отличия от «обычного» класса с виртуальными функциями

- Класс с виртуальными, но **не чисто** виртуальными функциями — не абстрактный, его объекты создавать можно.
- Абстрактный класс — это класс, у которого **хотя бы одна** функция помечена `= 0`.

## Важные нюансы

- **Виртуальный деструктор обязателен**, если предполагается удаление наследников через указатель на базовый класс, иначе — неопределённое поведение.
- Чисто виртуальная функция **может иметь тело** (реализацию), которую наследники могут вызвать явно:
  ```cpp
  class Base {
  public:
      virtual void f() = 0;
  };
  void Base::f() { /* реализация по умолчанию */ }
  ```
  Но даже с телом класс остаётся абстрактным.
- Абстрактный класс может иметь конструкторы — они вызываются при создании объектов наследников.
- В C++ абстрактный класс — это не то же самое, что интерфейс в Java: помимо чисто виртуальных функций он может содержать данные и готовые методы.

## Итог

Абстрактный класс — это инструмент проектирования иерархий, который:
- фиксирует общий интерфейс для семейства классов;
- запрещает создание объектов базового типа;
- обеспечивает полиморфное поведение через указатели и ссылки;
- может нести общую реализацию для наследников.
