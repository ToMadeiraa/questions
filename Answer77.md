# 77. Константность в C++: переменные, ссылки, указатели

## 1. Константные переменные

Ключевое слово `const` делает объект **только для чтения**: после инициализации его значение нельзя изменить.

```cpp
const int x = 10;
// x = 20; // ошибка компиляции

int y = 5;
const int z = y; // OK: инициализация значением
// z = 7;        // ошибка
```

Важно: `const`-переменная **обязана быть инициализирована** при объявлении (кроме случаев, когда она — член класса, инициализируемый в конструкторе).

### `const` и `constexpr`

- `const` — «обещание не изменять»; значение может быть вычислено в рантайме.
- `constexpr` — значение **гарантированно** известно на этапе компиляции (более строгое требование).

```cpp
const int a = rand();      // OK
// constexpr int b = rand(); // ошибка: не compile-time константа
constexpr int c = 42;      // OK
```

## 2. Константные ссылки

Ссылка — это **псевдоним** существующего объекта. Ссылку нельзя «перепривязать» к другому объекту, но через обычную ссылку можно менять сам объект.

```cpp
int a = 1;
int& ref = a;       // обычная ссылка
ref = 2;            // a == 2

const int& cref = a; // ссылка на константу
// cref = 3;         // ошибка: нельзя менять через cref
```

Ключевые свойства `const`-ссылки:

- **Не позволяет менять объект** через эту ссылку.
- **Может связываться с временными объектами** (rvalue) и продлевает их время жизни:

```cpp
const std::string& s = std::string("hello"); // OK, время жизни продлено
// std::string& s2 = std::string("hello");   // ошибка компиляции
```

- Может связываться с объектом **другого типа** с неявным преобразованием (создаётся временный объект):

```cpp
const double& d = 42; // OK: создаётся временный double
```

**Где применять:** параметры функций, которые не должны копировать аргумент и не собираются его менять:

```cpp
void print(const std::string& s); // без копирования, без изменения
```

## 3. Указатели и константность

У указателя есть **две независимые «степени свободы»**:

1. Можно ли менять **сам указатель** (куда он указывает)?
2. Можно ли менять **объект, на который он указывает**?

Отсюда три основные комбинации.

### 3.1. Указатель на константу (pointer to const)

```cpp
const int* p;   // то же, что int const* p;
```

- **Нельзя** менять объект через `*p`.
- **Можно** менять сам указатель (переназначить на другой адрес).

```cpp
int a = 1, b = 2;
const int* p = &a;
// *p = 10;  // ошибка: объект константный
p = &b;      // OK: сам указатель менять можно
```

### 3.2. Константный указатель (const pointer)

```cpp
int* const p = &a;
```

- **Можно** менять объект через `*p`.
- **Нельзя** менять сам указатель (он «прибит» к адресу).

```cpp
int a = 1, b = 2;
int* const p = &a;
*p = 10;    // OK: объект менять можно
// p = &b;  // ошибка: указатель константный
```

### 3.3. Константный указатель на константу

```cpp
const int* const p = &a;
```

- Нельзя менять ни объект, ни сам указатель.

### 3.4. Правило чтения объявления

Читайте справа налево, начиная от имени:

| Объявление | Чтение |
|---|---|
| `const int* p` | `p` — указатель на `const int` |
| `int* const p` | `p` — константный указатель на `int` |
| `const int* const p` | `p` — константный указатель на `const int` |
| `int** p` | `p` — указатель на указатель на `int` |
| `const int** p` | `p` — указатель на указатель на `const int` |
| `int* const* p` | `p` — указатель на константный указатель на `int` |

> Частая ошибка: `const int* p` и `int const* p` — **одно и то же** (const относится к `int`), а `int* const p` — совсем другое (const относится к указателю).

### 3.5. Сводная таблица

| Тип | `*p = ...` | `p = ...` |
|---|---|---|
| `int* p` | ✅ | ✅ |
| `const int* p` | ❌ | ✅ |
| `int* const p` | ✅ | ❌ |
| `const int* const p` | ❌ | ❌ |

## 4. Размер указателя в памяти

Размер указателя **не зависит** от типа, на который он указывает (`int*`, `double*`, `const char*` — все одинаковы), и **зависит от архитектуры и платформы**:

- **32-битная платформа:** 4 байта (32 бита).
- **64-битная платформа:** 8 байт (64 бита).

Проверить можно так:

```cpp
#include <iostream>

int main() {
    std::cout << sizeof(int*)    << '\n'; // 8 на x86-64
    std::cout << sizeof(double*) << '\n'; // 8
    std::cout << sizeof(char*)   << '\n'; // 8
    std::cout << sizeof(void*)   << '\n'; // 8
}
```

Дополнительно:

- На **любой** платформе `sizeof(char) == 1`, но `sizeof(char*)` обычно не 1.
- Размер ссылки в стандарте не определён; на практике компиляторы реализуют ссылки через указатели, и `sizeof(T&)` возвращает размер **объекта** `T`, а не ссылки (так работает, например, GCC).
- Размер не зависит от `const`-квалификаторов: `sizeof(const int*) == sizeof(int*)`.

## 5. Краткое резюме

- **`const` у переменной** — запрет изменения значения после инициализации.
- **`const`-ссылка** — псевдоним, через который нельзя менять объект; умеет связываться с временными объектами.
- **`const int* p`** — указатель на константу: данные менять нельзя, указатель — можно.
- **`int* const p`** — константный указатель: данные менять можно, указатель — нельзя.
- **`const int* const p`** — ни то, ни другое.
- **Размер указателя** = размер машинного слова: 4 байта на 32-битных системах, 8 байт на 64-битных; от типа не зависит.
