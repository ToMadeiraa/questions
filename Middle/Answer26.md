# 26. Расскажите о битовых полях

**Битовое поле** в C++ — это член класса или структуры, для которого явно указано, сколько битов памяти он должен занимать. Это позволяет упаковывать данные плотнее, чем при использовании обычных целочисленных типов, что бывает полезно для экономии памяти или для точного соответствия аппаратным регистрам и сетевым протоколам.

### Синтаксис и базовые типы

Объявление битового поля выглядит так:

```cpp
struct S {
    unsigned int b : 3; // b занимает 3 бита
};
```

Тип битового поля может быть целочисленным (включая `bool`) или перечислением (`enum`). Битовое поле не может быть статическим членом данных .

Ширина поля задаётся целочисленной константой и определяет диапазон значений. Например, для `unsigned int b : 3` допустимы значения от 0 до 7. Если попытаться сохранить 8, значение переполнится (обычно до 0, но формально это определяется реализацией) .

### Анонимные поля и выравнивание

Можно объявлять битовые поля без имени. Они служат для заполнения (padding) и не доступны для чтения или записи:

```cpp
struct S {
    unsigned int a : 4;
    unsigned int   : 4; // пропуск 4 бит
    unsigned int b : 4;
};
```

Особый случай — **анонимное поле шириной 0**. Оно не занимает места, но заставляет следующее за ним битовое поле начать с новой границы единицы распределения (allocation unit) базового типа :

```cpp
struct S {
    unsigned char a : 4;
    unsigned char   : 0; // следующее поле начнётся с нового байта
    unsigned char b : 4;
};
```

### Упаковка и порядок

Смежные битовые поля обычно упаковываются вместе, но конкретные детали (например, порядок от младших битов к старшим или наоборот, а также возможность пересечения границ байтов) **определяются реализацией** (implementation-defined) . В Microsoft Visual C++ данные упаковываются от младших битов к старшим .

### Ограничения

С битовыми полями связано несколько важных ограничений:

1. **Нельзя взять адрес**: Поскольку битовое поле может начинаться не с начала байта, операция `&` для него невозможна. Соответственно, нельзя создать указатель или неконстантную ссылку на битовое поле .
2. **Ссылки**: Константную ссылку (`const T&`) на битовое поле создать можно, но при этом будет создана временная копия значения, и ссылка будет привязана к ней, а не к самому полю .
3. **Размер**: Ширина поля не может превышать разрядность базового типа (в отличие от некоторых других языков, в C++ при превышении ширины лишние биты становятся неиспользуемым заполнением, а значение всё равно ограничивается типом) .

### Инициализация (C++20)

Начиная с C++20, для битовых полей разрешены инициализаторы по умолчанию (default member initializers):

```cpp
struct S {
    int b : 3 = 1; // корректно в C++20
};
```

До C++20 такая запись считалась некорректной .
