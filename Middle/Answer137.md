# 137. Что такое атомарная операция? std::atomic?

## Атомарная операция

**Атомарная операция** — это операция над объектом, которая является **неделимой** по отношению к любым другим атомарным операциям над тем же самым объектом . Это означает, что никакой другой поток не может наблюдать объект в промежуточном состоянии: результаты операции видны либо до её начала, либо после её завершения, но не в процессе выполнения.

Ключевые свойства атомарных операций:
- **Отсутствие гонок данных (data races)**: если один поток пишет в атомарный объект, а другой читает из него, поведение программы определено стандартом (в отличие от обычных переменных, где это приводит к неопределённому поведению) .
- **Неделимость**: операция не может быть прервана другим потоком на полпути.
- **Возможность упорядочивания памяти**: атомарные операции могут задавать ограничения на порядок видимости других (неатомарных) обращений к памяти через параметр `std::memory_order` .

## std::atomic

`std::atomic` — это шаблон класса из заголовка `<atomic>`, появившийся в C++11, который инкапсулирует значение типа `T` и предоставляет набор атомарных операций над ним .

### Основные характеристики

| Характеристика | Описание |
|---|---|
| **Копирование и перемещение** | Запрещены. `std::atomic` не является ни CopyConstructible, ни MoveConstructible . |
| **Специализации** | Стандартная библиотека предоставляет специализации для целочисленных типов, указателей, `bool`, а также для `std::shared_ptr` (C++20) . |
| **Lock-free** | Метод `is_lock_free()` позволяет проверить, реализуются ли операции без внутренних блокировок (мьютексов). В C++17 добавлена константа `is_always_lock_free` . |
| **Инициализация** | Начиная с C++20 конструктор по умолчанию инициализирует значение нулём (value-initialization). До C++20 требовалась явная инициализация через `std::atomic_init` . |

### Основные операции

Для любого `std::atomic<T>` доступны базовые операции:

- **`store(desired)`**: атомарно записывает значение.
- **`load()`**: атомарно читает значение.
- **`exchange(desired)`**: атомарно заменяет значение и возвращает предыдущее.
- **`compare_exchange_weak/strong(expected, desired)`**: атомарно сравнивает значение с `expected` и, если они равны, заменяет на `desired`; иначе записывает текущее значение в `expected` (CAS-операция) .

### Дополнительные операции для специализаций

Для **целочисленных типов** и **указателей** доступны дополнительные атомарные операции:

| Операция | Описание |
|---|---|
| `fetch_add` / `fetch_sub` | Атомарное сложение/вычитание, возвращает предыдущее значение |
| `fetch_and` / `fetch_or` / `fetch_xor` | Атомарные побитовые операции (только для целых) |
| `operator++` / `operator--` | Атомарный инкремент/декремент |

Для **указателей** (`std::atomic<T*>`) операции `fetch_add` и `fetch_sub` выполняют арифметику указателей .

### Псевдонимы типов

Стандарт определяет удобные псевдонимы для распространённых типов, например:
- `std::atomic_int` ≡ `std::atomic<int>`
- `std::atomic_bool` ≡ `std::atomic<bool>`
- `std::atomic_size_t`, `std::atomic_uint64_t` и другие .

### Пример использования

```cpp
#include <atomic>
#include <thread>
#include <iostream>

std::atomic<int> counter{0};

void increment() {
    for (int i = 0; i < 100000; ++i) {
        counter.fetch_add(1, std::memory_order_relaxed);
    }
}

int main() {
    std::thread t1(increment);
    std::thread t2(increment);
    t1.join();
    t2.join();
    std::cout << counter.load() << std::endl; // Гарантированно 200000
}
```

### Важное замечание о lock-free

Не все типы `std::atomic<T>` гарантируют отсутствие блокировок. Для сложных пользовательских типов реализация может использовать внутренний мьютекс. Для критичных к производительности участков следует проверять `is_lock_free()` или использовать гарантированно lock-free тип `std::atomic_flag` .
