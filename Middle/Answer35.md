# 35. Что такое список инициализации?

**Список инициализации** (initializer list, member initializer list) — это специальный синтаксис в конструкторах C++, позволяющий инициализировать поля класса и базовые классы **до** выполнения тела конструктора. Он записывается после списка параметров конструктора, через двоеточие, и отделяется от тела конструктора фигурными скобками.

## Синтаксис

```cpp
class MyClass {
    int a;
    double b;
    const int c;
    Base base;
    std::string name;
public:
    MyClass(int x, double y)
        : a(x),        // инициализация поля a
          b(y),        // инициализация поля b
          c(100),      // инициализация константного поля
          base(x),     // инициализация базового класса
          name("hello")// инициализация поля объекта
    {
        // тело конструктора
    }
};
```

## Ключевые особенности

### 1. Порядок инициализации
Члены инициализируются **в порядке их объявления в классе**, а не в порядке их перечисления в списке инициализации. Это частая причина ошибок.

```cpp
class A {
    int x;   // объявлен первым
    int y;   // объявлен вторым
public:
    A(int val) : y(val), x(y) {}  // ВНИМАНИЕ: x инициализируется первым!
    // x получит неинициализированное значение y
};
```

### 2. Когда список инициализации обязателен

Список инициализации **необходим** в следующих случаях:

- **Константные поля** (`const`):
  ```cpp
  class A {
      const int x;
  public:
      A(int v) : x(v) {}  // обязательно
  };
  ```

- **Ссылочные поля**:
  ```cpp
  class A {
      int& ref;
  public:
      A(int& r) : ref(r) {}  // обязательно
  };
  ```

- **Поля-объекты без конструктора по умолчанию**:
  ```cpp
  class A {
      std::string s;
  public:
      A() : s("initial") {}  // иначе ошибка компиляции
  };
  ```

- **Базовые классы без конструктора по умолчанию**:
  ```cpp
  class Derived : public Base {
  public:
      Derived(int x) : Base(x) {}  // обязательно
  };
  ```

- **Инициализация виртуальных базовых классов** (в самом производном классе).

### 3. Преимущества перед присваиванием в теле

```cpp
// Плохо: сначала инициализация по умолчанию, потом присваивание
A(int v) {
    x = v;
}

// Хорошо: прямая инициализация
A(int v) : x(v) {}
```

Список инициализации:
- Избегает двойной работы (инициализация + присваивание);
- Позволяет работать с типами, у которых нет конструктора по умолчанию или оператора присваивания;
- Обязателен для `const`, ссылок и некоторых других случаев.

### 4. Делегирующие конструкторы (C++11)

Спискок инициализации может вызывать другой конструктор того же класса:

```cpp
class A {
    int x, y;
public:
    A() : A(0, 0) {}          // делегирование
    A(int a, int b) : x(a), y(b) {}
};
```

### 5. Наследование и виртуальные базы

При множественном наследовании порядок инициализации базовых классов определяется порядком их объявления в списке наследования, а не в списке инициализации. Виртуальные базовые классы инициализируются самым производным классом.

### 6. Инициализация массивов-членов

До C++11 массивы-члены нельзя было инициализировать в списке инициализации. Начиная с C++11 можно использовать списки инициализации в фигурных скобках:

```cpp
class A {
    int arr[3];
public:
    A() : arr{1, 2, 3} {}
};
```

## Итог

Список инициализации — это механизм **прямой инициализации** членов класса и базовых классов в конструкторе. Он предпочтительнее присваивания в теле конструктора, а в ряде случаев (константы, ссылки, объекты без default-конструктора) — единственно возможный способ инициализации. Важно помнить о порядке инициализации членов — он определяется порядком объявления в классе, а не порядком в списке инициализации.
