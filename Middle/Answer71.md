# 71. Какая разница между overload and override?

Это два принципиально разных механизма в C++, которые часто путают из-за похожих названий. Разберём каждый по отдельности и сравним.

## Overloading (перегрузка)

**Перегрузка** — это создание нескольких функций (или операторов) с **одинаковым именем, но разными сигнатурами** в **одной и той же области видимости**. Компилятор выбирает нужную версию по типу и количеству аргументов на этапе компиляции (статическое связывание / раннее связывание).

```cpp
int add(int a, int b)          { return a + b; }
double add(double a, double b) { return a + b; }
int add(int a, int b, int c)   { return a + b + c; }

add(1, 2);       // вызов int add(int, int)
add(1.5, 2.5);   // вызов double add(double, double)
add(1, 2, 3);    // вызов int add(int, int, int)
```

Ключевые моменты:
- Функции находятся в **одной области видимости** (например, оба члена класса или обе свободные функции).
- Различаются **списком параметров** (типы, количество, порядок).
- **Возвращаемый тип не участвует** в разрешении перегрузки — по нему нельзя перегружать.
- Разрешается на этапе **компиляции**.

## Overriding (переопределение)

**Переопределение** — это замена виртуальной функции базового класса её реализацией в **производном классе** при **совпадении сигнатуры**. Вызывается через указатель/ссылку на базовый класс и разрешается на этапе **выполнения** (динамическое связывание / позднее связывание), благодаря таблице виртуальных функций (vtable).

```cpp
class Base {
public:
    virtual void print() const { std::cout << "Base\n"; }
    virtual ~Base() = default;
};

class Derived : public Base {
public:
    void print() const override { std::cout << "Derived\n"; } // override
};

Base* p = new Derived();
p->print(); // "Derived" — вызов разрешён в рантайме
```

Ключевые моменты:
- Функции находятся в **разных классах**, связанных наследованием.
- **Сигнатура должна совпадать** (имя, параметры, константность). Возвращаемый тип может быть ковариантным (указатель/ссылка на производный тип).
- Базовая функция должна быть **`virtual`**.
- Используйте ключевое слово **`override`** (C++11) — компилятор проверит, что действительно переопределяете, и выдаст ошибку, если сигнатуры не совпали (защита от случайного «сокрытия»).
- Разрешается на этапе **выполнения**.

## Сводная таблица

| Критерий | Overloading (перегрузка) | Overriding (переопределение) |
|---|---|---|
| Область видимости | Одна и та же | Базовый и производный классы |
| Сигнатура | **Разная** (параметры) | **Одинаковая** |
| Наследование | Не требуется | Обязательно |
| `virtual` | Не нужен | Обязателен в базовом классе |
| Связывание | Статическое (компиляция) | Динамическое (runtime, vtable) |
| Ключевое слово | — | `override` (C++11, рекомендуется) |
| Роль возвращаемого типа | Не учитывается | Может быть ковариантным |

## Частая ловушка: сокрытие имён (name hiding)

Если в производном классе объявить функцию с тем же именем, но **другой сигнатурой**, это не перегрузка и не переопределение, а **сокрытие** всех перегрузок базового класса с этим именем:

```cpp
class Base {
public:
    virtual void f(int)    {}
    virtual void f(double) {}
};

class Derived : public Base {
public:
    void f(int) override {}  // переопределяет только f(int)
    // f(double) из Base скрыта!
};

Derived d;
d.f(3.14); // вызовется Derived::f(int) после преобразования double->int
```

Чтобы вернуть видимость перегрузок базового класса, используют `using Base::f;`.

## Итог одной фразой

**Overloading** — «одно имя, разные параметры, один класс, выбор на компиляции». **Overriding** — «одна сигнатура, разные классы через наследование, выбор в рантайме через `virtual`».
