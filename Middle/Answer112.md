# 112. Как оптимизировать удаление элемента со средины вектора?

Удаление элемента из середины `std::vector` — операция линейной сложности `O(n)`, потому что вектор хранит элементы непрерывно, и после удаления все последующие элементы необходимо сдвинуть, чтобы закрыть образовавшуюся «дыру». Однако существуют способы оптимизировать этот процесс в зависимости от требований к порядку элементов.

## 1. Если порядок элементов НЕ важен: O(1) через обмен с последним

Самый быстрый способ — поставить на место удаляемого элемента последний элемент вектора, а затем удалить последний. Это работает за **O(1)** (константное время), но **нарушает порядок** оставшихся элементов.

```cpp
#include <vector>
#include <utility>

template <typename T>
void quick_remove_at(std::vector<T>& vec, std::size_t idx) {
    if (idx < vec.size()) {
        // Перемещаем последний элемент на место удаляемого
        vec[idx] = std::move(vec.back());
        // Удаляем последний (теперь дублирующий) элемент
        vec.pop_back();
    }
}
```

Этот подход идеален, когда вектор используется как неупорядоченный контейнер (например, пул объектов, множество активных сущностей), и порядок не имеет значения.

## 2. Если порядок ВАЖЕН: минимизация перемещений

Если порядок необходимо сохранить, полностью избежать `O(n)` не получится, но можно оптимизировать константу:

**Используйте перемещение вместо копирования.** Начиная с C++11, `std::vector::erase` использует move-семантику для сдвига элементов. Для типов, поддерживающих эффективное перемещение (например, `std::string`, `std::unique_ptr`, контейнеры), это значительно быстрее копирования. Убедитесь, что ваш тип имеет корректный move-конструктор и move-присваивание.

**Удаляйте диапазон, а не по одному.** Если нужно удалить несколько элементов по условию, используйте идиому erase-remove (или `std::erase_if` в C++20), которая минимизирует количество перемещений:

```cpp
// C++20 и новее
std::erase_if(vec, [](const auto& item) { return /* условие удаления */; });

// До C++20: идиома erase-remove
vec.erase(
    std::remove_if(vec.begin(), vec.end(), [](const auto& item) { 
        return /* условие удаления */; 
    }),
    vec.end()
);
```

`std::remove_if` «уплотняет» сохраняемые элементы в начало, а затем `erase` отрезает хвост одним вызовом, что эффективнее множественных одиночных `erase`.

## 3. Радикальное решение: сменить контейнер

Если удаление из середины происходит часто и порядок важен, `std::vector` — неоптимальная структура данных. Рассмотрите:

- **`std::list`** — двусвязный список, удаление по итератору за `O(1)`, но плохая локальность кэша и отсутствие произвольного доступа.
- **`std::deque`** — двухсторонняя очередь, удаление из середины всё ещё `O(n)`, но в некоторых реализациях перемещения могут быть дешевле благодаря блочной структуре.
- **`std::set` / `std::unordered_set`** — если уникальность и поиск важнее порядка.

## Итоговая рекомендация

| Ситуация | Решение | Сложность |
|---|---|---|
| Порядок не важен | `vec[idx] = std::move(vec.back()); vec.pop_back();` | **O(1)** |
| Порядок важен, удаление одного элемента | `vec.erase(vec.begin() + idx)` (move-семантика C++11) | **O(n)** |
| Порядок важен, массовое удаление по условию | `std::erase_if` (C++20) / erase-remove | **O(n)**, минимум перемещений |
| Частые удаления из середины | Сменить контейнер на `std::list` или другую структуру | Зависит от контейнера |

Ключевой вывод: если порядок не критичен, используйте обмен с последним — это единственный способ получить **O(1)** для `std::vector`. Во всех остальных случаях оптимизация сводится к минимизации количества и стоимости перемещений.
