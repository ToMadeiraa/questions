# 25. Для чего используют выравнивания, можно ли его контролировать?

## Краткий ответ

Выравнивание (alignment) используется для того, чтобы данные в памяти располагались по адресам, кратным определённым степеням двойки. Это необходимо для **корректной работы на некоторых аппаратных архитектурах** и для **повышения производительности** за счёт сокращения числа обращений к памяти . В большинстве случаев компилятор выбирает оптимальное выравнивание автоматически, но в C++ его можно **контролировать** с помощью спецификатора `alignas` (начиная с C++11) и запрашивать через оператор `alignof` .

---

## Зачем нужно выравнивание

### 1. Аппаратные ограничения (корректность)

Некоторые процессоры (например, Motorola 68000) физически не способны выполнить операцию чтения или записи по невыровненному адресу — попытка такого доступа приводит к аппаратному исключению . Даже на архитектурах x86, которые обычно допускают невыровненный доступ, это может быть медленнее.

### 2. Производительность

Современные процессоры читают память не побайтно, а блоками (например, 4, 8 или 16 байт). Если объект расположен по адресу, не кратному его размеру, процессору может потребоваться **два обращения к памяти** вместо одного, чтобы извлечь все байты объекта. Выравнивание гарантирует, что объект целиком помещается в одну «естественную» границу доступа .

### 3. Требования ABI и структур данных

Компилятор вставляет **padding** (неиспользуемые байты) между членами структуры, чтобы каждый член был выровнен согласно своему типу. Это влияет на `sizeof` структуры. Например, структура с `char` и `int` может занимать 8 байт вместо 5 именно из-за выравнивания .

---

## Можно ли контролировать выравнивание?

Да. В современном C++ (C++11 и новее) для этого есть два стандартных инструмента.

### 1. `alignof` — запрос выравнивания

Оператор `alignof` возвращает требуемое выравнивание для типа или выражения. Результат имеет тип `std::size_t` и обычно выражается в байтах .

```cpp
#include <iostream>

struct Foo {
    char c;
    int i;
};

int main() {
    std::cout << alignof(char) << '\n';   // обычно 1
    std::cout << alignof(int)  << '\n';   // обычно 4
    std::cout << alignof(Foo)  << '\n';   // обычно 4 (по максимальному члену)
}
```

### 2. `alignas` — задание выравнивания

Спецификатор `alignas` позволяет **увеличить** (ужесточить) выравнивание типа или объекта. Он может применяться к :

- объявлению класса/структуры/объединения/перечисления;
- объявлению небитового поля класса;
- объявлению переменной (кроме параметров функций и параметров catch).

```cpp
struct alignas(16) Vec4 {
    float x, y, z, w;
};

alignas(64) char cacheline[64];
```

Ключевые правила использования `alignas`:

- Если указано несколько спецификаторов `alignas`, выбирается **самый строгий (наибольший)** .
- `alignas` **не может ослабить** естественное выравнивание типа. Если запрошенное выравнивание меньше естественного, программа считается некорректной (ill-formed) .
- `alignas(0)` игнорируется .
- Недопустимые значения (например, `alignas(3)`) являются ошибкой, поскольку допустимые выравнивания — это степени двойки .

**Пример комбинирования:**

```cpp
struct alignas(8) S {};

// Ошибка: alignas(1) ослабило бы выравнивание S (которое равно 8)
// struct alignas(1) U { S s; }; // ill-formed
```

### 3. Ограничение: уменьшение выравнивания (упаковка)

Стандартный `alignas` **не предназначен для уменьшения** выравнивания ниже естественного. Если требуется плотная упаковка структуры (без padding), используются нестандартные средства, например `#pragma pack` в MSVC или атрибуты компилятора (`__attribute__((packed))` в GCC/Clang). Однако это снижает переносимость и может привести к невыровненному доступу .

### 4. Динамическое выделение с пользовательским выравниванием

Если нужно выделить память с выравниванием, превышающим стандартное (`std::max_align_t`), в C++17 появились перегрузки `operator new` и `operator new[]`, принимающие `std::align_val_t`. Также существуют вспомогательные шаблоны `std::aligned_storage` (устарел в C++23) и `std::aligned_union` для создания буферов под объекты с нестандартным выравниванием .

## Итог

| Вопрос | Ответ |
|---|---|
| Зачем нужно выравнивание | Корректность на строгих архитектурах, производительность доступа к памяти, соблюдение ABI |
| Можно ли запросить | Да, оператор `alignof` |
