# 164. Реализуйте функцию, которая за один проход найдет уникальный элемент в контейнере

## Постановка задачи

Под «уникальным элементом» обычно понимают элемент, который встречается в контейнере **ровно один раз**, тогда как все остальные элементы встречаются дважды (или чётное число раз). Классический пример — задача вида: дан массив, где каждое число повторяется дважды, кроме одного — найти это число.

Требование «за один проход» означает, что мы не можем сначала посчитать частоты (это потребовало бы либо второго прохода, либо дополнительной памяти O(n) под `std::unordered_map`).

## Ключевая идея: XOR

Для случая «все повторяются дважды, кроме одного» есть элегантное решение через побитовое исключающее ИЛИ (XOR):

Свойства XOR:
- `a ^ a = 0` — одинаковые числа взаимно уничтожаются;
- `a ^ 0 = a`;
- операция коммутативна и ассоциативна.

Значит, если свернуть весь контейнер через XOR, все парные элементы обнулятся, и в результате останется ровно тот элемент, который встречается один раз.

## Реализация

```cpp
#include <vector>
#include <cstddef>

// Универсальная версия под любой диапазон (итераторы)
template <typename InputIt, typename T = typename std::iterator_traits<InputIt>::value_type>
T findUnique(InputIt first, InputIt last)
{
    T result{};               // ноль нужного типа
    for (; first != last; ++first)
        result ^= *first;     // один проход, O(1) доп. памяти
    return result;
}

// Удобная обёртка для контейнера
template <typename Container>
auto findUnique(const Container& c)
{
    return findUnique(c.begin(), c.end());
}
```

Пример использования:

```cpp
#include <iostream>
#include <list>

int main()
{
    std::vector<int> v{4, 1, 2, 1, 2, 4, 7};
    std::cout << findUnique(v) << '\n';   // 7

    std::list<int> l{10, 3, 10, 5, 3};
    std::cout << findUnique(l) << '\n';   // 5
}
```

## Анализ

| Характеристика | Значение |
|---|---|
| Время | O(n) — ровно один проход |
| Доп. память | O(1) |
| Требование к типу | поддержка `operator^` (целочисленные типы) |

## Важные оговорки

1. **XOR работает только для целочисленных типов.** Для `double`, строк и произвольных структур этот трюк не годится — там понадобится хеш-таблица (`std::unordered_map` / `std::unordered_set`), что нарушит O(1) по памяти, либо сортировка (O(n log n)).

2. **Если «уникальный» = «встречается ровно один раз» при произвольных кратностях остальных**, XOR недостаточен. Тогда за один проход с O(1) памяти задачу в общем случае не решить — нужна либо хеш-таблица (один проход, O(n) памяти), либо два прохода (сортировка/подсчёт). Стоит уточнить у преподавателя постановку: классическая формулировка подразумевает «все, кроме одного, встречаются дважды».

3. **Обобщение на «все повторяются трижды, кроме одного»** решается через подсчёт битов по модулю 3 (тоже один проход, O(1) памяти), но это уже другой вариант задачи.

## Итог

Для стандартной формулировки «каждое число дважды, одно — один раз» оптимальное решение — свёртка через XOR за один проход с константной памятью, как показано в шаблоне `findUnique`.
