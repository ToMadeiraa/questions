# 81. Что такое выравнивание данных?

**Выравнивание данных (data alignment)** в C++ — это свойство адреса памяти (или типа объекта), определяющее, по каким границам (кратным степени двойки) может быть размещён объект данного типа. Каждый тип объекта в C++ имеет **требование выравнивания (alignment requirement)** — целое значение типа `std::size_t`, всегда являющееся степенью двойки, которое задаёт количество байтов между последовательными адресами, по которым могут размещаться объекты этого типа .

## Ключевые понятия

**Требование выравнивания типа.** Для любого полного типа объекта существует минимальное выравнивание, которому должен удовлетворять адрес размещения объекта. Например, если `alignof(int)` равно 4, то адрес любого объекта типа `int` должен быть кратен 4. Наименьшее выравнивание имеют типы `char`, `signed char` и `unsigned char` — оно равно 1. Наибольшее фундаментальное выравнивание определяется реализацией и соответствует `alignof(std::max_align_t)` .

**Заполнение (padding).** Чтобы обеспечить выполнение требований выравнивания для всех нестатических членов класса или структуры, компилятор может вставлять неиспользуемые байты (padding) между членами. Например, в структуре:
```cpp
struct X {
    int n;   // 4 байта, выравнивание 4
    char c;  // 1 байт, выравнивание 1
};
```
После поля `c` компилятор добавит 3 байта заполнения, чтобы размер структуры был кратен её выравниванию (4). Итоговый `sizeof(X)` будет равен 8, а `alignof(X)` — 4 .

## Управление выравниванием в C++

Начиная с C++11, для запроса и установки выравнивания используются стандартные средства:

- **`alignof`** — оператор, возвращающий требование выравнивания типа. Например, `alignof(int)` обычно равно 4 .
- **`alignas`** — спецификатор, позволяющий задать более строгое (большее) выравнивание для переменной или типа. Например, `alignas(16) float arr[4];` гарантирует, что `arr` будет размещён по 16-байтовой границе .

Если выравнивание типа делается строже, чем `std::max_align_t`, такое требование называется **расширенным (extended alignment)**, а тип — **сверхвыровненным (over-aligned)**. Поддержка сверхвыровненных типов в динамической памяти (например, через `new`) определяется реализацией; для гарантированного размещения используются специальные средства, такие как `std::aligned_storage` (устарел в C++23) или платформенные функции вроде `_aligned_malloc` .

## Зачем это нужно

Выравнивание данных критично по двум причинам. Во-первых, многие аппаратные архитектуры требуют или настоятельно рекомендуют обращаться к данным по выровненным адресам; невыровненный доступ может быть медленнее или даже приводить к аппаратному исключению. Во-вторых, правильное выравнивание позволяет процессору эффективнее использовать кэш и векторизованные инструкции. Компилятор автоматически выравнивает объекты в соответствии с требованиями их типов, поэтому в большинстве сценариев программисту не нужно об этом заботиться .
