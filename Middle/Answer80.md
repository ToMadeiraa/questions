# 80. Какие функции класса автоматически генерирует компилятор, если их не определить?

Компилятор C++ автоматически генерирует (неявно определяет) ряд специальных функций-членов класса, если программист не объявил их явно. Эти функции называются **специальными функциями-членами** (special member functions) и имеют особый синтаксис объявления .

В зависимости от стандарта C++ и ситуации, компилятор может сгенерировать следующие функции:

### 1. Конструктор по умолчанию
Генерируется, если в классе не объявлено **ни одного** конструктора (ни пользовательского, ни с параметрами). Выполняет инициализацию полей по умолчанию (для встроенных типов — оставляет без инициализации, для классов — вызывает их конструкторы по умолчанию).

### 2. Деструктор
Генерируется, если деструктор не объявлен явно. Вызывает деструкторы полей класса и базовых классов. В C++20 и новее существует понятие «перспективного деструктора» (prospective destructor) .

### 3. Конструктор копирования
Генерируется, если он не объявлен явно. Выполняет **поверхностное копирование** (shallow copy) — копирует значения всех полей. Для классов вызывает их конструкторы копирования, для указателей — просто копирует адрес.

### 4. Оператор присваивания копированием
Генерируется, если не объявлен явно. Также выполняет поверхностное копирование полей.

### 5. Конструктор перемещения (начиная с C++11)
Генерируется, если не объявлены явно **ни конструктор копирования, ни оператор присваивания копированием, ни деструктор** (а также если не объявлен конструктор перемещения или оператор перемещения). Выполняет перемещение ресурсов (например, «перекладывание» указателей).

### 6. Оператор присваивания перемещением (начиная с C++11)
Генерируется при тех же условиях, что и конструктор перемещения.

---

### Важное правило (Rule of Three/Five)
Если вы объявляете **деструктор, конструктор копирования или оператор присваивания копированием**, компилятор **не будет** генерировать конструктор перемещения и оператор присваивания перемещением . Это сделано для обратной совместимости и безопасности: класс, управляющий ресурсами вручную, скорее всего, требует явной реализации перемещения.

Если вы хотите сохранить поведение по умолчанию для этих функций, можно использовать синтаксис `= default`:
```cpp
class MyClass {
public:
    MyClass() = default;
    MyClass(const MyClass&) = default;
    MyClass& operator=(const MyClass&) = default;
    ~MyClass() = default;
};
```

### Резюме
Компилятор генерирует до **шести** специальных функций-членов (в современном C++): конструктор по умолчанию, деструктор, копирующий конструктор, копирующее присваивание, перемещающий конструктор и перемещающее присваивание. Однако генерация перемещающих операций блокируется, если объявлены копирующие операции или деструктор.
