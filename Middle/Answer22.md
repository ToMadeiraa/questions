# 22. Как происходит передача параметров в функцию?

В C++ существует несколько механизмов передачи параметров в функцию. Выбор способа влияет на производительность, безопасность и семантику (может ли функция изменить аргумент).

## 1. Передача по значению (by value)

Параметр — это **копия** аргумента. Функция работает с копией, изменения не затрагивают оригинал.

```cpp
void foo(int x) {
    x = 42;          // изменяется только локальная копия
}

int a = 10;
foo(a);              // a остаётся 10
```

Особенности:
- Для примитивных типов (`int`, `double`, указатели) — дёшево.
- Для больших объектов (например, `std::string`, `std::vector`) — дорого: вызывается конструктор копирования.
- Копия создаётся всегда, даже если объект не изменяется (если не применена оптимизация).

## 2. Передача по ссылке (by reference)

Параметр — это **псевдоним** (алиас) исходного аргумента. Функция напрямую работает с оригиналом.

```cpp
void foo(int& x) {
    x = 42;          // изменяется оригинал
}

int a = 10;
foo(a);              // a теперь 42
```

Особенности:
- Нет копирования — эффективно для больших объектов.
- Позволяет функции изменять аргумент.
- Нельзя передать временный объект (rvalue) или литерал в неконстантную ссылку.

### Константная ссылка (`const T&`)

Используется, когда нужно избежать копирования, но не нужно менять аргумент:

```cpp
void print(const std::string& s) {
    std::cout << s;   // копирования нет, изменение запрещено
}
```

Это стандартный способ передавать «тяжёлые» объекты только для чтения. Также `const T&` может связываться с временными объектами (rvalue), продлевая их время жизни на время вызова.

### Rvalue-ссылка (`T&&`)

Появилась в C++11 для семантики перемещения и идеальной передачи (perfect forwarding):

```cpp
void take(std::string&& s) {
    // s — ссылка на временный объект, можно "переместить" ресурсы
}

take(std::string("hello"));  // OK
```

Широко используется в шаблонах совместно с `std::forward`.

## 3. Передача по указателю (by pointer)

Передаётся **адрес** аргумента. Функция может изменить объект через разыменование.

```cpp
void foo(int* p) {
    if (p) *p = 42;
}

int a = 10;
foo(&a);             // a теперь 42
```

Особенности:
- Позволяет передать `nullptr` (сигнал «аргумента нет»).
- Требует явного взятия адреса `&` и разыменования `*`.
- В современном C++ для «обязательных» аргументов предпочитают ссылки, а указатели — когда нужна опциональность.

## 4. Передача массивов

Массив при передаче в функцию **распадается** (decay) в указатель на первый элемент:

```cpp
void foo(int arr[]) { /* arr — это int* */ }
```

Поэтому размер массива теряется. Решения:
- передавать размер отдельно;
- передавать ссылку на массив: `void foo(int (&arr)[10])`;
- использовать `std::array` или `std::span` (C++20).

## 5. Передача функций и лямбд

- Указатель на функцию: `void foo(void (*f)(int))`.
- `std::function` — универсальная обёртка (с накладными расходами).
- Шаблонный параметр `template<class F> void foo(F&& f)` — самый эффективный, без стирания типа.

## 6. Механизм на уровне ABI (кратко)

С точки зрения вызывающего кода (calling convention):
- Аргументы передаются через **регистры** (например, System V AMD64: RDI, RSI, RDX, RCX, R8, R9) и/или **стек**.
- Порядок и способ зависят от платформы и соглашения о вызовах (`cdecl`, `stdcall`, `fastcall`, `thiscall` для методов).
- Ссылки на уровне ABI обычно реализуются как указатели.
- Возврат больших объектов может осуществляться через скрытый указатель на память результата (RVO/NRVO оптимизируют это).

## 7. Параметры по умолчанию и вариативные функции

- Параметры по умолчанию: `void foo(int x = 0);` — подставляются на этапе компиляции.
- Вариативные функции C-стиля (`...`) — `va_list`, `va_start` и т.д.; в C++ предпочтительнее шаблоны с `variadic templates` или `std::initializer_list`.

## Сводная таблица

| Способ | Копирование | Может менять | Принимает rvalue | Когда использовать |
|---|---|---|---|---|
| `T` (значение) | да | нет (свою копию) | да | примитивы, маленькие объекты |
| `T&` | нет | да | нет | нужно изменить аргумент |
| `const T&` | нет | нет | да | «тяжёлые» объекты только для чтения |
| `T&&` | нет | да (перемещение) | да | семантика перемещения, forwarding |
| `T*` | нет (копируется адрес) | да (через `*`) | да (адрес rvalue — редко) | опциональный аргумент, C-интерфейсы |

**Практическое правило:** примитивы — по значению; большие объекты для чтения — `const T&`; для изменения — `T&`; для перемещения и шаблонов — `T&&` с `std::forward`; указатель — когда нужна опциональность или совместимость с C.
