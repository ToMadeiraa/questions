# 60. Что такое специализация шаблона?

**Специализация шаблона (template specialization)** — это механизм в C++, позволяющий предоставить собственную реализацию шаблона (класса, функции или переменной, начиная с C++14) для конкретного набора аргументов шаблона, вместо использования общего (первичного) шаблона . Это даёт возможность оптимизировать код, обрабатывать особые случаи или изменять поведение для определённых типов.

В C++ существует два основных вида специализации: **явная (полная)** и **частичная**.

### 1. Явная (полная) специализация

Полная специализация определяет конкретную реализацию для **всех** аргументов шаблона. Она объявляется с помощью пустого списка параметров `template<>`.

**Синтаксис и применение:**
Полностью специализировать можно шаблоны функций, классов, а также (начиная с C++14) шаблоны переменных. Кроме того, можно специализировать отдельные члены шаблонного класса (функции-члены, статические данные, вложенные классы) .

**Пример для шаблона класса:**
```cpp
// Первичный шаблон
template <typename T>
struct Formatter {
    void print(T value) { /* ... */ }
};

// Явная (полная) специализация для типа char*
template <>
struct Formatter<char*> {
    void print(char* value) { /* ... */ } // Другая реализация
};
```
В этом примере при использовании `Formatter<int>` будет выбран первичный шаблон, а при `Formatter<char*>` — специализированная версия .

**Пример для шаблона функции:**
```cpp
template <typename T>
void swap(T& a, T& b) { /* ... */ }

// Явная специализация для double
template <>
void swap<double>(double& a, double& b) {
    // Специальная логика для double
}
```

**Важные правила:**
*   Специализация должна быть объявлена в той же области видимости (обычно в том же пространстве имён), что и первичный шаблон .
*   Она должна быть объявлена **до** первого использования, которое могло бы вызвать неявную инстанциацию шаблона .
*   Явная специализация функции не является `inline` по умолчанию, если только она не объявлена таковой явно, независимо от того, был ли `inline` первичный шаблон .

### 2. Частичная специализация

Частичная специализация позволяет специализировать шаблон **не для всех**, а лишь для некоторых аргументов или для целого класса типов (например, для всех указателей). Она применима **только к шаблонам классов** (и переменных, начиная с C++14), но не к шаблонам функций .

**Пример (специализация для указателей):**
```cpp
// Первичный шаблон
template <typename T>
class Storage { /* ... */ };

// Частичная специализация для любых указателей T*
template <typename T>
class Storage<T*> {
    // Специальная реализация для указателей
};
```
Здесь `Storage<int*>` или `Storage<MyClass*>` будут использовать частичную специализацию, а `Storage<int>` — первичный шаблон .

**Пример (специализация по одному из нескольких параметров):**
```cpp
template <typename Key, typename Value>
class Map { /* ... */ };

// Частичная специализация, где ключ всегда int
template <typename Value>
class Map<int, Value> {
    // Специальная реализация
};
```

**Ограничения частичной специализации:**
*   Список аргументов частичной специализации не может быть идентичен списку аргументов первичного шаблона (она должна что-то специализировать) .
*   В списке аргументов нельзя использовать аргументы по умолчанию .

### Зачем нужна специализация?

1.  **Оптимизация производительности:** Например, стандартная библиотека использует специализацию `std::vector<bool>` для компактного хранения битов, что отличается от общей реализации для других типов.
2.  **Семантические различия:** Для указателей (`T*`) часто требуется особая логика (например, разыменование перед копированием), которую нельзя или неэффективно выразить в общем шаблоне .
3.  **Обработка особых случаев:** Когда для конкретного типа (например, `void` или `char*`) требуется совершенно иной набор операций или членов данных, чем для остальных .
