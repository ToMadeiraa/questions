# 8. Что такое операционная система? Какие существуют типы по назначению?

## Что такое операционная система

**Операционная система (ОС)** — это комплекс системного программного обеспечения, который предоставляет программам доступ к аппаратным ресурсам компьютера и управляет этими ресурсами. ОС выступает посредником между прикладным программным обеспечением и «железом», а также между пользователем и компьютером.

Основные функции ОС:

- **Управление процессами** — планирование выполнения задач, многозадачность, синхронизация, межпроцессное взаимодействие.
- **Управление памятью** — выделение и освобождение оперативной памяти, виртуальная память, защита адресных пространств процессов.
- **Управление файловой системой** — организация хранения данных, операции с файлами и каталогами.
- **Управление устройствами ввода-вывода** — драйверы, буферизация, разделение доступа к устройствам.
- **Управление пользователями и правами доступа** — аутентификация, разграничение полномочий.
- **Предоставление интерфейса** — командная строка (shell) и/или графический интерфейс.
- **Сетевое взаимодействие** — реализация сетевых протоколов, сокетов.

С точки зрения программиста на C++, ОС — это, прежде всего, **набор системных вызовов (API)**, через которые программа взаимодействует с окружением: создание потоков (`std::thread`, `pthread_create`), работа с файлами (`fopen`, `std::fstream`), выделение памяти (`malloc`/`new` → `brk`/`mmap`), синхронизация (`mutex`, `semaphore`), сеть (`socket`, `connect`). Стандартная библиотека C++ (STL, `<thread>`, `<filesystem>`, `<memory>`) сама по себе не работает с железом — она опирается на эти системные вызовы, которые предоставляет конкретная ОС (Linux, Windows, macOS и т.д.).

## Типы ОС по назначению

Классификация по назначению (сфере применения):

1. **ОС общего назначения (универсальные)** — для персональных компьютеров, рабочих станций и серверов. Поддерживают широкий спектр приложений, многозадачность, многопользовательский режим. Примеры: Windows, Linux (Ubuntu, Fedora), macOS, FreeBSD. Именно с ними чаще всего имеет дело разработчик на C++.

2. **ОС реального времени (RTOS)** — гарантируют предсказуемое время реакции на события (жёсткое или мягкое реальное время). Используются во встроенных системах, робототехнике, промышленной автоматизации, авионике. Примеры: FreeRTOS, VxWorks, QNX, Zephyr, RT-Thread. При разработке на C++ здесь важны детерминированность, отсутствие непредсказуемых задержек, часто — ограничения на динамическое выделение памяти и исключения.

3. **Встроенные (embedded) ОС** — ориентированы на работу с ограниченными ресурсами (микроконтроллеры, IoT-устройства). Часто совмещают функции с RTOS или являются специализированными ядрами. Примеры: Embedded Linux, FreeRTOS, Contiki, Mbed OS.

4. **Серверные ОС** — оптимизированы под высокую нагрузку, сетевые сервисы, масштабирование, виртуализацию, надёжность. Примеры: серверные редакции Windows Server, Linux-дистрибутивы (RHEL, Debian, CentOS), FreeBSD, Solaris.

5. **Мобильные ОС** — для смартфонов и планшетов; акцент на энергоэффективность, сенсорный ввод, управление памятью в условиях ограничений. Примеры: Android, iOS.

6. **Сетевые ОС** — основная задача — предоставление сетевых сервисов и совместное использование ресурсов (файлов, принтеров) в сети. Примеры: Novell NetWare (исторически), серверные редакции Windows и Linux с сетевыми службами.

7. **ОС для суперкомпьютеров и кластеров** — поддержка массового параллелизма, высокоскоростных interconnect, специализированных планировщиков и файловых систем. Примеры: Linux-дистрибутивы для HPC (например, Cray OS на базе Linux).

8. **ОС для специализированных устройств** — например, для маршрутизаторов и телекоммуникационного оборудования (Cisco IOS, Junos), для игровых консолей, для бортовых систем автомобилей (AUTOSAR OS).

9. **Учебные и исследовательские ОС** — создаются для изучения принципов построения ОС (MINIX, xv6, Nachos). Полезны как примеры для понимания того, как устроены системные вызовы, с которыми взаимодействует код на C++.

Дополнительно ОС различают по другим признакам: по числу пользователей (одно- и многопользовательские), по режиму обработки (пакетные, разделения времени, реального времени), по архитектуре ядра (монолитные, микроядерные, гибридные) — но это уже не классификация «по назначению».

В контексте C++ важно понимать: переносимость кода обеспечивается за счёт стандартной библиотеки и абстракций (например, `std::filesystem`, `std::thread`), однако многие возможности (сигналы POSIX, `epoll`/`io_uring` в Linux, IOCP в Windows, API реального времени) являются платформенно-зависимыми и требуют знания целевой ОС и её типа.
