# 43. Что такое конструктор по умолчанию? Для чего нужны default и delete?

**Конструктор по умолчанию** — это конструктор, который можно вызвать без аргументов. Он либо вообще не имеет параметров, либо все его параметры имеют аргументы по умолчанию . Такой конструктор вызывается при инициализации по умолчанию и инициализации значением .

Если в классе не объявлен ни один конструктор, компилятор неявно объявляет и определяет конструктор по умолчанию. Однако если вы объявили хотя бы один конструктор с параметрами, компилятор перестаёт генерировать конструктор по умолчанию автоматически .

### Ключевое слово `default`

Спецификатор `= default` (начиная с C++11) явно указывает компилятору сгенерировать реализацию специальной функции-члена по умолчанию, даже если в классе уже есть другие конструкторы .

Это полезно в ситуациях, когда вы хотите сохранить возможность создания объекта без аргументов, но при этом объявили другие конструкторы. Например:

```cpp
class MyClass {
public:
    MyClass(int x);           // Пользовательский конструктор
    MyClass() = default;      // Явно требуем сгенерировать конструктор по умолчанию
};
```

Без `= default` компилятор не создал бы конструктор по умолчанию, так как есть пользовательский конструктор `MyClass(int)`.

### Ключевое слово `delete`

Спецификатор `= delete` (начиная с C++11) используется для явного запрета использования функции. Если удалённая функция выбрана в результате разрешения перегрузки, программа не скомпилируется .

Для конструктора по умолчанию `= delete` означает, что создание объекта без аргументов запрещено. Это часто применяется для классов, которые по смыслу не должны создаваться «пустыми»:

```cpp
class NonDefaultConstructible {
public:
    NonDefaultConstructible() = delete;   // Запрещаем создание без аргументов
    NonDefaultConstructible(int value);   // Единственный способ создать объект
};
```

Кроме того, `= delete` широко используется для запрета копирования (удаление конструктора копирования и оператора присваивания), что делает тип некопируемым — это важно для классов, владеющих уникальными ресурсами (файлы, соединения, мьютексы) .

**Важное различие:** `= delete` не просто скрывает функцию — попытка её вызвать приводит к ошибке компиляции на этапе разрешения перегрузки, что делает запрет явным и диагностируемым.
