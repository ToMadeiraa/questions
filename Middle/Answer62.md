# 62. Что такое exception? Как бросить и поймать?

## Что такое исключение (exception)

**Исключение** — это механизм обработки ошибок и особых ситуаций в C++, при котором управление передаётся из точки возникновения проблемы в специальный обработчик, а не возвращается обычным способом (через `return`).

Ключевые идеи:

- Исключение «разрывает» нормальный поток выполнения. Если в функции возникло исключение и оно не поймано локально, функция завершается, и исключение распространяется вверх по стеку вызовов (**stack unwinding**) до первого подходящего `catch`.
- При раскрутке стека для всех локальных объектов вызываются деструкторы (это основа идиомы RAII).
- Исключения используются для *исключительных* ситуаций (ошибки, нехватка ресурсов), а не для обычного ветвления логики — это дорого и затрудняет чтение кода.

Стандартная иерархия: базовый класс `std::exception` (заголовок `<exception>`), от него унаследованы `std::runtime_error`, `std::logic_error`, `std::out_of_range`, `std::bad_alloc`, `std::invalid_argument` и др.

## Как бросить исключение — `throw`

```cpp
#include <stdexcept>

double divide(double a, double b) {
    if (b == 0.0)
        throw std::invalid_argument("division by zero"); // бросаем объект-исключение
    return a / b;
}
```

Правила и нюансы:

- `throw` может бросать объект **любого** копируемого типа (не только наследников `std::exception`), но на практике бросают классы, унаследованные от `std::exception`.
- Бросать принято **по значению**, а ловить — **по ссылке** (`catch (const T&)`), чтобы избежать срезки (slicing) и лишних копий.
- Не бросайте указатели на локальные объекты и «сырые» указатели вообще — владение и освобождение памяти становятся неочевидными.
- Повторный выброс текущего исключения из `catch` — `throw;` (без операнда).
- `throw` внутри деструктора опасен: если во время раскрутки стека уже активно другое исключение, повторный выброс приведёт к `std::terminate`.

## Как поймать исключение — `try` / `catch`

```cpp
#include <iostream>
#include <stdexcept>

int main() {
    try {
        std::cout << divide(10, 0) << '\n';
    }
    catch (const std::invalid_argument& e) {   // конкретный тип — первым
        std::cerr << "Ошибка аргумента: " << e.what() << '\n';
    }
    catch (const std::exception& e) {          // базовый тип — после
        std::cerr << "Общая ошибка: " << e.what() << '\n';
    }
    catch (...) {                              // поймать всё остальное
        std::cerr << "Неизвестное исключение\n";
    }
}
```

Правила и нюансы:

- `try`-блок задаёт охраняемую область; за ним следует один или несколько `catch`.
- **Порядок `catch` важен**: обработчики проверяются сверху вниз, срабатывает первый подходящий. Поэтому производные типы должны идти раньше базовых.
- `catch (...)` ловит любое исключение, но не даёт доступа к объекту — используется как «последняя линия обороны» (логирование, переброс `throw;`).
- В `catch` можно обращаться к `e.what()` (для `std::exception`), к полям пользовательских исключений.
- Если исключение не поймано нигде, вызывается `std::terminate()` (по умолчанию — аварийное завершение, часто через `abort`).

## Дополнительно: спецификация исключений

- `noexcept` — указывает, что функция не бросает исключений; если всё же бросит — `std::terminate`. Важен для оптимизаций и корректной работы move-семантики (перемещающий конструктор/присваивание обычно помечают `noexcept`).
- Динамическая спецификация `throw(T1, T2)` устарела (deprecated в C++11, удалена в C++20) — используйте `noexcept`.

## Мини-пример с пользовательским исключением

```cpp
#include <stdexcept>
#include <string>

class MyError : public std::runtime_error {
public:
    explicit MyError(const std::string& msg) : std::runtime_error(msg) {}
};

void mayThrow(bool flag) {
    if (flag) throw MyError("что-то пошло не так");
}

int main() {
    try {
        mayThrow(true);
    } catch (const MyError& e) {
        // обработали конкретное исключение
    }
}
```

## Итог

| Действие | Синтаксис | Ключевые моменты |
|---|---|---|
| Бросить | `throw объект;` | бросать по значению, тип — наследник `std::exception` |
| Поймать | `try { ... } catch (const T& e) { ... }` | ловить по const-ссылке, производные — раньше базовых |
| Поймать всё | `catch (...) { throw; }` | последний обработчик, часто с перебросом |
| Не бросать | `noexcept` | иначе `std::terminate` |
