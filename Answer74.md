# 74. Что такое умный указатель? Какие умные указатели есть в стандартной библиотеке?

**Умный указатель** — это шаблон класса, инкапсулирующий «сырой» указатель и реализующий идиому **RAII** (Resource Acquisition Is Initialization). Он автоматически управляет временем жизни объекта в куче: когда умный указатель выходит из области видимости (например, завершается функция), его деструктор автоматически вызывает `delete`, освобождая память, что предотвращает утечки памяти и обеспечивает безопасность при исключениях .

В стандартной библиотеке C++ (начиная с C++11) умные указатели определены в заголовочном файле `<memory>` и пространстве имен `std`. Основные из них:

| Умный указатель | Семантика владения | Ключевые особенности |
| :--- | :--- | :--- |
| **`std::unique_ptr`** | Эксклюзивное владение | Один объект может принадлежать только одному `unique_ptr`. Копирование запрещено, разрешено только перемещение (`std::move`). Минимальные накладные расходы, предпочтительный выбор по умолчанию . |
| **`std::shared_ptr`** | Разделяемое владение | Несколько `shared_ptr` могут совместно владеть одним объектом. Внутри поддерживается счетчик ссылок, объект уничтожается, когда счетчик достигает нуля. Имеет дополнительные накладные расходы (счетчик ссылок) . |
| **`std::weak_ptr`** | Невладеющая ссылка | Указывает на объект, управляемый `shared_ptr`, но **не увеличивает** счетчик ссылок. Используется для предотвращения циклических ссылок (например, взаимных ссылок между родительским и дочерним объектами) или для проверки существования объекта . |

> **Примечание**: `std::auto_ptr` был объявлен устаревшим в C++11 и удален в C++17; в новом коде его использовать не следует .
