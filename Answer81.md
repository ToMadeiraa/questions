# 81. Перегрузка функций в C++

## Определение

**Перегрузка функций (function overloading)** — это возможность в C++ иметь несколько функций с **одинаковым именем**, но **разными списками параметров** (сигнатурами). Компилятор выбирает нужную версию функции на этапе компиляции на основе количества и типов переданных аргументов.

```cpp
int add(int a, int b)         { return a + b; }
double add(double a, double b) { return a + b; }
```

При вызове `add(2, 3)` вызовется первая версия, при `add(2.5, 3.1)` — вторая.

## Что входит в сигнатуру функции

При перегрузке различие должно быть в **сигнатуре**, то есть в:

- **количестве параметров**;
- **типах параметров**;
- **порядке типов параметров**;
- **квалификаторах параметров** (`const`, `volatile`, ссылки, указатели);
- для методов класса — также в **квалификаторах самого метода** (`const`, `volatile`, `&`, `&&`, `noexcept`).

## Виды перегрузки

### 1. По количеству параметров

```cpp
void print(int a) {}
void print(int a, int b) {}
```

### 2. По типам параметров

```cpp
void show(int x)    {}
void show(double x) {}
void show(const char* s) {}
```

### 3. По порядку типов параметров

```cpp
void f(int, double)  {}
void f(double, int)  {}
```

### 4. По квалификаторам (const/volatile, ссылки, указатели)

```cpp
void g(int& x)              {}
void g(const int& x)        {}
void g(int* x)              {}
```

```cpp
void h(int&& x) {}   // rvalue-ссылка
void h(int& x)  {}   // lvalue-ссылка
```

### 5. Перегрузка методов класса по `const`

```cpp
class A {
public:
    void method()       { /* для неконстантных объектов */ }
    void method() const { /* для константных объектов     */ }
};
```

### 6. Перегрузка операторов

Отдельный вид перегрузки, где имя функции — это `operator@`:

```cpp
class Vec {
public:
    Vec operator+(const Vec& other) const; // перегрузка оператора +
    bool operator==(const Vec& other) const;
};
```

### 7. Перегрузка шаблонных функций

```cpp
template<typename T>
T max(T a, T b) { return a > b ? a : b; }

int  max(int a, int b)        { return a > b ? a : b; }      // нешаблонная
char max(char a, char b)      { return a > b ? a : b; }      // специализация
```

### 8. Перегрузка конструкторов класса

```cpp
class Point {
public:
    Point()                 : x_(0), y_(0) {}
    Point(int x, int y)     : x_(x), y_(y) {}
    Point(const Point& p)   : x_(p.x_), y_(p.y_) {}
};
```

## Что НЕ является перегрузкой (нельзя перегружать только этим)

Функции **нельзя** перегружать только по:

- **типу возвращаемого значения**:
  ```cpp
  int  f(int);       // ошибка компиляции
  double f(int);     // ошибка компиляции — та же сигнатура
  ```
- **именам параметров**;
- **значениям по умолчанию**:
  ```cpp
  void f(int a);
  void f(int a = 0); // ошибка — неоднозначность при вызове f()
  ```
- **спецификатору `inline` / `static`** (для свободных функций).

## Разрешение перегрузки (overload resolution)

Компилятор выбирает функцию по трём шагам:

1. **Точное совпадение** типов аргументов.
2. **Совпадение с приведением типов** (promotion — например, `char` → `int`, `float` → `double`).
3. **Совпадение с пользовательскими/стандартными преобразованиями** (например, через конструктор с одним аргументом).

Если найдено несколько равнозначных кандидатов — возникает ошибка **неоднозначности (ambiguity)**:

```cpp
void f(long);
void f(double);
f(42);   // ошибка: неоднозначно
```

## Пример: полный

```cpp
#include <iostream>
#include <string>

class Calculator {
public:
    int    sum(int a, int b)             { return a + b; }
    double sum(double a, double b)       { return a + b; }
    int    sum(int a, int b, int c)      { return a + b + c; }

    std::string sum(const std::string& a, const std::string& b) {
        return a + b;
    }

    void show()       { std::cout << "mutable\n"; }
    void show() const { std::cout << "const\n";   }
};

int main() {
    Calculator c;
    const Calculator cc;

    std::cout << c.sum(2, 3)                 << '\n'; // 5
    std::cout << c.sum(2.5, 3.5)             << '\n'; // 6.0
    std::cout << c.sum(1, 2, 3)              << '\n'; // 6
    std::cout << c.sum("Hello, ", "World!")  << '\n'; // Hello, World!
    c.show();   // mutable
    cc.show();  // const
}
```

## Кратко для ответа

> Перегрузка функций — это механизм C++, позволяющий объявлять несколько функций с одним именем, но разными сигнатурами. Виды перегрузки: по числу параметров, по их типам, по порядку типов, по квалификаторам (`const`/`volatile`/ссылки/указатели), перегрузка методов класса по `const`, перегрузка операторов, шаблонные перегрузки и перегрузка конструкторов. Нельзя перегружать только по типу возвращаемого значения или именам параметров; разрешение перегрузки выполняется компилятором на этапе компиляции с учётом точных совпадений и преобразований типов.
