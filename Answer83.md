# 83. Инициализация переменной в `if` (C++17)

Начиная со стандарта **C++17**, в языке появилась возможность объявлять и инициализировать переменную прямо в заголовке оператора `if` (а также `switch`). Эта конструкция называется **if statement with initializer** (оператор `if` с инициализатором).

## Синтаксис

```cpp
if (init-statement; condition) {
    // тело if
} else {
    // тело else
}
```

Здесь `init-statement` — это объявление переменной (или несколько объявлений через запятую), а `condition` — обычное условие, которое может использовать эту переменную.

## Простой пример

```cpp
#include <iostream>
#include <map>

int main() {
    std::map<std::string, int> m = {{"one", 1}, {"two", 2}};

    if (auto it = m.find("one"); it != m.end()) {
        std::cout << "Найдено: " << it->second << '\n';
    } else {
        std::cout << "Не найдено\n";
    }
    // переменная it здесь уже недоступна
}
```

Переменная `it` объявлена в области видимости самого оператора `if` (включая ветки `if` и `else`), но **не видна** после его завершения. Это позволяет избежать засорения внешней области видимости «временными» переменными.

## Зачем это нужно

### 1. Ограничение области видимости

До C++17 приходилось либо объявлять переменную снаружи:

```cpp
// Старый способ — переменная «живёт» дольше, чем нужно
auto it = m.find("one");
if (it != m.end()) {
    // ...
}
// it всё ещё существует здесь, хотя уже не нужна
```

…либо использовать дополнительный блок `{ }`:

```cpp
{
    auto it = m.find("one");
    if (it != m.end()) {
        // ...
    }
}
```

Конструкция `if (init; cond)` решает эту задачу элегантнее и компактнее.

### 2. Удобство для блокировок и RAII

Классический пример — блокировка мьютекса, которая должна существовать ровно на время выполнения условного блока:

```cpp
std::mutex mtx;
std::map<int, int> data;

if (std::lock_guard<std::mutex> lock(mtx); !data.empty()) {
    // работаем с data под защитой мьютекса
}
// мьютекс освобождён здесь
```

### 3. Проверка и использование значения в одном месте

```cpp
if (int x = compute(); x > 0) {
    std::cout << "x положителен: " << x << '\n';
} else {
    std::cout << "x не положителен: " << x << '\n';
}
```

Обратите внимание: в ветке `else` переменная `x` тоже доступна (но её значение — это уже вычисленный результат `compute()`).

## Важные детали

- **Стандарт:** конструкция появилась в **C++17**. В C++14 и более ранних версиях она не компилируется.
- **Область видимости:** переменная из `init-statement` видна в `condition`, в теле `if` и в ветке `else`, но не после оператора.
- **Тип `condition`:** условие по-прежнему должно приводиться к `bool`. Если в `init-statement` объявлена переменная, её значение **не** используется как условие автоматически — условие задаётся отдельно после точки с запятой. (Для сравнения: в `if (int x = f())` без точки с запятой — это уже не C++17-инициализатор, а условие с неявным преобразованием к `bool`.)
- **Несколько объявлений:** можно объявлять несколько переменных, но только одного типа:

```cpp
if (int a = 1, b = 2; a < b) {
    // ...
}
```

- **Аналогично для `switch`:** в C++17 появился и `switch` с инициализатором:

```cpp
switch (auto x = get_value(); x) {
    case 1: /* ... */ break;
    default: /* ... */ break;
}
```

## Итог

Инициализация переменной в `if` — это синтаксическая возможность C++17, позволяющая объявить переменную прямо в заголовке `if`, использовать её в условии и теле, и автоматически ограничить её область видимости самим оператором. Это делает код компактнее, безопаснее (меньше «висящих» переменных) и особенно удобно при работе с итераторами, блокировками и функциями, возвращающими значение для проверки.
