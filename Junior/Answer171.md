# 171. Напишите реализацию функции int atoi (const char *str); преобразования строки в число.

## Описание функции

`atoi` (ASCII to Integer) преобразует строку в целое число типа `int`. Поведение стандартной функции из `<cstdlib>`:

1. Пропускает ведущие пробельные символы (пробел, `\t`, `\n`, `\v`, `\f`, `\r`).
2. Распознаёт необязательный знак `+` или `-`.
3. Читает последовательность десятичных цифр до первого нецифрового символа.
4. Если цифр после знака нет — возвращает `0`.
5. Результат приводится к `int`; поведение при переполнении не определено стандартом (на практике — обрезание/насыщение).

## Реализация

```cpp
#include <climits>

int atoi(const char* str) {
    if (str == nullptr) {
        return 0;
    }

    // 1. Пропуск ведущих пробельных символов
    while (*str == ' '  || *str == '\t' || *str == '\n' ||
           *str == '\v' || *str == '\f' || *str == '\r') {
        ++str;
    }

    // 2. Обработка знака
    int sign = 1;
    if (*str == '+' || *str == '-') {
        if (*str == '-') {
            sign = -1;
        }
        ++str;
    }

    // 3. Накопление цифр
    long long result = 0;          // используем широкий тип для контроля переполнения
    while (*str >= '0' && *str <= '9') {
        result = result * 10 + (*str - '0');
        ++str;

        // Защита от переполнения int (насыщение, как делают многие реализации)
        if (sign == 1  && result >  INT_MAX) return INT_MAX;
        if (sign == -1 && result > -(long long)INT_MIN) return INT_MIN;
    }

    // 4. Применение знака
    return static_cast<int>(sign * result);
}
```

## Пояснения к реализации

- **`nullptr`-проверка** — хотя стандартная `atoi` не определена для `nullptr`, добавление проверки делает функцию безопаснее.
- **Пропуск пробелов** — используем явное перечисление символов из стандарта C (`' '`, `'\t'`, `'\n'`, `'\v'`, `'\f'`, `'\r'`) вместо `isspace`, чтобы избежать зависимости от локали.
- **Знак** — обрабатывается отдельно, что позволяет корректно работать с `INT_MIN` (у которого нет положительного аналога в `int`).
- **Накопление в `long long`** — позволяет обнаружить переполнение `int` и вернуть `INT_MAX`/`INT_MIN` (поведение, аналогичное `strtol` и большинству реальных реализаций `atoi`).
- **Условие `*str - '0'`** — стандартный приём преобразования символа-цифры в число.

## Альтернативный компактный вариант (без контроля переполнения)

Если контроль переполнения не требуется (как в учебных заданиях), функция может выглядеть так:

```cpp
int atoi(const char* str) {
    int sign = 1;
    int result = 0;

    while (*str == ' ') ++str;                // только пробелы

    if (*str == '-' || *str == '+') {
        sign = (*str == '-') ? -1 : 1;
        ++str;
    }

    while (*str >= '0' && *str <= '9') {
        result = result * 10 + (*str - '0');
        ++str;
    }

    return sign * result;
}
```

## Пример использования

```cpp
#include <iostream>

int main() {
    std::cout << atoi("   -12345abc") << '\n'; // -12345
    std::cout << atoi("+42")         << '\n'; // 42
    std::cout << atoi("abc")         << '\n'; // 0
    std::cout << atoi("   ")         << '\n'; // 0
    std::cout << atoi("-")           << '\n'; // 0
    return 0;
}
```
