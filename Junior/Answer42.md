# Вопрос 42. Какие алгоритмы на графах знаете?

> **Кратко:** графовые алгоритмы делятся на обходы (BFS, DFS), поиск кратчайших путей (Дейкстра, Беллман–Форд, Флойд–Уоршелл), минимальное остовное дерево (Краскал, Прим), анализ структуры (компоненты, мосты, точки сочленения, SCC, двудольность) и топологическую сортировку. Почти все они строятся на двух идеях — обходе в ширину или в глубину, — а выбор определяется весами рёбер, наличием отрицательных весов и тем, нужны пути от одной вершины или между всеми парами.

---

## Представление графа

| Способ | Память | Проверка ребра | Обход соседей | Когда использовать |
|---|---|---|---|---|
| Матрица смежности | `O(V²)` | `O(1)` | `O(V)` | плотные графы, `V` до тысяч |
| Список смежности | `O(V + E)` | `O(deg)` | `O(deg)` | разреженные графы — основной случай |
| Список рёбер | `O(E)` | `O(E)` | — | алгоритмы, которым нужны только рёбра (Краскал) |

---

## Обходы: BFS и DFS

**BFS** идёт «волнами» от источника и находит кратчайшие пути в графе без весов за `O(V + E)`. **DFS** уходит вглубь и служит основой для поиска циклов, компонент, мостов и топологической сортировки.

```cpp
#include <cstddef>
#include <queue>
#include <vector>

// Кратчайшие расстояния в невзвешенном графе; -1 — вершина недостижима
std::vector<int> bfsDistances(const std::vector<std::vector<int>>& g, int src) {
    std::vector<int> dist(g.size(), -1);
    std::queue<int> q;
    dist[static_cast<std::size_t>(src)] = 0;
    q.push(src);
    while (!q.empty()) {
        const int v = q.front();
        q.pop();
        for (int to : g[static_cast<std::size_t>(v)]) {
            if (dist[static_cast<std::size_t>(to)] != -1) continue;
            dist[static_cast<std::size_t>(to)] = dist[static_cast<std::size_t>(v)] + 1;
            q.push(to);                    // метка ставится при постановке в очередь
        }
    }
    return dist;
}
```

DFS пишут рекурсивно (компактно, но глубина `V` может переполнить стек) или итеративно с явным `std::vector<int>` в роли стека. Рекурсия на 10⁵ вершинах, вытянутых в цепочку, — реальный риск падения.

## Топологическая сортировка

Нужна для ориентированного ациклического графа (DAG): порядок, в котором вершина идёт раньше всех своих потомков. Применяется для зависимостей сборки, планирования, порядка вычислений.

**Алгоритм Кана**: считаем входящие степени, в очередь кладём вершины с нулевой степенью, а извлекая вершину, уменьшаем степени её соседей. Если после обхода обработаны не все вершины, в графе есть цикл. Альтернатива — DFS с добавлением вершины в конец после обработки потомков (обратный порядок выхода). Оба варианта работают за `O(V + E)`.

---

## Кратчайшие пути

| Алгоритм | Веса | Сложность | Особенности |
|---|---|---|---|
| BFS | без весов | `O(V + E)` | минимальное число рёбер |
| 0-1 BFS | 0 и 1 | `O(V + E)` | двусвязная очередь вместо приоритетной |
| Дейкстра | неотрицательные | `O((V + E) log V)` | основной алгоритм для одного источника |
| Беллман–Форд | любые | `O(V·E)` | находит отрицательные циклы |
| Флойд–Уоршелл | любые | `O(V³)` | все пары сразу, `V` до ~400 |
| A* | неотрицательные | зависит от эвристики | нужна допустимая (не переоценивающая) эвристика |

## Дейкстра

Жадный алгоритм: каждый раз окончательно фиксируется ближайшая недостигнутая вершина. С двоичной кучей — `O((V + E) log V)`.

```cpp
// требуются <vector>, <queue>, <functional>, <limits>, <utility>
using Weight = long long;
constexpr Weight INF = std::numeric_limits<Weight>::max() / 2;

std::vector<Weight> dijkstra(const std::vector<std::vector<std::pair<int, Weight>>>& g,
                             int src) {
    using Item = std::pair<Weight, int>;            // {расстояние, вершина}
    std::vector<Weight> dist(g.size(), INF);
    std::priority_queue<Item, std::vector<Item>, std::greater<Item>> pq;   // min-heap
    dist[static_cast<std::size_t>(src)] = 0;
    pq.emplace(0, src);
    while (!pq.empty()) {
        const auto [d, v] = pq.top();
        pq.pop();
        if (d != dist[static_cast<std::size_t>(v)]) continue;   // устаревшая запись
        for (const auto& [to, w] : g[static_cast<std::size_t>(v)])
            if (const Weight nd = d + w; nd < dist[static_cast<std::size_t>(to)]) {
                dist[static_cast<std::size_t>(to)] = nd;
                pq.emplace(nd, to);         // ленивое удаление вместо decrease-key
            }
    }
    return dist;
}
```

Отрицательные рёбра ломают жадность: зафиксированное расстояние может позже уменьшиться. Для таких графов нужен Беллман–Форд, а если граф к тому же DAG — линейный проход по топологическому порядку.

## Минимальное остовное дерево

**Краскал**: сортируем рёбра по весу и добавляем очередное, если оно не образует цикл. Проверку цикла делает система непересекающихся множеств (DSU) со сжатием путей и объединением по рангу; сложность `O(E log E)`.

```cpp
#include <algorithm>
#include <numeric>
#include <vector>

struct DSU {
    std::vector<int> parent, rank;
    explicit DSU(int n) : parent(n), rank(n, 0) {
        std::iota(parent.begin(), parent.end(), 0);
    }
    int find(int v) {                       // сжатие путей
        return parent[v] == v ? v : parent[v] = find(parent[v]);
    }
    bool unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return false;           // ребро замкнуло бы цикл
        if (rank[a] < rank[b]) std::swap(a, b);
        parent[b] = a;
        if (rank[a] == rank[b]) ++rank[a];
        return true;
    }
};

struct Edge { int u, v; long long w; };

// Вес MST или -1, если граф несвязный
long long kruskal(int n, std::vector<Edge> edges) {
    std::sort(edges.begin(), edges.end(),
              [](const Edge& a, const Edge& b) { return a.w < b.w; });
    DSU dsu(n);
    long long total = 0;
    int used = 0;
    for (const auto& e : edges) {
        if (!dsu.unite(e.u, e.v)) continue;
        total += e.w;
        if (++used == n - 1) return total;  // дерево построено
    }
    return used == n - 1 ? total : -1;
}
```

**Прим** растёт из одной вершины, добавляя минимальное ребро до ещё не включённой; с двоичной кучей — `O(E log V)`. Краскал удобнее на разреженных графах, Прим — на плотных.

## Другие задачи

| Задача | Алгоритм | Сложность |
|---|---|---|
| Компоненты связности | BFS/DFS или DSU | `O(V + E)` |
| Обнаружение цикла | DFS с цветами (белый/серый/чёрный) | `O(V + E)` |
| Двудольность | BFS с раскраской в два цвета | `O(V + E)` |
| Мосты и точки сочленения | DFS с `tin`/`low` | `O(V + E)` |
| Компоненты сильной связности | Косарайю (два DFS) или Тарьян | `O(V + E)` |
| LCA (наименьший общий предок) | бинарный подъём, Эйлер + RMQ | `O(log V)` / `O(1)` |
| Максимальный поток | Диниц, Эдмондс–Карп | `O(V²E)` / `O(VE²)` |
| Паросочетание в двудольном | Куна, Хопкрофт–Карп | `O(VE)` / `O(E√V)` |

## Типичные ошибки

1. **Метка посещения в BFS ставится при извлечении**, а не при добавлении — вершина попадает в очередь многократно.
2. **Дейкстра на графе с отрицательными рёбрами** — неверный ответ без предупреждения.
3. **Переполнение `INF`**: `INF + w` уходит в минус при `int`; брать `max/2` или `long long`.
4. **Рекурсивный DFS на глубоком графе** — переполнение стека; нужен итеративный обход.
5. **Забыть про несвязность**: один запуск обхода не покрывает все вершины, нужен цикл по всем.
6. **Неориентированное ребро добавлено только в одну сторону** — половина графа теряется.
7. **Краскал без DSU** (проверка цикла обходом) — `O(E·V)` вместо `O(E log E)`.

---

## Что добавить на собеседовании

- Выбор алгоритма — это в первую очередь вопрос о весах: без весов BFS, неотрицательные — Дейкстра, любые — Беллман–Форд или Флойд–Уоршелл.
- «Ленивое» удаление из кучи в Дейкстре заменяет `decrease-key` и упрощает код без потери асимптотики.
- Показать практическую сторону: `O(V + E)` против `O(V²)` на разреженном графе с миллионом рёбер — это разница в реальном времени работы.
- Назвать прикладные задачи: зависимости сборки (топологическая сортировка), маршрутизация (Дейкстра/A*), кластеризация (MST), сети (потоки).

## Итог

| Группа | Ключевой алгоритм | Когда применять |
|---|---|---|
| Обход | BFS / DFS | достижимость, компоненты, путь без весов |
| Порядок | топологическая сортировка (Кан) | зависимости в DAG, обнаружение цикла |
| Один источник | Дейкстра | неотрицательные веса, разреженный граф |
| Общий случай | Беллман–Форд | отрицательные веса, поиск отрицательного цикла |
| Все пары | Флойд–Уоршелл | небольшой граф, нужны все расстояния |
| Остов | Краскал / Прим | минимальная стоимость связывания |
| Структура | мосты, SCC, двудольность | анализ связности и устойчивости графа |
