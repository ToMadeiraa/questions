# Вопрос 24. Какие знаете команды препроцессора?

> **Кратко:** Команды препроцессора называются директивами: они начинаются с `#`, занимают одну логическую строку и не требуют точки с запятой. Их немного, и они делятся на четыре группы: включение файлов (`#include`), определение макросов (`#define`, `#undef`), условная компиляция (`#if`, `#ifdef`, `#ifndef`, `#elif`, `#else`, `#endif`) и служебные (`#pragma`, `#error`, `#warning`, `#line`). Плюс внутри директив работают операторы `defined`, `#` и `##`.

---

## Формально: что считается директивой

- `#` — первый непробельный символ логической строки (пробелы перед ним допустимы); физические строки склеиваются обратным слешем в конце;
- строка с одной лишь `#` — нулевая (пустая) директива, она ничего не делает;
- всё, что не начинается с `#`, — обычный текст, в котором раскрываются макросы.

```cpp
#define SUM(a, b) \
    ((a) + (b))        // продолжение директивы на следующей строке
```

---

## Полный перечень директив

| Директива | Назначение | Статус |
|---|---|---|
| `#include` | текстовая вставка файла | стандарт |
| `#define` | определить объектный или функциональный макрос | стандарт |
| `#undef` | снять определение макроса | стандарт |
| `#if` | ветвление по целочисленному константному выражению | стандарт |
| `#ifdef` / `#ifndef` | проверка, определён ли макрос | стандарт |
| `#elif` | иначе-если в цепочке условий | стандарт |
| `#elifdef` / `#elifndef` | сокращение для `#elif defined(...)` | C++23 |
| `#else` / `#endif` | закрытие ветвей и блока условия | стандарт |
| `#error` | принудительная ошибка компиляции с сообщением | стандарт |
| `#warning` | предупреждение с сообщением | C++23 (раньше — расширение) |
| `#line` | подменить номер строки и имя файла для диагностики | стандарт |
| `#pragma` | реализационно-зависимая подсказка компилятору | стандарт (эффект — нет) |
| `_Pragma("...")` | оператор: `#pragma` внутри макроса | стандарт C99/C++11 |
| `#import` | включение ровно один раз | расширение (MSVC, GCC для Obj-C) |
| `#include_next` | продолжить поиск со следующего каталога | расширение GCC/Clang |
| `#assert` / `#ident` | проверка и строка версии в объектном файле | расширение GCC |

> `#pragma once` стандартом **не является**, но поддерживается практически всеми компиляторами — подробнее в вопросе о защите заголовков.

---

## `#include`: две формы

| Форма | Порядок поиска (типичный) |
|---|---|
| `#include "file.h"` | каталог текущего файла → каталоги `-iquote` → `-I` → системные |
| `#include <file.h>` | только каталоги `-I` → системные |

Ищется именно **файл**, а не «модуль»: это текстовая вставка, а не импорт сущностей (механика — в отдельном вопросе).

---

## `#define` и `#undef`

```cpp
#define BUFFER_SIZE 4096                              // объектно-подобный: просто имя
#define MIN(a, b) ((a) < (b) ? (a) : (b))             // функционально-подобный: скобка сразу после имени

#undef BUFFER_SIZE                                    // снять определение
```

Важно: `#define MIN(a,b)` и `#define MIN (a,b)` — разные вещи. Во втором случае определено имя `MIN`, а `(a, b)` попало в тело макроса, и аргументов у него нет.

---

## Условная компиляция

```cpp
#if defined(_WIN32)
#  define PLATFORM "windows"
#elif defined(__linux__)
#  define PLATFORM "linux"
#elif defined(__APPLE__)
#  define PLATFORM "macos"
#else
#  error "unsupported platform"
#endif
```

Правила, которые часто спрашивают:

- `#if` работает только с **целыми** константами; `sizeof`, приведения и переменные недоступны;
- неопределённый идентификатор в выражении превращается в `0`;
- `defined X` и `defined(X)` эквивалентны, но `defined` — оператор, а не макрос;
- проверять надо `#ifdef FOO`, а не `#if FOO`, если макрос может быть определён без значения;
- вложенность блоков ограничена (стандарт гарантирует минимум 256 уровней).

---

## `#error` и `#warning`

```cpp
#if !defined(__cplusplus) || __cplusplus < 201703L
#  error "This header requires C++17 or newer"
#endif
```

`#error` останавливает трансляцию с сообщением — стандартный способ зафиксировать требования (версия стандарта, обязательный заголовок, неподдерживаемая платформа). `#warning` лишь печатает предупреждение; до C++23 он был расширением, поэтому в переносимом коде его прячут за `#ifdef`.

---

## `#line`

Меняет то, что подставляется в `__LINE__` и `__FILE__`, и то, что видно в диагностике — например, `#line 100 "generated.cpp"` заставит следующую строку считаться сотой. Нужна генераторам кода, чтобы сообщения указывали на исходный `.proto`/`.idl`, а не на сгенерированный `.cpp`.

---

## `#pragma` и `_Pragma`

`#pragma` передаёт компилятору команду, смысл которой определяет реализация. Наиболее употребимые:

| Прагма | Эффект |
|---|---|
| `#pragma once` | включить файл не более одного раза |
| `#pragma pack(push, 1)` / `pack(pop)` | выравнивание полей структур по 1 байту |
| `#pragma GCC diagnostic push/ignored/pop` | локально отключить предупреждения |
| `#pragma comment(lib, "ws2_32.lib")` | MSVC: прилинковать библиотеку |

`_Pragma` — оператор, потому что `#pragma` нельзя засунуть внутрь макроса: `#` в теле макроса имеет другое значение.

```cpp
#define PACK_PUSH _Pragma("pack(push, 1)")
#define PACK_POP  _Pragma("pack(pop)")
```

Неизвестная прагма игнорируется — поэтому `#pragma once` безопасно писать всегда.

---

## Операторы, доступные в директивах

| Оператор | Где | Что делает |
|---|---|---|
| `defined(X)` | `#if`, `#elif` | 1, если макрос определён |
| `#x` | тело функционального макроса | превращает аргумент в строковый литерал |
| `a ## b` | тело макроса | склеивает два токена в один |
| `__has_include(<h>)` | `#if` (C++17) | есть ли заголовок |
| `__has_cpp_attribute(a)` | `#if` (C++17) | поддерживается ли атрибут |
| `__VA_ARGS__` | тело вариадического макроса | аргументы после многоточия |
| `__VA_OPT__(x)` | C++20 | подставить `x`, если пакет непуст |

```cpp
#define STR(x) STR_IMPL(x)
#define STR_IMPL(x) #x

#if defined(__has_include)
#  if __has_include(<optional>)
#    include <optional>            // есть заголовок — включаем
#  endif
#endif
```

## Предопределённые макросы

| Макрос | Значение |
|---|---|
| `__cplusplus` | версия стандарта: `201703L`, `202002L` |
| `__FILE__` / `__LINE__` | имя файла и номер строки в точке раскрытия |
| `__DATE__` / `__TIME__` | дата и время компиляции (ломают воспроизводимость сборки) |
| `NDEBUG` | не предопределён языком; задаётся флагом `-DNDEBUG` и отключает `assert` |
| `_MSC_VER`, `__GNUC__`, `__clang__` | версии компиляторов |
| `_WIN32`, `__linux__`, `__APPLE__` | платформа |

## Типичные ошибки

1. **Ставить `;` после директивы** — `#define A 1;` подставит точку с запятой в выражение и сломает его.
2. **Пробел между именем макроса и `(`** — макрос станет объектно-подобным и не будет принимать аргументы.
3. **Использовать `#if` вместо `#ifdef`** для макросов-флагов без значения: `#if DEBUG` при пустом `#define DEBUG` — синтаксическая ошибка, а не `0`.
4. **Писать `#if defined(__has_include) && __has_include(<x>)` одной строкой** — короткое замыкание для такого оператора не гарантировано; надёжнее вложенный `#if`.
5. **Прятать за `#if` синтаксически некорректный код** и удивляться, что ошибка «исчезла»: ветвь просто не компилируется.
6. **Использовать `#define` для констант** вместо `inline constexpr` и для «функций» вместо шаблонов.

---

## Что добавить на собеседовании

- Полезно знать разницу между **директивой** и **оператором** (`defined`, `#`, `##`, `_Pragma`) — это разные уровни.
- Хороший признак — назвать стандартизацию `#warning` и `#elifdef`/`#elifndef` в C++23, появление `__has_include` (C++17) и `__VA_OPT__` (C++20), а также feature-test-макросы `__cpp_*` как стандартный способ проверять возможности компилятора.
- Финальная мысль: почти все задачи, ради которых раньше брали директивы, сегодня решаются `constexpr`, шаблонами и модулями; директивы остаются для того, что принципиально текст.

## Итог

| Группа | Директивы | Зачем |
|---|---|---|
| Включение | `#include` | собрать единицу трансляции из файлов |
| Макросы | `#define`, `#undef` | подстановка текста, константы-флаги, кодогенерация |
| Условия | `#if`, `#ifdef`, `#ifndef`, `#elif`, `#elifdef`, `#else`, `#endif` | компилировать разный код под платформу и стандарт |
| Диагностика | `#error`, `#warning`, `#line` | зафиксировать требования, поправить номера строк |
| Служебные | `#pragma`, `_Pragma` | подсказки компилятору (в т. ч. `once`, `pack`) |
| Операторы | `defined`, `#`, `##`, `__has_include` | строить и проверять макросы |
