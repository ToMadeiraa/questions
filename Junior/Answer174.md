# 174. Реализуйте бинарный поиск в массиве

## Что такое бинарный поиск

**Бинарный поиск (binary search)** — алгоритм поиска элемента в **отсортированном** массиве, работающий за время `O(log n)`. Идея: на каждом шаге сравниваем искомый элемент со средним элементом массива и отбрасываем ту половину, в которой элемент заведомо не может находиться.

**Обязательное условие:** массив должен быть отсортирован (по возрастанию для классической реализации).

## Итеративная реализация

```cpp
#include <iostream>
#include <vector>

// Возвращает индекс найденного элемента или -1, если элемент отсутствует.
int binarySearch(const std::vector<int>& arr, int target) {
    int left = 0;
    int right = static_cast<int>(arr.size()) - 1;

    while (left <= right) {
        // Защита от переполнения int: (left + right) / 2 может переполниться
        int mid = left + (right - left) / 2;

        if (arr[mid] == target) {
            return mid;            // элемент найден
        } else if (arr[mid] < target) {
            left = mid + 1;        // ищем в правой половине
        } else {
            right = mid - 1;       // ищем в левой половине
        }
    }
    return -1;                     // элемент не найден
}

int main() {
    std::vector<int> arr = {-5, -1, 0, 3, 7, 12, 25, 40, 99};
    int target = 12;

    int index = binarySearch(arr, target);
    if (index != -1)
        std::cout << "Элемент " << target << " найден по индексу " << index << "\n";
    else
        std::cout << "Элемент " << target << " не найден\n";

    return 0;
}
```

**Пояснения:**
- `left` и `right` — границы текущего диапазона поиска (включительно).
- `mid = left + (right - left) / 2` — безопасная формула середины (не переполняется, в отличие от `(left + right) / 2`).
- Цикл завершается, когда диапазон пуст (`left > right`) — значит, элемента нет.

## Рекурсивная реализация

```cpp
int binarySearchRec(const std::vector<int>& arr, int left, int right, int target) {
    if (left > right) return -1;                    // база рекурсии: не найдено

    int mid = left + (right - left) / 2;
    if (arr[mid] == target) return mid;             // база рекурсии: найдено
    if (arr[mid] < target)
        return binarySearchRec(arr, mid + 1, right, target);
    return binarySearchRec(arr, left, mid - 1, target);
}
```

Рекурсивный вариант короче, но использует стек вызовов глубиной `O(log n)`, поэтому итеративная версия предпочтительнее по памяти.

## Пример пошаговой работы

Массив: `{-5, -1, 0, 3, 7, 12, 25, 40, 99}`, ищем `12`.

| Шаг | left | right | mid | arr[mid] | Сравнение с 12 |
|-----|------|-------|-----|----------|----------------|
| 1   | 0    | 8     | 4   | 7        | 7 < 12 → left = 5 |
| 2   | 5    | 8     | 6   | 25       | 25 > 12 → right = 5 |
| 3   | 5    | 5     | 5   | 12       | найдено, индекс 5 |

## Важные нюансы

1. **Отсортированность обязательна.** Если массив не отсортирован, бинарный поиск даст неверный результат. Для сортировки можно использовать `std::sort`.
2. **Переполнение `int`.** В больших массивах `(left + right) / 2` может переполниться — используйте `left + (right - left) / 2`.
3. **Границы диапазона.** Классическая схема — включительные границы `[left, right]`, условие цикла `left <= right`, обновление `mid ± 1`. Альтернативная схема — полуинтервал `[left, right)`, условие `left < right`, обновление `right = mid`. Не смешивайте схемы — это типичная ошибка.
4. **Сложность.** Время — `O(log n)`, память — `O(1)` для итеративной версии.

## Готовое решение из STL

В стандартной библиотеке C++ есть `std::binary_search` и `std::lower_bound` / `std::upper_bound`:

```cpp
#include <algorithm>
#include <vector>

std::vector<int> arr = {1, 3, 5, 7, 9};
bool found = std::binary_search(arr.begin(), arr.end(), 5);      // true

// lower_bound вернёт итератор на первый элемент >= 5
auto it = std::lower_bound(arr.begin(), arr.end(), 5);
if (it != arr.end() && *it == 5)
    int index = static_cast<int>(it - arr.begin());              // индекс 2
```

На практике в реальном коде чаще используют именно `std::binary_search` / `std::lower_bound`, а собственную реализацию пишут на собеседованиях и в учебных заданиях — она демонстрирует понимание алгоритма.
