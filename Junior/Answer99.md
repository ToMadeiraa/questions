# 99. Наследование в C++

## Определение

**Наследование** — это механизм объектно-ориентированного программирования, позволяющий создавать новый класс (производный/дочерний) на основе существующего класса (базового/родительского), перенимая его свойства и поведение.

## Для чего используется наследование

### 1. Повторное использование кода (Code Reuse)

Наследование позволяет избежать дублирования кода: общая функциональность выносится в базовый класс, а производные классы её наследуют.

```cpp
class Animal {
public:
    void eat() { std::cout << "Eating...\n"; }
    void sleep() { std::cout << "Sleeping...\n"; }
};

class Dog : public Animal {
public:
    void bark() { std::cout << "Woof!\n"; }
};

// Dog наследует eat() и sleep(), не дублируя их
```

### 2. Моделирование иерархий реального мира

Наследование отражает отношения **«является» (is-a)** между объектами: собака — это животное, круг — это фигура, менеджер — это сотрудник.

```cpp
class Shape { /* ... */ };
class Circle : public Shape { /* ... */ };   // Круг — это фигура
class Rectangle : public Shape { /* ... */ }; // Прямоугольник — это фигура
```

### 3. Полиморфизм (динамическое поведение)

Наследование — основа **полиморфизма**: через указатель/ссылку на базовый класс можно работать с объектами разных производных классов, вызывая их переопределённые методы (виртуальные функции).

```cpp
class Shape {
public:
    virtual double area() const = 0;
    virtual ~Shape() = default;
};

class Circle : public Shape {
    double r;
public:
    Circle(double r) : r(r) {}
    double area() const override { return 3.14159 * r * r; }
};

class Square : public Shape {
    double a;
public:
    Square(double a) : a(a) {}
    double area() const override { return a * a; }
};

// Полиморфное использование:
std::vector<std::unique_ptr<Shape>> shapes;
shapes.push_back(std::make_unique<Circle>(2.0));
shapes.push_back(std::make_unique<Square>(3.0));

for (const auto& s : shapes)
    std::cout << s->area() << "\n";  // вызов нужной версии area()
```

### 4. Расширяемость и сопровождение

Наследование позволяет расширять поведение базового класса без его изменения (принцип открытости/закрытости — OCP из SOLID). Новую функциональность можно добавить через новый производный класс.

### 5. Абстракция и общие интерфейсы

Базовый класс (часто абстрактный) задаёт общий интерфейс для семейства классов. Клиентский код зависит от абстракции, а не от конкретных реализаций — это снижает связанность (coupling).

### 6. Повторное использование интерфейса

Множественное наследование (в C++) позволяет классу реализовать несколько интерфейсов (абстрактных базовых классов), комбинируя контракты.

## Виды наследования в C++

| Вид | Синтаксис | Доступ к public/protected членам базового класса в производном |
|---|---|---|
| public | `class D : public B` | public → public, protected → protected |
| protected | `class D : protected B` | public и protected → protected |
| private | `class D : private B` | public и protected → private |

## Важные замечания

- Наследование следует применять только при отношении **«является» (is-a)**, а не «имеет» (has-a) — для последнего используйте **композицию**.
- Базовый класс должен иметь **виртуальный деструктор**, если через указатель на базовый класс удаляются производные объекты.
- Злоупотребление наследованием приводит к жёсткой связанности и хрупким иерархиям; предпочтительнее «композиция вместо наследования», когда это возможно.
- В C++ есть также **виртуальное наследование**, решающее проблему «ромба» при множественном наследовании.

## Итог

Наследование используется для: **повторного использования кода**, **моделирования иерархий is-a**, **реализации полиморфизма**, **расширяемости** и **определения общих интерфейсов**. Это один из ключевых механизмов ООП в C++, но применять его следует осознанно — только там, где действительно есть отношение «является».
