# 55. Основные типы данных в C++

В C++ типы данных делятся на несколько категорий. Рассмотрим их подробно.

## 1. Целочисленные типы (integral types)

| Тип | Типичный размер | Диапазон (типично) |
|-----|-----------------|--------------------|
| `bool` | 1 байт | `true` / `false` |
| `char` | 1 байт | −128…127 или 0…255 |
| `signed char` | 1 байт | −128…127 |
| `unsigned char` | 1 байт | 0…255 |
| `short` (`short int`) | 2 байта | −32768…32767 |
| `unsigned short` | 2 байта | 0…65535 |
| `int` | обычно 4 байта | −2 147 483 648…2 147 483 647 |
| `unsigned int` | 4 байта | 0…4 294 967 295 |
| `long` | 4 или 8 байт | зависит от платформы |
| `unsigned long` | 4 или 8 байт | зависит от платформы |
| `long long` | 8 байт | −9.2·10¹⁸…9.2·10¹⁸ |
| `unsigned long long` | 8 байт | 0…1.8·10¹⁹ |

> **Важно:** размеры типов в стандарте C++ не фиксированы жёстко (кроме минимальных гарантий). Для точных размеров используйте заголовок `<cstdint>`: `int8_t`, `int16_t`, `int32_t`, `int64_t` и их беззнаковые варианты `uint8_t` и т. д.

Модификаторы: `signed`, `unsigned`, `short`, `long` могут комбинироваться с базовым `int`.

## 2. Типы с плавающей точкой (floating-point)

| Тип | Типичный размер | Точность |
|-----|-----------------|----------|
| `float` | 4 байта | ~7 значащих цифр |
| `double` | 8 байт | ~15 значащих цифр |
| `long double` | 8–16 байт | ≥ точности `double` |

Используются для дробных чисел. `double` — тип по умолчанию для литералов вида `3.14`.

## 3. Символьные типы

- `char` — базовый символьный тип (может быть знаковым или беззнаковым — зависит от реализации).
- `wchar_t` — «широкий» символ (для Unicode, размер зависит от платформы).
- `char16_t` — для UTF-16 (C++11).
- `char8_t` — для UTF-8 (C++20).

## 4. Логический тип

- `bool` — принимает значения `true` и `false`. При преобразовании в целое: `true` → 1, `false` → 0.

## 5. Перечисления (enum)

```cpp
enum Color { RED, GREEN, BLUE };          // обычное перечисление
enum class Status { OK, ERROR };          // scoped enum (C++11)
```

## 6. Указатели и ссылки

- Указатель: `int* p;` — хранит адрес объекта.
- Ссылка: `int& r = x;` — псевдоним существующего объекта.
- `nullptr_t` — тип литерала `nullptr` (C++11).

## 7. Составные (производные) типы

- **Массивы:** `int arr[10];`
- **Строки:** `std::string` (из `<string>`), C-строки `char[]`.
- **Структуры:** `struct Point { int x, y; };`
- **Объединения:** `union U { int i; float f; };`
- **Классы:** `class MyClass { ... };`

## 8. Тип `void`

Обозначает «отсутствие типа». Используется:
- как тип возвращаемого значения функции, ничего не возвращающей;
- как `void*` — указатель на «что угодно» (без типа);
- в контексте параметров.

## 9. Специальные типы (C++11 и новее)

- `auto` — автоматический вывод типа.
- `decltype(expr)` — тип выражения.
- `std::nullptr_t` — тип `nullptr`.
- `std::byte` (C++17) — байт как единица памяти.

## 10. Квалификаторы типов

- `const` — значение нельзя изменить.
- `volatile` — запрещает оптимизации, связанные с доступом к переменной.
- `constexpr` — значение известно на этапе компиляции.

### Пример использования разных типов

```cpp
#include <iostream>
#include <string>

int main() {
    int a = 42;
    double b = 3.14;
    char c = 'A';
    bool flag = true;
    std::string s = "Hello";

    int arr[3] = {1, 2, 3};
    int* p = &a;
    int& ref = a;

    std::cout << a << " " << b << " " << c << " " << flag << " " << s << "\n";
    return 0;
}
```

### Итог

Основные группы типов C++:
1. **Целочисленные** (`bool`, `char`, `short`, `int`, `long`, `long long` + модификаторы).
2. **С плавающей точкой** (`float`, `double`, `long double`).
3. **Символьные** (`char`, `wchar_t`, `char16_t`, `char8_t`).
4. **Логический** (`bool`).
5. **Перечисления** (`enum`, `enum class`).
6. **Указатели и ссылки**.
7. **Составные** (массивы, структуры, объединения, классы).
8. **`void`** и специальные типы (`auto`, `decltype`, `nullptr_t`, `std::byte`).
