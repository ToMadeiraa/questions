# 78. Передача аргументов в функции C++: по значению, по ссылке и по указателю

В C++ существует три основных способа передачи аргументов в функцию. Выбор способа влияет на производительность, безопасность и семантику программы.

## 1. Передача по значению (pass by value)

При передаче по значению в функцию копируется **само значение** аргумента. Функция работает с копией, поэтому изменения параметра внутри функции **не влияют** на исходную переменную.

```cpp
void modify(int x) {
    x = 100;  // изменяется только локальная копия
}

int main() {
    int a = 5;
    modify(a);
    // a по-прежнему равно 5
}
```

**Особенности:**
- Создаётся копия объекта (для классов вызывается конструктор копирования).
- Изменения параметра не видны вызывающей стороне.
- Подходит для небольших типов (`int`, `double`, `char`, указатели).
- Для больших объектов (например, `std::string`, `std::vector`) копирование может быть дорогим.

## 2. Передача по ссылке (pass by reference)

Параметр объявляется как ссылка (`T&`). Функция получает **псевдоним** исходной переменной, а не копию. Изменения параметра **напрямую изменяют** исходный объект.

```cpp
void modify(int& x) {
    x = 100;  // изменяется исходная переменная
}

int main() {
    int a = 5;
    modify(a);
    // a теперь равно 100
}
```

**Особенности:**
- Копирования нет — функция работает с оригиналом.
- Изменения видны вызывающей стороне.
- Ссылка не может быть «нулевой» — она всегда ссылается на существующий объект.
- Синтаксис использования внутри функции такой же, как у обычной переменной (не нужен `*`).
- Для защиты от изменений используют константную ссылку: `const T&` — эффективно (без копирования) и безопасно.

```cpp
void print(const std::string& s) {  // без копирования, только чтение
    std::cout << s;
}
```

## 3. Передача по указателю (pass by pointer)

Параметр объявляется как указатель (`T*`). В функцию передаётся **адрес** объекта. Чтобы изменить сам объект, нужно разыменовать указатель (`*ptr`).

```cpp
void modify(int* x) {
    *x = 100;  // изменяется исходная переменная
}

int main() {
    int a = 5;
    modify(&a);
    // a теперь равно 100
}
```

**Особенности:**
- Копируется только адрес (указатель), а не сам объект.
- Указатель может быть `nullptr` — это нужно проверять внутри функции.
- Можно «переприсвоить» указатель внутри функции, но это не изменит указатель вызывающей стороны (если не передавать `T**`).
- Требуется явное разыменование (`*`) для доступа к объекту и взятие адреса (`&`) при вызове.
- В современном C++ для входных параметров предпочитают ссылки; указатели оставляют, когда «отсутствие объекта» (`nullptr`) — допустимое состояние.

## Сравнительная таблица

| Критерий | По значению | По ссылке | По указателю |
|---|---|---|---|
| Что передаётся | Копия значения | Псевдоним (ссылка) | Адрес объекта |
| Изменение оригинала | Нет | Да | Да (через `*`) |
| Копирование объекта | Да | Нет | Нет (копируется адрес) |
| Может быть «пустым» | — | Нет | Да (`nullptr`) |
| Синтаксис доступа | `x` | `x` | `*x` |
| Нужен `&` при вызове | Нет | Нет | Да |

## Что выбрать?

- **Малые типы** (`int`, `double`, `bool`, перечисления) — передавайте **по значению**.
- **Большие объекты только для чтения** — `const T&` (по константной ссылке).
- **Объекты, которые нужно изменить** — `T&` (по ссылке).
- **Когда объект может отсутствовать** или требуется совместимость с C-API — **по указателю**.
- **Когда нужно изменить сам указатель вызывающей стороны** — передавайте указатель по ссылке `T*&` или двойной указатель `T**`.

## Важный нюанс

Передача по ссылке и по указателю с точки зрения эффективности почти эквивалентны (в обоих случаях не копируется объект). Главное различие — семантика: ссылка всегда валидна и работает как псевдоним, указатель может быть `nullptr` и требует явного разыменования. В современном идиоматичном C++ ссылки предпочтительнее для параметров, а указатели — когда нужно выразить «необязательность» объекта или работать с динамической памятью.
