# 162. Команды Bash

Bash (Bourne Again SHell) — это командная оболочка и язык сценариев, используемый по умолчанию в большинстве дистрибутивов Linux и macOS. Команды Bash можно разделить на две большие категории: **встроенные (builtins)** — выполняются самим интерпретатором Bash, и **внешние** — вызывают отдельные программы из файловой системы .

## 1. Встроенные команды (Builtins)

Это команды, которые являются частью самого Bash. Их выполнение не требует запуска дочернего процесса, поэтому они работают быстрее и могут изменять состояние текущей оболочки (например, текущий каталог или переменные окружения).

Вот основные встроенные команды Bash :

| Команда | Назначение |
| :--- | :--- |
| `cd` | Смена текущего рабочего каталога. |
| `pwd` | Вывод абсолютного пути текущего каталога. |
| `echo` | Вывод текста или значений переменных в стандартный поток вывода. |
| `printf` | Форматированный вывод (аналог одноимённой функции C). |
| `read` | Чтение строки из стандартного ввода и сохранение её в переменной. |
| `export` | Пометка переменной для экспорта в среду дочерних процессов. |
| `source` (или `.`) | Выполнение команд из файла в текущем контексте оболочки. |
| `alias` | Создание псевдонимов для команд. |
| `history` | Просмотр истории выполненных команд. |
| `jobs`, `bg`, `fg` | Управление заданиями (процессами) в оболочке. |
| `exit` | Завершение работы оболочки (или скрипта). |
| `help` | Вывод справки по встроенным командам Bash. |

**Пример использования `read` и `echo`:**
```bash
#!/bin/bash
echo "Как вас зовут?"
read username
echo "Привет, $username!"
```
Этот скрипт запрашивает имя пользователя и затем выводит приветствие .

## 2. Внешние команды (External Commands)

Эти команды представляют собой отдельные исполняемые файлы, которые Bash находит в каталогах, перечисленных в переменной `$PATH`. Они запускаются как дочерние процессы.

### Работа с файлами и каталогами
| Команда | Назначение |
| :--- | :--- |
| `ls` | Список файлов и каталогов. |
| `cp` | Копирование файлов и каталогов. |
| `mv` | Перемещение или переименование файлов. |
| `rm` | Удаление файлов и каталогов. |
| `mkdir` | Создание нового каталога. |
| `rmdir` | Удаление пустого каталога. |
| `cat` | Вывод содержимого файла на экран (или объединение файлов). |
| `less` / `more` | Постраничный просмотр содержимого файла. |
| `touch` | Создание пустого файла или обновление времени его модификации. |

### Управление правами доступа
| Команда | Назначение |
| :--- | :--- |
| `chmod` | Изменение прав доступа к файлу (чтение/запись/исполнение). |
| `chown` | Изменение владельца и группы файла. |

Права доступа можно задавать в символьном виде (например, `chmod u+x file.sh` — добавить право на исполнение для владельца) или в числовом (например, `chmod 755 file.sh`) .

### Поиск и обработка текста
| Команда | Назначение |
| :--- | :--- |
| `grep` | Поиск строк, соответствующих шаблону. |
| `find` | Поиск файлов в файловой системе по различным критериям. |
| `sed` | Потоковый редактор для обработки текста. |
| `awk` | Язык обработки текстовых данных. |
| `wc` | Подсчёт количества строк, слов и символов. |

### Управление процессами
| Команда | Назначение |
| :--- | :--- |
| `ps` | Вывод списка текущих процессов. |
| `top` / `htop` | Интерактивный просмотр процессов и нагрузки на систему. |
| `kill` | Отправка сигнала процессу (обычно для завершения). |
| `grep` | (часто используется в связке с `ps` для фильтрации, например `ps aux | grep bash`). |

### Разработка (актуально для C++)
| Команда | Назначение |
| :--- | :--- |
| `g++` / `gcc` | Компиляция и компоновка программ на C/C++. |
| `make` | Сборка проекта на основе Makefile. |
| `gdb` | Отладчик. |

## 3. Комбинирование команд (Конвейеры и списки)

Мощь Bash заключается в возможности комбинировать команды.

- **Конвейер (`|`)**: Передаёт стандартный вывод одной команды на стандартный ввод другой.
  ```bash
  ps aux | grep "my_program"
  ```
  Эта команда найдёт все процессы, в имени которых встречается `my_program` .

- **Логические операторы (`&&`, `||`)**: Условное выполнение.
  - `cmd1 && cmd2` — выполнить `cmd2`, только если `cmd1` завершилась успешно (код возврата 0).
  - `cmd1 || cmd2` — выполнить `cmd2`, только если `cmd1` завершилась с ошибкой (код возврата не 0) .

- **Последовательное выполнение (`;`)**: Выполнить команды друг за другом независимо от результата.

## 4. Полезные сочетания клавиш и функции

- **Автодополнение (`Tab`)**: Нажатие `Tab` автоматически дополняет имена команд, файлов и каталогов. Двойное нажатие `Tab` выводит список возможных вариантов .
- **История (`history` и `!!`)**: Команда `history` показывает пронумерованный список предыдущих команд. `!!` повторяет последнюю выполненную команду .
- **Перенаправление ввода-вывода**:
  - `>` — перенаправить вывод в файл (с перезаписью).
  - `>>` — перенаправить вывод в файл (с добавлением в конец).
  - `<` — перенаправить ввод из файла.

## 5. Справка

Для получения подробной информации о любой команде используйте `man` (для внешних команд и системных вызовов) или `help` (для встроенных команд Bash).

```bash
man ls      # справка по внешней команде ls
help cd     # справка по встроенной команде cd
```

Для программирования на C++ наиболее важными являются команды навигации по файловой системе (`cd`, `ls`, `pwd`), компиляции (`g++`, `make`), а также инструменты для работы с текстом и процессами (`grep`, `ps`, `kill`).
