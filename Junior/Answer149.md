## 149. Для чего нужен порт?

**Порт (port)** — это числовой идентификатор (16-битное число от 0 до 65535), который используется в сетевом программировании для **разделения потоков данных между различными приложениями (процессами) на одном хосте**.

Если **IP-адрес** идентифицирует конкретный компьютер в сети, то **порт** идентифицирует конкретное приложение (процесс) на этом компьютере. Комбинация `IP-адрес:порт` однозначно определяет конечную точку соединения (сокет).

### Основные задачи порта

1. **Мультиплексирование соединений.** На одном компьютере одновременно работают десятки сетевых приложений (браузер, почтовый клиент, мессенджер, веб-сервер). Все они получают пакеты через один сетевой интерфейс, но благодаря разным портам операционная система знает, какому процессу передать каждый пакет.

2. **Демультиплексирование входящего трафика.** Когда пакет приходит на хост, ОС по номеру порта назначения определяет, какому сокету (и какому процессу) его доставить.

3. **Идентификация сервиса.** По номеру порта можно понять, к какому сервису идёт обращение (хотя формально это лишь соглашение).

4. **Организация клиент-серверного взаимодействия.** Сервер «слушает» заранее известный порт, а клиент подключается к нему, при этом клиенту ОС автоматически назначает свободный «эфемерный» порт для ответного канала.

### Диапазоны портов

| Диапазон | Название | Назначение |
|---|---|---|
| 0–1023 | Системные (well-known) | Стандартные сервисы: 80 (HTTP), 443 (HTTPS), 21 (FTP), 22 (SSH), 25 (SMTP), 53 (DNS). Требуют привилегий администратора. |
| 1024–49151 | Зарегистрированные (registered) | Зарезервированы за конкретными приложениями (например, 3306 — MySQL, 5432 — PostgreSQL, 8080 — альтернативный HTTP). |
| 49152–65535 | Динамические (ephemeral) | Временно выдаются ОС клиентским приложениям для исходящих соединений. |

### Пример на C++ (сокеты Berkeley/POSIX)

```cpp
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>
#include <unistd.h>
#include <iostream>

int main() {
    // Создаём TCP-сокет
    int server_fd = socket(AF_INET, SOCK_STREAM, 0);
    if (server_fd < 0) { perror("socket"); return 1; }

    // Привязываем сокет к конкретному порту на всех интерфейсах
    sockaddr_in addr{};
    addr.sin_family      = AF_INET;
    addr.sin_addr.s_addr = INADDR_ANY;   // любой локальный IP
    addr.sin_port        = htons(8080);  // <-- НОМЕР ПОРТА (8080)

    if (bind(server_fd, (sockaddr*)&addr, sizeof(addr)) < 0) {
        perror("bind"); return 1;
    }

    listen(server_fd, 5);
    std::cout << "Сервер слушает порт 8080\n";

    // ... accept(), recv(), send() ...

    close(server_fd);
    return 0;
}
```

Здесь `htons(8080)` переводит номер порта в **сетевой порядок байт** (big-endian), что обязательно, поскольку порт в заголовках TCP/UDP передаётся именно в таком формате.

### Ключевые моменты

- Порт входит в состав **транспортного уровня** (TCP/UDP) — в заголовке пакета есть поля «порт источника» и «порт назначения».
- Пара `(IP, порт, протокол)` образует **сокет** — конечную точку соединения.
- Один порт может обслуживаться только одним процессом одновременно (для TCP); для UDP возможно разделение через `SO_REUSEPORT`.
- **Порт ≠ физический разъём**: это чисто программная абстракция, позволяющая ОС маршрутизировать данные конкретному приложению.
