# 115. Виртуальные функции в C++

## Определение

**Виртуальная функция** — это функция-член класса, объявленная с ключевым словом `virtual` в базовом классе, которая может быть переопределена в производных классах. При вызове через указатель или ссылку на базовый класс вызывается реализация, соответствующая **фактическому типу объекта** (динамическому типу), а не типу указателя/ссылки.

```cpp
class Shape {
public:
    virtual void draw() const {           // виртуальная функция
        std::cout << "Shape::draw\n";
    }
    virtual ~Shape() = default;           // виртуальный деструктор!
};

class Circle : public Shape {
public:
    void draw() const override {          // переопределение
        std::cout << "Circle::draw\n";
    }
};

class Square : public Shape {
public:
    void draw() const override {
        std::cout << "Square::draw\n";
    }
};

int main() {
    Shape* p1 = new Circle();
    Shape* p2 = new Square();

    p1->draw();   // Circle::draw  — полиморфизм
    p2->draw();   // Square::draw

    delete p1;
    delete p2;
}
```

## Зачем нужны виртуальные функции

1. **Реализация динамического (позднего) полиморфизма.** Позволяют работать с объектами разных производных классов через единый интерфейс базового класса, вызывая при этом корректную реализацию.

2. **Расширяемость без изменения существующего кода.** Добавление нового производного класса не требует правки функций, работающих с базовым типом (принцип открытости/закрытости).

3. **Разделение интерфейса и реализации.** Базовый класс задаёт контракт, производные классы — конкретное поведение.

4. **Хранение разнородных объектов в одном контейнере.** `std::vector<std::unique_ptr<Shape>>` позволяет единообразно обрабатывать разные фигуры.

## Механизм работы: таблица виртуальных функций (vtable)

- Для каждого класса, содержащего виртуальные функции (или наследующего их), компилятор создаёт **таблицу виртуальных функций** — массив указателей на реализации.
- Каждый объект такого класса содержит скрытый указатель **vptr** на vtable своего класса (обычно первое поле объекта).
- При вызове `p->draw()` происходит: взятие vptr из объекта → выбор нужного слота в vtable → вызов функции. Это **динамическое связывание** (dynamic dispatch), выполняемое во время работы программы.
- Цена: небольшой расход памяти (vptr в каждом объекте + vtable на класс) и небольшие накладные расходы на вызов по сравнению с обычной функцией.

## Ключевые правила и особенности

- **Переопределение (override)** в производном классе требует совпадения сигнатуры (имя, параметры, квалификаторы). Полезно писать `override` — компилятор проверит корректность.
- **Виртуальность наследуется.** Если функция виртуальна в базовом классе, она виртуальна и во всех производных, даже без слова `virtual`.
- **Виртуальный деструктор обязателен**, если объекты удаляются через указатель на базовый класс. Иначе — неопределённое поведение (вызовется только деструктор базового класса).
- **Чисто виртуальная функция** (`= 0`) делает класс абстрактным — нельзя создавать его объекты; производные классы обязаны реализовать такую функцию (интерфейс).
- **Статическое связывание** происходит при вызове через объект (не указатель/ссылку), а также в конструкторах и деструкторах (виртуальность там не работает в полной мере).
- **Ключевое слово `final`** запрещает дальнейшее переопределение функции в производных классах.
- **Вызов виртуальной функции через `ClassName::func()`** явно отключает динамическое связывание (квалифицированный вызов).
- Виртуальными **не могут** быть: статические функции, конструкторы, дружественные функции (friend).

## Пример с чисто виртуальной функцией (абстрактный класс)

```cpp
class Animal {
public:
    virtual void speak() const = 0;   // чисто виртуальная — интерфейс
    virtual ~Animal() = default;
};

class Dog : public Animal {
public:
    void speak() const override { std::cout << "Woof!\n"; }
};

class Cat : public Animal {
public:
    void speak() const override { std::cout << "Meow!\n"; }
};

void makeSound(const Animal& a) {
    a.speak();   // полиморфный вызов
}
```

## Итог

Виртуальные функции — основной инструмент **динамического полиморфизма** в C++. Они позволяют вызывать переопределённое поведение производного класса через указатель/ссылку на базовый класс, реализуясь через vtable/vptr. Без них полиморфизм времени выполнения в C++ был бы невозможен.
