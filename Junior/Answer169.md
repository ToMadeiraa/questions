# 169. Посчитайте количество единиц в произвольном числе.

## Постановка задачи

Под «количеством единиц в произвольном числе» обычно понимается **количество единичных битов в двоичном представлении числа** (это классическая задача *popcount* / *Hamming weight*). Реже имеется в виду количество цифр `1` в десятичной записи. Ниже разобраны оба варианта — начнём с основного (биты).

---

## Вариант 1. Количество единичных битов (popcount)

### Способ 1. Простой перебор битов

Идея: сдвигаем число вправо, пока оно не станет нулём, и проверяем младший бит.

```cpp
#include <iostream>

int countOnes(unsigned int x) {
    int count = 0;
    while (x != 0) {
        if (x & 1u)       // проверяем младший бит
            ++count;
        x >>= 1;          // сдвигаем вправо
    }
    return count;
}

int main() {
    unsigned int n;
    std::cout << "Введите число: ";
    std::cin >> n;
    std::cout << "Единиц в двоичной записи: " << countOnes(n) << '\n';
}
```

Сложность — **O(log n)** (по числу битов). Важно использовать **беззнаковый** тип: для знакового при сдвиге вправо может выполняться арифметический сдвиг.

---

### Способ 2. Трюк `x & (x - 1)` — самый популярный

Ключевое наблюдение: операция `x & (x - 1)` **сбрасывает младший установленный бит**. Значит, число итераций равно числу единиц.

Пример: `x = 12 = 1100₂`
- `12 & 11 = 1100 & 1011 = 1000` (8)
- `8 & 7 = 1000 & 0111 = 0000` (0) — готово, 2 итерации = 2 единицы.

```cpp
int countOnes(unsigned int x) {
    int count = 0;
    while (x) {
        x &= (x - 1);   // сбрасываем младший установленный бит
        ++count;
    }
    return count;
}
```

Сложность — **O(k)**, где `k` — число единиц (быстрее среднего случая, чем способ 1).

---

### Способ 3. Встроенные средства C++

В C++20 есть стандартная функция `std::popcount` (заголовок `<bit>`), которая компилируется в аппаратную инструкцию `POPCNT` там, где она есть:

```cpp
#include <bit>
#include <iostream>

int main() {
    unsigned int n;
    std::cin >> n;
    std::cout << std::popcount(n) << '\n';   // C++20
}
```

До C++20 часто используют встроенные функции компилятора:

```cpp
int count = __builtin_popcount(n);      // GCC / Clang, для unsigned int
// __builtin_popcountll(n) — для unsigned long long
```

---

### Способ 4. Классический «параллельный» алгоритм (без циклов)

Для 32-битного числа за фиксированные 5 шагов (метод параллельного суммирования битов):

```cpp
int countOnes(std::uint32_t x) {
    x = x - ((x >> 1) & 0x55555555u);
    x = (x & 0x33333333u) + ((x >> 2) & 0x33333333u);
    x = (x + (x >> 4)) & 0x0F0F0F0Fu;
    return (x * 0x01010101u) >> 24;
}
```

Работает за **O(1)** независимо от значения — удобно, когда ветвления/циклы нежелательны.

---

## Вариант 2. Количество цифр «1» в десятичной записи

Если под числом понимается именно десятичное представление (например, в числе `1211` — три единицы):

```cpp
#include <iostream>

int countDigitOnes(long long n) {
    if (n < 0) n = -n;          // модуль
    if (n == 0) return 0;

    int count = 0;
    while (n > 0) {
        if (n % 10 == 1)        // проверяем последнюю цифру
            ++count;
        n /= 10;                // отбрасываем её
    }
    return count;
}

int main() {
    long long n;
    std::cin >> n;
    std::cout << countDigitOnes(n) << '\n';
}
```

Сложность — **O(log₁₀ n)**.

---

## Рекомендации для практического задания

| Ситуация | Что выбрать |
|---|---|
| Учебная задача «руками» | `x & (x - 1)` — коротко и наглядно |
| Нужна максимальная скорость, C++20 | `std::popcount` |
| Компилятор GCC/Clang, C++17 | `__builtin_popcount` |
| Нельзя использовать циклы | параллельный алгоритм (способ 4) |
| Имеется в виду десятичная запись | `n % 10 == 1` в цикле |

**Важные детали:**
- Для битовых операций берите **беззнаковый** тип (`unsigned`, `std::uint32_t`), иначе сдвиг вправо знакового отрицательного числа — неопределённое/зависимое от реализации поведение.
- `std::popcount` в C++20 принимает только беззнаковые типы — приводите явно: `std::popcount(static_cast<unsigned>(n))`.
- Для нуля обе версии корректно возвращают `0`.
