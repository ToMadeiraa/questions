# 94. Лямбда-функции в C++

## Что такое лямбда-функция

**Лямбда-функция** (лямбда-выражение) — это анонимная функция, которую можно определить прямо в месте её использования, без необходимости объявлять отдельную именованную функцию или функтор (класс с `operator()`).

Лямбда-выражения появились в стандарте **C++11** и позволяют писать компактный код, особенно удобный для передачи в алгоритмы STL (`std::sort`, `std::for_each`, `std::find_if` и т.п.), для callback-ов и для локальных вспомогательных вычислений.

### Синтаксис

```cpp
[захват](параметры) -> возвращаемый_тип { тело }
```

Где:
- `[захват]` — **список захвата** (capture list), определяет, какие переменные из внешней области видимости доступны внутри лямбды и каким способом;
- `(параметры)` — список параметров, как у обычной функции (можно опустить, если параметров нет);
- `-> возвращаемый_тип` — необязательное указание типа возвращаемого значения (обычно выводится автоматически);
- `{ тело }` — тело функции.

### Простейший пример

```cpp
#include <iostream>

int main() {
    auto hello = []() { std::cout << "Hello, lambda!\n"; };
    hello();  // вызов лямбды
}
```

Лямбда создаёт **замыкание** (closure) — объект безымянного класса, у которого перегружен `operator()`. Тип этого объекта уникален и известен только компилятору, поэтому его обычно сохраняют через `auto` или `std::function`.

```cpp
// С параметрами и возвращаемым значением
auto sum = [](int a, int b) -> int { return a + b; };
std::cout << sum(2, 3);  // 5

// Тип возвращаемого значения выводится автоматически
auto mul = [](int a, int b) { return a * b; };
```

### Использование с алгоритмами STL

```cpp
#include <algorithm>
#include <vector>

std::vector<int> v = {5, 2, 8, 1, 9};

// Сортировка по убыванию
std::sort(v.begin(), v.end(), [](int a, int b) { return a > b; });

// Поиск первого чётного числа
auto it = std::find_if(v.begin(), v.end(), [](int x) { return x % 2 == 0; });
```

## Доступ к переменным внешней области видимости: список захвата

По умолчанию лямбда **не имеет доступа** к локальным переменным из внешней области видимости — их нужно явно «захватить» в квадратных скобках. Существует два основных способа захвата.

### 1. Захват по значению

Переменная **копируется** в замыкание в момент создания лямбды. Изменения переменной снаружи на лямбду уже не влияют, а изменение копии внутри лямбды (без `mutable`) запрещено.

```cpp
int x = 10;

auto f = [x]() { return x * 2; };  // x копируется
x = 100;                            // на лямбду не влияет

std::cout << f();  // 20, а не 200
```

### 2. Захват по ссылке

Лямбда получает **ссылку** на внешнюю переменную и работает с оригиналом. Изменения видны в обе стороны.

```cpp
int counter = 0;

auto inc = [&counter]() { ++counter; };
inc();
inc();

std::cout << counter;  // 2
```

> ⚠️ **Осторожно:** если лямбда с захватом по ссылке «переживёт» захваченную переменную (например, сохранена в `std::function` и вызвана позже), получится висячая ссылка — неопределённое поведение.

### Сокращённые формы захвата

| Запись | Значение |
|--------|----------|
| `[]` | ничего не захватывать |
| `[x]` | захватить `x` по значению |
| `[&x]` | захватить `x` по ссылке |
| `[=]` | захватить **все** используемые переменные по значению |
| `[&]` | захватить **все** используемые переменные по ссылке |
| `[=, &x]` | всё по значению, но `x` — по ссылке (смешанный захват) |
| `[&, x]` | всё по ссылке, но `x` — по значению |
| `[this]` | захватить указатель `this` (для лямбд внутри методов класса) |
| `[*this]` | захватить копию текущего объекта (C++17) |

```cpp
int a = 1, b = 2;

auto f1 = [=]() { return a + b; };      // обе по значению
auto f2 = [&]() { a++; b++; };          // обе по ссылке
auto f3 = [=, &a]() { a++; return b; };// a по ссылке, b по значению
```

### Ключевое слово `mutable`

Замыкание по умолчанию ведёт себя как объект с `const operator()`, поэтому изменять захваченные **по значению** переменные внутри нельзя. `mutable` снимает это ограничение — изменения затрагивают только внутреннюю копию:

```cpp
int x = 0;
auto f = [x]() mutable { x += 5; return x; };

std::cout << f();  // 5
std::cout << f();  // 10 — копия сохраняется между вызовами
std::cout << x;    // 0 — внешняя переменная не изменилась
```

### Захват `this` в методах класса

Внутри метода класса лямбда не видит члены класса напрямую — нужно захватить `this`:

```cpp
class Widget {
    int value = 42;
public:
    auto getter() {
        return [this]() { return value; };  // доступ к члену через this
    }
};
```

В C++17 появился захват `[*this]` — копия всего объекта, полезно, если лямбда может пережить сам объект.

---

## Итог

- Лямбда — это анонимная функция-замыкание, объявляемая на месте использования (C++11).
- Синтаксис: `[захват](параметры) -> тип { тело }`.
- Доступ к внешним переменным осуществляется через **список захвата**: `[x]` — по значению, `[&x]` — по ссылке, `[=]` / `[&]` — все переменные, `[this]` — текущий объект.
- Захват по значению копирует переменную, по ссылке — даёт доступ к оригиналу (с риском висячей ссылки).
- `mutable` позволяет изменять копии захваченных по значению переменных внутри лямбды.
