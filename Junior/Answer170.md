# 170. Есть структура по типу «односвязный список». Напишите функцию, которая разворачивает список. То есть, первый элемент становится последним, а последний - первым.

## Постановка задачи

Односвязный список — это структура данных, в которой каждый узел хранит значение и указатель только на **следующий** узел. Развернуть (обратить) список — значит изменить все связи `next` так, чтобы порядок элементов стал обратным: бывший последний узел становится головой, а бывший первый — хвостом (его `next == nullptr`).

## Структура списка

```cpp
struct Node {
    int   value;   // полезные данные (может быть любым типом)
    Node* next;    // указатель на следующий узел
};

// Удобный псевдоним для головы списка
using List = Node*;
```

## Итеративный алгоритм (рекомендуемый)

Идея: идём по списку, на каждом шаге запоминаем следующий узел, «разворачиваем» текущий указатель назад и сдвигаем три указателя вперёд. Сложность — **O(n)** по времени и **O(1)** по памяти.

```cpp
Node* reverseList(Node* head) {
    Node* prev = nullptr;   // узел, который станет "следующим" для текущего
    Node* curr = head;      // текущий обрабатываемый узел

    while (curr != nullptr) {
        Node* next = curr->next; // 1) запомнили следующий узел
        curr->next = prev;       // 2) развернули связь назад
        prev = curr;             // 3) сдвинули prev вперёд
        curr = next;             // 4) сдвинули curr вперёд
    }
    return prev; // новая голова списка
}
```

Пошаговая трассировка для списка `1 -> 2 -> 3 -> nullptr`:

| Шаг | `prev` | `curr` | `next` | Действие |
|-----|--------|--------|--------|----------|
| 1 | `nullptr` | `1` | `2` | `1->next = nullptr`; `prev=1`, `curr=2` |
| 2 | `1` | `2` | `3` | `2->next = 1`; `prev=2`, `curr=3` |
| 3 | `2` | `3` | `nullptr` | `3->next = 2`; `prev=3`, `curr=nullptr` |
| — | `3` | `nullptr` | — | цикл завершён, возвращаем `3` |

Результат: `3 -> 2 -> 1 -> nullptr`.

## Рекурсивный вариант

```cpp
Node* reverseListRec(Node* head) {
    // База: пустой список или один элемент — уже развёрнут
    if (head == nullptr || head->next == nullptr)
        return head;

    // Разворачиваем остаток списка
    Node* newHead = reverseListRec(head->next);

    // head->next теперь указывает на последний узел развёрнутого остатка;
    // делаем так, чтобы он указывал на head, и обнуляем head->next
    head->next->next = head;
    head->next = nullptr;

    return newHead;
}
```

Минус рекурсии: глубина стека равна длине списка — для длинных списков (порядка сотен тысяч узлов) возможен переполнение стека. Поэтому в продакшене предпочтителен итеративный вариант.

## Полный пример с `main`

```cpp
#include <iostream>

struct Node {
    int   value;
    Node* next;
};

Node* reverseList(Node* head) {
    Node* prev = nullptr;
    Node* curr = head;
    while (curr) {
        Node* next = curr->next;
        curr->next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}

void print(const Node* head) {
    for (const Node* p = head; p; p = p->next)
        std::cout << p->value << ' ';
    std::cout << '\n';
}

int main() {
    // Построим список 1 -> 2 -> 3 -> 4 -> 5
    Node* head = nullptr;
    Node* tail = nullptr;
    for (int v : {1, 2, 3, 4, 5}) {
        Node* n = new Node{v, nullptr};
        if (!head) head = tail = n;
        else { tail->next = n; tail = n; }
    }

    print(head);              // 1 2 3 4 5
    head = reverseList(head);
    print(head);              // 5 4 3 2 1

    // Освобождение памяти
    while (head) { Node* t = head; head = head->next; delete t; }
    return 0;
}
```

## Крайние случаи

Функция корректно обрабатывает:
- **пустой список** (`head == nullptr`) — цикл не выполнится, вернётся `nullptr`;
- **список из одного элемента** — `curr->next = nullptr` остаётся корректным, возвращается тот же узел;
- **список из двух и более элементов** — работает по общей схеме.

## Сложность

| Параметр | Итеративно | Рекурсивно |
|----------|------------|------------|
| Время | O(n) | O(n) |
| Память | O(1) | O(n) стек вызовов |

## Замечание о «развороте» без возврата новой головы

Иногда удобно передавать голову по ссылке/указателю, чтобы функция изменяла её на месте:

```cpp
void reverseListInPlace(Node** headRef) {
    Node* prev = nullptr;
    Node* curr = *headRef;
    while (curr) {
        Node* next = curr->next;
        curr->next = prev;
        prev = curr;
        curr = next;
    }
    *headRef = prev;
}
```

Оба подхода эквивалентны; выбор зависит от стиля кода — в C++ идиоматичнее возвращать новую голову (как в `std::reverse`-подобных реализациях), но вариант с `Node**`/`Node*&` тоже встречается.
