# 141. Какая информация нужна, чтобы создать сокет?

Чтобы создать сокет в C++, необходимо передать в функцию `socket()` три ключевых параметра, которые однозначно определяют тип создаваемого сокета и протокол его работы. Эти параметры определяют **семейство адресов**, **тип сокета** и **протокол**.

### 1. Семейство адресов (Address Family)
Определяет, в какой сетевой среде будет использоваться сокет. Для сетевого программирования обычно используются следующие значения:
*   **`AF_INET`**: для IPv4-адресов.
*   **`AF_INET6`**: для IPv6-адресов.
*   **`AF_UNSPEC`**: указывает, что семейство адресов не указано явно, что позволяет приложению принимать как IPv4, так и IPv6 адреса (обычно используется в сочетании с `getaddrinfo`) .

### 2. Тип сокета (Socket Type)
Определяет семантику связи.
*   **`SOCK_STREAM`**: обеспечивает ориентированную на соединение, надежную передачу байтовых потоков. В интернет-протоколах обычно соответствует **TCP** .
*   **`SOCK_DGRAM`**: поддерживает датаграммы (ненадежные, без установления соединения). Обычно соответствует **UDP** .

### 3. Протокол (Protocol)
Уточняет конкретный протокол передачи, который будет использоваться сокетом. Обычно можно передать `0`, чтобы система автоматически выбрала протокол на основе типа сокета, или указать явно:
*   **`IPPROTO_TCP`**: для TCP.
*   **`IPPROTO_UDP`**: для UDP .

### Пример кода (на основе Winsock)
В Windows при создании сокета обычно сначала заполняют структуру `addrinfo` для указания требуемых параметров, а затем вызывают функцию `socket()`:

```cpp
struct addrinfo hints;
ZeroMemory(&hints, sizeof(hints));

// 1. Указываем семейство адресов (AF_UNSPEC означает принятие как IPv4, так и IPv6)
hints.ai_family = AF_UNSPEC; 

// 2. Указываем тип сокета (SOCK_STREAM означает потоковый сокет)
hints.ai_socktype = SOCK_STREAM; 

// 3. Указываем протокол (IPPROTO_TCP означает протокол TCP)
hints.ai_protocol = IPPROTO_TCP; 

// Вызываем socket() для создания сокета
SOCKET ConnectSocket = socket(hints.ai_family, hints.ai_socktype, hints.ai_protocol);

if (ConnectSocket == INVALID_SOCKET) {
    // Обработка ошибки создания
    printf("Error at socket(): %ld\n", WSAGetLastError());
}
```


**Важно отметить**: если вы не укажете семейство адресов (например, оставите `AF_UNSPEC`), но при этом последующий вызов `connect` завершится неудачей, вы можете попробовать явно указать `AF_INET` (только IPv4) или `AF_INET6` (только IPv6) для повторной попытки .
