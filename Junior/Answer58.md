# 58. Что такое `enum` в C++

## Определение

`enum` (перечисление, enumeration) — это составной тип данных, который позволяет создать набор именованных целочисленных констант. Каждое имя в перечислении получает целочисленное значение, и эти имена можно использовать в коде вместо «магических чисел», что делает код более читаемым и безопасным.

```cpp
enum Color {
    RED,    // 0
    GREEN,  // 1
    BLUE    // 2
};
```

## Синтаксис

```cpp
enum ИмяПеречисления {
    Значение1,
    Значение2,
    // ...
};
```

По умолчанию первому элементу присваивается `0`, каждому следующему — на единицу больше. Можно задавать значения явно:

```cpp
enum HttpStatus {
    OK = 200,
    NotFound = 404,
    ServerError = 500
};
```

Если явно задать значение одному элементу, следующие за ним получат последовательные значения:

```cpp
enum Flags {
    A = 5,
    B,       // 6
    C = 10,
    D        // 11
};
```

## Два вида перечислений в C++

### 1. Неограниченные (`unscoped`) перечисления

Классический вариант, унаследованный от C. Имена элементов попадают в окружающую область видимости и неявно преобразуются в `int`.

```cpp
enum Color { RED, GREEN, BLUE };

Color c = RED;
int x = RED;  // неявное преобразование в int — разрешено

// Проблема: имена «протекают» в область видимости
enum Fruit { APPLE, BANANA };
// enum Error { OK, ERROR };  // конфликт имён с другими enum
```

Можно указать базовый тип:

```cpp
enum Color : unsigned char { RED, GREEN, BLUE };
```

### 2. Ограниченные (`scoped`) перечисления — `enum class` (C++11)

Более безопасный современный вариант. Имена находятся внутри области видимости перечисления и **не** преобразуются неявно в целые числа.

```cpp
enum class Color {
    Red,
    Green,
    Blue
};

Color c = Color::Red;      // нужно указывать квалификатор Color::
// int x = Color::Red;     // ошибка: нет неявного преобразования
int x = static_cast<int>(Color::Red);  // явное приведение — OK
```

Преимущества `enum class`:
- **Изоляция имён** — нет конфликтов между разными перечислениями.
- **Строгая типизация** — нельзя случайно сравнить или присвоить значение другого типа.
- Можно задавать базовый тип: `enum class Color : uint8_t { ... };`.

## Применение

```cpp
#include <iostream>

enum class DayOfWeek { Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday };

const char* toString(DayOfWeek d) {
    switch (d) {
        case DayOfWeek::Monday:    return "Понедельник";
        case DayOfWeek::Tuesday:   return "Вторник";
        case DayOfWeek::Wednesday: return "Среда";
        case DayOfWeek::Thursday:  return "Четверг";
        case DayOfWeek::Friday:    return "Пятница";
        case DayOfWeek::Saturday:  return "Суббота";
        case DayOfWeek::Sunday:    return "Воскресенье";
    }
    return "Неизвестно";
}

int main() {
    DayOfWeek today = DayOfWeek::Wednesday;
    std::cout << toString(today) << "\n";  // Среда
}
```

## Полезные свойства и особенности

- **Размер**: по умолчанию обычно `int`, но базовый тип можно задать явно (важно для бинарной совместимости и экономии памяти).
- **Область значений**: для перечисления с базовым типом `int` значения элементов должны помещаться в диапазон, достаточный для всех элементов (обычно хватает `int`).
- **Сравнение**: элементы одного перечисления можно сравнивать между собой (`==`, `<` и т. д.).
- **Побитовые операции**: для неограниченных перечислений работают неявно (часто используют как флаги); для `enum class` нужно перегружать операторы `|`, `&` и т. д.
- **`switch`**: удобно использовать перечисления в `switch` — компилятор может предупредить о непокрытых значениях.

## Перечисления как битовые флаги

Для неограниченных перечислений можно задавать степени двойки и комбинировать значения:

```cpp
enum Permissions {
    Read    = 1 << 0,  // 1
    Write   = 1 << 1,  // 2
    Execute = 1 << 2   // 4
};

int perms = Read | Write;  // 3 — чтение и запись
```

Для `enum class` аналогичное требует перегрузки операторов:

```cpp
enum class Permissions : unsigned {
    Read    = 1 << 0,
    Write   = 1 << 1,
    Execute = 1 << 2
};

inline Permissions operator|(Permissions a, Permissions b) {
    return static_cast<Permissions>(static_cast<unsigned>(a) | static_cast<unsigned>(b));
}
```

## Итог

| Характеристика | `enum` (unscoped) | `enum class` (scoped, C++11) |
|---|---|---|
| Область видимости имён | окружающая | внутри перечисления |
| Неявное преобразование в `int` | да | нет |
| Конфликты имён | возможны | исключены |
| Задание базового типа | да (C++11) | да |
| Рекомендуется | для совместимости с C, флагов | в современном C++ по умолчанию |

**Вывод:** `enum` — это способ дать осмысленные имена целочисленным константам. В современном C++ предпочтительно использовать `enum class`, так как он обеспечивает строгую типизацию и изоляцию имён, снижая вероятность ошибок.
