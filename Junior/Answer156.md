# 156. Что такое PID?

**PID (Process Identifier)** — это уникальный числовой идентификатор, присваиваемый операционной системой каждому активному процессу. В контексте языка C++ (и программирования под Unix/Linux в целом) понимание PID необходимо для управления процессами, отладки и взаимодействия с операционной системой.

Ниже приведено подробное объяснение с точки зрения системного программирования.

### 1. Определение и основные свойства

Согласно документации POSIX и man-страницам Linux (credentials(7)), PID — это **уникальное неотрицательное целое число**, которое присваивается процессу при его создании .

*   **Тип данных:** Для хранения PID в C/C++ используется тип `pid_t`, который обычно определяется в заголовочном файле `<sys/types.h>` (часто является псевдонимом для `int` или `long` в зависимости от платформы) .
*   **Уникальность:** В рамках одной системы в один момент времени не может быть двух процессов с одинаковым PID. Однако после завершения процесса его PID может быть переиспользован ядром для нового процесса (циклическое использование) .
*   **Сохранение:** PID процесса не меняется при вызове `execve()` (замене образа процесса), но меняется при создании нового процесса через `fork()` .

### 2. Как получить PID в C++

Для получения идентификатора текущего процесса используется системный вызов `getpid()`, а для получения идентификатора родительского процесса — `getppid()`.

**Пример кода на C++:**

```cpp
#include <iostream>
#include <unistd.h> // Для getpid(), getppid()
#include <sys/types.h>

int main() {
    // Получаем PID текущего процесса
    pid_t current_pid = getpid();
    // Получаем PID родительского процесса
    pid_t parent_pid = getppid();

    std::cout << "Мой PID: " << current_pid << std::endl;
    std::cout << "PID родителя (PPID): " << parent_pid << std::endl;

    return 0;
}
```

### 3. Где и зачем используется PID

PID играет ключевую роль в системных вызовах, которые позволяют управлять процессами. В C++ вы будете передавать PID в качестве аргумента в следующие функции (обычно объявленные в `<signal.h>` или `<sys/wait.h>`):

*   **Управление сигналами (`kill`):** Отправка сигнала конкретному процессу (например, для завершения работы или приостановки). `kill(pid, SIGTERM);` .
*   **Ожидание завершения (`waitpid`):** Родительский процесс использует PID потомка, чтобы дождаться его завершения и получить код возврата .
*   **Изменение приоритета (`setpriority`):** Изменение "nice" значения процесса с указанным PID .
*   **Отладка (`ptrace`):** Механизм, позволяющий отладчику (например, GDB) контролировать выполнение другого процесса по его PID .

### 4. Специальные значения PID

В Unix-подобных системах существуют зарезервированные PID:

*   **PID 1:** Это процесс `init` (или `systemd` в современных дистрибутивах). Он всегда запускается ядром при загрузке системы и является предком всех остальных процессов. Его завершение (если это не предусмотрено системой) обычно приводит к панике ядра .
*   **PPID (Parent PID):** Идентификатор родителя. Если родительский процесс завершился раньше потомка, потомок становится "сиротой" и его PPID меняется на 1 (его усыновляет `init`) .

### 5. Просмотр PID в системе

Хотя вопрос касается C++, полезно знать, как посмотреть PID извне (например, для отладки вашей программы). В командной строке Linux/Unix для этого используются утилиты:

*   `ps`: Выводит список процессов (колонка `PID`).
*   `top` / `htop`: Показывают PID в реальном времени.
*   `pidof <имя_программы>`: Возвращает PID запущенного экземпляра программы.

### Резюме для ответа

**PID** — это числовой дескриптор процесса. В C++ он представлен типом `pid_t` и получается через `getpid()`. Он используется для отправки сигналов, управления ресурсами и отслеживания иерархии процессов (например, родитель-потомок). Знание PID необходимо при написании многопроцессных приложений и системных утилит.
