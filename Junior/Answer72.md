# 72. Указатели на функции в C++

## Для чего нужен указатель на функцию

Указатель на функцию — это переменная, которая хранит **адрес функции в памяти**. Через такой указатель можно вызывать функцию, как будто это обычная переменная, что открывает несколько важных возможностей:

1. **Передача функции как аргумента в другую функцию** — это основа реализации *callback*-механизмов (обратных вызовов). Например, функция сортировки может принимать функцию-компаратор, чтобы задавать порядок сравнения элементов.
2. **Реализация таблиц функций (dispatch tables)** — массив указателей на функции позволяет заменить длинные цепочки `if/else` или `switch` на индексацию по массиву. Классический пример — калькулятор: каждой операции (`+`, `-`, `*`, `/`) соответствует своя функция, а выбор происходит по индексу.
3. **Реализация полиморфизма на уровне C** (до появления виртуальных функций в C++). В C++ для этого чаще используют виртуальные функции, но указатели на функции всё ещё применяются, например, для «тонкой» настройки поведения без наследования.
4. **Хранение функций в структурах данных** — например, меню, где каждому пункту сопоставлено действие; обработчики событий; конечные автоматы.
5. **Взаимодействие с C-библиотеками**, которые ожидают функцию-обработчик (например, `qsort`, `signal`, `atexit`, `pthread_create`).

> Важно: в C++ указатели на функции — не единственный способ. Лямбды, `std::function` и шаблоны (в том числе шаблоны с параметром-функцией) часто удобнее. Но указатели на функции остаются самым «лёгким» (без накладных расходов) и совместимым с C механизмом.

## Как объявить указатель на функцию

Синтаксис объявления:

```cpp
тип_возвращаемого_значения (*имя_указателя)(список_параметров);
```

Ключевой момент — **скобки вокруг `*имя`** обязательны. Без них объявление будет прочитано иначе:

```cpp
int (*p)(double);   // указатель на функцию, принимающую double и возвращающую int
int *p(double);     // функция, принимающая double и возвращающая указатель на int — это НЕ то, что нужно
```

### Примеры

```cpp
// Функция, принимающая два int и возвращающая int
int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }

// Объявление указателя на функцию
int (*op)(int, int);

// Присваивание адреса функции (имя функции — это уже её адрес)
op = add;          // эквивалентно op = &add;
int r = op(2, 3);  // вызов через указатель — эквивалентно (*op)(2, 3);
```

### Использование `typedef` / `using` для читаемости

Объявления указателей на функции громоздки, поэтому их часто прячут за псевдонимом:

```cpp
// Старый способ (C-стиль)
typedef int (*BinOp)(int, int);

// Современный C++ способ
using BinOp = int (*)(int, int);

BinOp op = add;
```

### Передача указателя на функцию в другую функцию

```cpp
#include <iostream>

int add(int a, int b) { return a + b; }
int mul(int a, int b) { return a * b; }

// Принимаем указатель на функцию как параметр
int apply(int x, int y, int (*f)(int, int)) {
    return f(x, y);
}

int main() {
    std::cout << apply(2, 3, add) << '\n'; // 5
    std::cout << apply(2, 3, mul) << '\n'; // 6
}
```

### Массив указателей на функции (таблица диспетчеризации)

```cpp
#include <iostream>

int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }

int main() {
    // Массив указателей на функции
    int (*ops[2])(int, int) = { add, sub };

    std::cout << ops[0](5, 3) << '\n'; // 8  (add)
    std::cout << ops[1](5, 3) << '\n'; // 2  (sub)
}
```

### Возврат указателя на функцию из функции

Синтаксис становится особенно «зубодробительным»:

```cpp
// Функция возвращает указатель на функцию
int (*getOp(char c))(int, int) {
    return (c == '+') ? add : sub;
}
```

Здесь снова выручает `using`:

```cpp
using BinOp = int (*)(int, int);

BinOp getOp(char c) {
    return (c == '+') ? add : sub;
}
```

### Указатели на функции-члены класса

Для нестатических методов класса синтаксис другой — нужен указатель на член класса и объект:

```cpp
struct Widget {
    void show() const { /* ... */ }
};

void (Widget::*pm)() const = &Widget::show;

Widget w;
(w.*pm)();          // вызов через объект
Widget* pw = &w;
(pw->*pm)();        // вызов через указатель на объект
```

## Итог

| Вопрос | Ответ |
|---|---|
| Зачем нужен | Callback'и, таблицы функций, передача поведения как параметра, совместимость с C |
| Синтаксис объявления | `тип (*имя)(параметры);` |
| Чтение | «Указатель на функцию, принимающую … и возвращающую …» |
| Удобство | `using Alias = тип (*)(параметры);` |
| Современная альтернатива | `std::function`, шаблоны, лямбды (но они «тяжелее» по накладным расходам) |

Главное правило при чтении и записи таких объявлений — **правило «изнутри наружу»** и обязательные скобки вокруг имени указателя.
