# 175. Реализуйте любую сортировку

Ниже — реализация **быстрой сортировки (quicksort)** на C++ с подробными комментариями. Это один из самых популярных алгоритмов сортировки, который в среднем работает за O(n log n).

## Идея алгоритма

1. Выбирается **опорный элемент** (pivot).
2. Массив разбивается на две части: элементы меньше опорного и элементы больше опорного (разбиение Хоара или Ломуто).
3. Рекурсивно сортируются обе части.

## Реализация

```cpp
#include <iostream>
#include <vector>

// Функция разбиения (схема Хоара)
// Возвращает индекс, по которому массив разделён на две части
int partition(std::vector<int>& arr, int low, int high) {
    int pivot = arr[high];   // опорный элемент — последний
    int i = low - 1;         // индекс последнего элемента < pivot

    for (int j = low; j < high; ++j) {
        if (arr[j] < pivot) {
            ++i;
            std::swap(arr[i], arr[j]);
        }
    }
    // Ставим опорный элемент на своё место
    std::swap(arr[i + 1], arr[high]);
    return i + 1;
}

// Рекурсивная быстрая сортировка
void quickSort(std::vector<int>& arr, int low, int high) {
    if (low < high) {
        int p = partition(arr, low, high); // индекс опорного элемента
        quickSort(arr, low, p - 1);        // сортируем левую часть
        quickSort(arr, p + 1, high);       // сортируем правую часть
    }
}

// Удобная обёртка
void quickSort(std::vector<int>& arr) {
    if (!arr.empty()) {
        quickSort(arr, 0, static_cast<int>(arr.size()) - 1);
    }
}

int main() {
    std::vector<int> data = {10, 7, 8, 9, 1, 5, -3, 0, 4};

    std::cout << "До сортировки: ";
    for (int x : data) std::cout << x << ' ';
    std::cout << '\n';

    quickSort(data);

    std::cout << "После сортировки: ";
    for (int x : data) std::cout << x << ' ';
    std::cout << '\n';

    return 0;
}
```

**Вывод программы:**

```
До сортировки: 10 7 8 9 1 5 -3 0 4
После сортировки: -3 0 1 4 5 7 8 9 10
```

## Разбор

- **`partition`** — переставляет элементы так, что все значения меньше опорного оказываются слева от него, а большие — справа. Возвращает итоговую позицию опорного элемента.
- **`quickSort`** — рекурсивно применяет `partition` к левой и правой подпоследовательностям, пока размер подмассива больше 1.
- **Обёртка** без параметров `low`/`high` упрощает вызов из `main`.

## Характеристики

| Параметр | Значение |
|---|---|
| Средняя сложность | O(n log n) |
| Худшая сложность | O(n²) (например, на уже отсортированном массиве с крайним pivot) |
| Лучшая сложность | O(n log n) |
| Доп. память | O(log n) на стек рекурсии |
| Устойчивость | Неустойчивая |

## Возможные улучшения

1. **Случайный выбор опорного элемента** — защита от худшего случая O(n²):
   ```cpp
   int randomPivot = low + rand() % (high - low + 1);
   std::swap(arr[randomPivot], arr[high]);
   ```
2. **Медиана трёх** (`low`, `mid`, `high`) как pivot — снижает вероятность деградации.
3. **Гибрид с сортировкой вставками** для маленьких подмассивов (например, `< 16` элементов) — уменьшает накладные расходы рекурсии.
4. **Итеративная реализация** с явным стеком — избавляет от риска переполнения стека вызовов.
