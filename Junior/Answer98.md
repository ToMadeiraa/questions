# 98. Полиморфизм в C++

## Определение

**Полиморфизм** (от греч. *poly* — много, *morph* — форма) — это механизм объектно-ориентированного программирования, позволяющий объектам разных типов обрабатываться через единый интерфейс, при этом каждый тип реализует поведение по-своему. Проще говоря: **один интерфейс — множество реализаций**.

## Основная идея

Полиморфизм позволяет вызывать один и тот же метод для объектов разных классов, и в зависимости от фактического типа объекта будет выполнена соответствующая реализация. Это делает код более универсальным и расширяемым.

## Виды полиморфизма в C++

### 1. Статический (ранний) полиморфизм

Разрешается на этапе **компиляции**.

**a) Перегрузка функций (overloading)**

```cpp
int add(int a, int b) { return a + b; }
double add(double a, double b) { return a + b; }
```

Компилятор выбирает нужную версию по типам аргументов.

**b) Перегрузка операторов**

```cpp
class Complex {
public:
    Complex operator+(const Complex& other) const { /* ... */ }
};
```

**c) Шаблоны (templates)**

```cpp
template <typename T>
T max(T a, T b) { return (a > b) ? a : b; }
```

Одна обобщённая функция/класс, конкретизируемая для разных типов при компиляции.

### 2. Динамический (поздний) полиморфизм

Разрешается на этапе **выполнения** через механизм **виртуальных функций** и таблицу виртуальных методов (vtable).

```cpp
#include <iostream>

class Shape {
public:
    virtual void draw() const {
        std::cout << "Рисую фигуру\n";
    }
    virtual ~Shape() = default;
};

class Circle : public Shape {
public:
    void draw() const override {
        std::cout << "Рисую круг\n";
    }
};

class Square : public Shape {
public:
    void draw() const override {
        std::cout << "Рисую квадрат\n";
    }
};

int main() {
    Shape* shapes[] = { new Circle(), new Square() };
    for (Shape* s : shapes)
        s->draw();  // выбор реализации — в рантайме
}
```

Вывод:
```
Рисую круг
Рисую квадрат
```

## Ключевые условия динамического полиморфизма

1. Наличие **наследования** (базовый и производный классы).
2. Объявление метода в базовом классе как **`virtual`**.
3. **Переопределение** метода (`override`) в производном классе.
4. Вызов через **указатель или ссылку** на базовый класс.
5. **Виртуальный деструктор** в базовом классе (обязательно, если через указатель на базу удаляются объекты наследников).

## Как это работает «под капотом»

Объект класса с виртуальными функциями содержит скрытый указатель **vptr** на таблицу виртуальных функций **vtable**. При вызове виртуального метода через указатель/ссылку на базу программа обращается к vtable фактического типа объекта и вызывает нужную реализацию. За счёт этого выбор функции происходит во время выполнения.

## Полиморфизм и абстрактные классы

Часто динамический полиморфизм реализуется через **чисто виртуальные функции** (`= 0`), образующие интерфейс:

```cpp
class Animal {
public:
    virtual void speak() const = 0;  // чистый виртуальный метод
    virtual ~Animal() = default;
};
```

Класс с хотя бы одной чисто виртуальной функцией называется **абстрактным** — создать его экземпляр нельзя, но можно использовать через указатель/ссылку.

## Преимущества

- Единый интерфейс для разных типов.
- Расширяемость: новый класс подключается без изменения существующего кода, работающего с базовым интерфейсом (принцип открытости/закрытости).
- Упрощение кода — вместо `switch`/`if` по типу используется вызов виртуального метода.

## Недостатки / издержки

- Накладные расходы на vtable и vptr (небольшие).
- Запрет на вызов виртуальных функций в конструкторах/деструкторах в полиморфном смысле (в конструкторе базового класса вызывается версия базового класса).
- Возможна проблема «срезки» (**object slicing**) при передаче объекта наследника по значению — передавать нужно по ссылке или указателю.

## Итог

Полиморфизм — это способность объектов с общим интерфейсом вести себя по-разному в зависимости от их реального типа. В C++ он реализуется статически (перегрузка, шаблоны) и динамически (виртуальные функции), обеспечивая гибкость, расширяемость и повторное использование кода.
