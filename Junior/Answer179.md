# 179. Реализуйте подсчет слов в предложении.

## Постановка задачи

Требуется написать программу на C++, которая считает количество слов в предложении (строке). Словом считается последовательность непробельных символов, разделённая пробельными символами (пробел, табуляция, перевод строки и т.п.).

## Базовый вариант (через `std::cin`)

Самый простой способ: оператор `>>` для `std::string` читает очередное слово, автоматически пропуская пробельные символы. Поэтому достаточно считать слова в цикле до конца ввода.

```cpp
#include <iostream>
#include <string>

int main() {
    std::string word;
    int count = 0;

    while (std::cin >> word) {
        ++count;
    }

    std::cout << "Количество слов: " << count << std::endl;
    return 0;
}
```

**Плюсы:** коротко, автоматически обрабатывает любые пробельные символы (пробелы, `\t`, `\n`).
**Ограничение:** читает до EOF, а не до конца строки — для одного предложения нужно либо вводить одну строку и завершать ввод (`Ctrl+D`/`Ctrl+Z`), либо использовать `std::getline` (см. ниже).

## Вариант с чтением целой строки (`std::getline`)

Если предложение должно читаться одной строкой целиком (с сохранением пробелов и последующей обработкой), используют `std::getline` и ручной разбор:

```cpp
#include <iostream>
#include <string>
#include <cctype>

int countWords(const std::string& text) {
    int count = 0;
    bool inWord = false;

    for (char ch : text) {
        if (std::isspace(static_cast<unsigned char>(ch))) {
            inWord = false;          // пробел — выходим из слова
        } else if (!inWord) {
            inWord = true;           // начало нового слова
            ++count;
        }
    }
    return count;
}

int main() {
    std::string line;
    std::getline(std::cin, line);

    std::cout << "Количество слов: " << countWords(line) << std::endl;
    return 0;
}
```

### Как это работает

- Флаг `inWord` показывает, находимся ли мы внутри слова.
- При встрече пробельного символа флаг сбрасывается.
- При встрече первого непробельного символа после пробела флаг устанавливается и счётчик увеличивается ровно на 1 (так несколько пробелов подряд не дают ложных срабатываний).
- `static_cast<unsigned char>` обязателен, чтобы избежать UB при передаче отрицательных `char` в `std::isspace`.

## Вариант через `std::istringstream`

Если строка уже прочитана и нужно переиспользовать механизм `>>`:

```cpp
#include <iostream>
#include <sstream>
#include <string>

int main() {
    std::string line;
    std::getline(std::cin, line);

    std::istringstream iss(line);
    std::string word;
    int count = 0;
    while (iss >> word) ++count;

    std::cout << "Количество слов: " << count << std::endl;
    return 0;
}
```

Это компромисс: строка читается целиком (как в задании — «предложение»), а подсчёт делегируется проверенному механизму потокового извлечения.

## Вариант со `std::count` / `std::distance`

Идиоматичный в STL способ для уже готовой строки — итераторы `std::istream_iterator`:

```cpp
#include <iostream>
#include <sstream>
#include <string>
#include <iterator>
#include <algorithm>

int main() {
    std::string line;
    std::getline(std::cin, line);
    std::istringstream iss(line);

    auto n = std::distance(std::istream_iterator<std::string>(iss),
                           std::istream_iterator<std::string>());
    std::cout << "Количество слов: " << n << std::endl;
}
```

## Крайние случаи, которые стоит учесть

| Вход | Ожидаемый результат |
|---|---|
| `"   "` (только пробелы) | `0` |
| `""` (пустая строка) | `0` |
| `"  hello   world  "` | `2` |
| `"one"` | `1` |
| `"a\tb\nc"` | `3` (если считать все whitespace) |

Ручной вариант с флагом `inWord` корректно обрабатывает все эти случаи, включая несколько пробелов подряд и строки, начинающиеся/заканчивающиеся пробелами.

## Итоговая рекомендация

- Если нужен **минимальный код** — используйте `while (std::cin >> word) ++count;`.
- Если по условию предложение — это **одна строка** (её нужно прочитать целиком, возможно, с сохранением), берите `std::getline` + ручной разбор с флагом — это явно и надёжно.
- Если важен **STL-стиль** — `std::istringstream` + `std::istream_iterator`.

Во всех вариантах сложность **O(n)** по длине строки, дополнительная память — **O(1)** (кроме хранения самой строки или одного слова).
