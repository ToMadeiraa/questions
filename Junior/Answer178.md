# 178. Реализуйте перевода числа из строки в int

## Постановка задачи

Требуется написать функцию, которая принимает строку (например, `std::string` или `const char*`) и возвращает целое число типа `int`. Нужно корректно обработать:
- ведущие пробелы;
- знак `+` или `-`;
- последовательность цифр;
- переполнение (выход за диапазон `int`);
- ситуацию, когда цифр нет вовсе (некорректный ввод).

По сути, это аналог стандартной функции `std::stoi` / `atoi`, но реализованный вручную.

## Базовый алгоритм

1. Пропустить ведущие пробельные символы.
2. Определить знак числа (если первый непробельный символ — `+` или `-`, учесть его и сдвинуться).
3. Идти по строке, пока символы являются цифрами (`'0'…'9'`), накапливая результат по формуле:

   \[
   \text{result} = \text{result} \cdot 10 + (c - '0')
   \]

4. Проверять переполнение перед каждым умножением/сложением.
5. Вернуть результат с учётом знака.

## Реализация

```cpp
#include <string>
#include <cctype>
#include <stdexcept>
#include <climits>
#include <iostream>

int strToInt(const std::string& s) {
    size_t i = 0;
    const size_t n = s.size();

    // 1. Пропускаем ведущие пробелы
    while (i < n && std::isspace(static_cast<unsigned char>(s[i]))) {
        ++i;
    }

    // 2. Определяем знак
    bool negative = false;
    if (i < n && (s[i] == '+' || s[i] == '-')) {
        negative = (s[i] == '-');
        ++i;
    }

    // 3. Накапливаем цифры с проверкой переполнения
    long long result = 0;           // используем широкий тип для промежуточных вычислений
    bool hasDigits = false;

    while (i < n && std::isdigit(static_cast<unsigned char>(s[i]))) {
        hasDigits = true;
        int digit = s[i] - '0';

        // Проверка на переполнение до умножения
        if (result > (LLONG_MAX - digit) / 10) {
            throw std::out_of_range("strToInt: integer overflow");
        }

        result = result * 10 + digit;
        ++i;
    }

    if (!hasDigits) {
        throw std::invalid_argument("strToInt: no digits found");
    }

    // 4. Применяем знак и проверяем диапазон int
    if (negative) result = -result;

    if (result < INT_MIN || result > INT_MAX) {
        throw std::out_of_range("strToInt: value out of int range");
    }

    return static_cast<int>(result);
}
```

## Пояснения к ключевым моментам

### Проверка переполнения

Нельзя просто сравнивать `result` с `INT_MAX` в процессе — переполнение может произойти ещё до этого. Поэтому:
- накапливаем в `long long` (гарантированно шире `int`);
- перед умножением на 10 проверяем `result > (LLONG_MAX - digit) / 10`, чтобы само умножение не вызвало UB.

Для строгой проверки именно диапазона `int` можно проверять раньше:

```cpp
if (result > (INT_MAX - digit) / 10) {
    // но нужно аккуратно с отрицательными: INT_MIN = -2147483648
}
```

Проще накапливать в `long long`, а затем сравнивать с `INT_MIN`/`INT_MAX` — так код читается проще и остаётся корректным.

### Работа с `char`

`std::isspace` и `std::isdigit` ожидают `unsigned char` (или `EOF`). Приведение `static_cast<unsigned char>` защищает от UB при отрицательных значениях `char` (например, для кириллицы в некоторых кодировках).

### Обработка ошибок

- Нет цифр → `std::invalid_argument`.
- Выход за диапазон → `std::out_of_range`.

Это соответствует поведению `std::stoi`.

## Пример использования

```cpp
int main() {
    try {
        std::cout << strToInt("   -42abc") << '\n';   // -42 (парсим до нецифры)
        std::cout << strToInt("+123")      << '\n';   // 123
        std::cout << strToInt("2147483647")<< '\n';   // INT_MAX
        std::cout << strToInt("2147483648")<< '\n';   // исключение out_of_range
        std::cout << strToInt("abc")       << '\n';   // исключение invalid_argument
    } catch (const std::exception& e) {
        std::cerr << "Error: " << e.what() << '\n';
    }
}
```

Вывод:

```
-42
123
2147483647
Error: strToInt: value out of int range
Error: strToInt: no digits found
```

## Возможные вариации

1. **Аналог `atoi`** — без исключений, при ошибке возвращает `0`, при переполнении — «насыщение» до `INT_MAX`/`INT_MIN`.
2. **Строгий разбор** — требовать, чтобы вся строка (после пробелов) состояла только из числа, иначе ошибка.
3. **Проверка на `INT_MIN`** — отдельный случай, т.к. `-2147483648` по модулю больше `INT_MAX`. При накоплении в `long long` эта проблема снимается автоматически.
4. **Шаблонная версия** — параметризовать типом результата (`int`, `long`, `long long`) с соответствующими границами из `<limits>`.

## Итог

Ключевые идеи реализации перевода строки в `int`:
- пошаговый разбор: пробелы → знак → цифры;
- накопление результата в более широком типе;
- явная проверка переполнения до выполнения опасной операции;
- аккуратная обработка `char` через `unsigned char`;
- единообразная обработка ошибок через исключения (как в `std::stoi`).
