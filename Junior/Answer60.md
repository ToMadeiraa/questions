# 60. Разница между структурой (`struct`) и классом (`class`) в C++

## Краткий ответ

В C++ между `struct` и `class` существует **ровно два** формальных различия:

1. **Модификатор доступа по умолчанию для членов:**
   - `struct` — `public`
   - `class` — `private`

2. **Модификатор доступа по умолчанию при наследовании:**
   - `struct` — `public` (наследование)
   - `class` — `private` (наследование)

Во всём остальном `struct` и `class` **полностью эквивалентны**: обе конструкции позволяют объявлять поля, методы, конструкторы, деструкторы, перегружать операторы, наследовать, использовать виртуальные функции, шаблоны, дружественные функции и т.д.

## Подробное сравнение

### 1. Доступ по умолчанию для членов класса

```cpp
struct PointS {
    int x;   // public по умолчанию
    int y;   // public по умолчанию
};

class PointC {
    int x;   // private по умолчанию
    int y;   // private по умолчанию
};

int main() {
    PointS s;
    s.x = 1;    // OK: x публичный

    PointC c;
    // c.x = 1; // Ошибка компиляции: x приватный
}
```

Чтобы сделать члены `class` публичными, нужно явно указать `public:`:

```cpp
class PointC {
public:
    int x;
    int y;
};
```

### 2. Доступ по умолчанию при наследовании

```cpp
struct BaseS { int a; };
struct DerivedS : BaseS { };   // public-наследование по умолчанию

class BaseC { public: int a; };
class DerivedC : BaseC { };    // private-наследование по умолчанию!

int main() {
    DerivedS ds;
    ds.a = 10;   // OK: a доступен (public-наследование)

    DerivedC dc;
    // dc.a = 10; // Ошибка: private-наследование
}
```

Эквивалентные записи:

```cpp
struct D1 : public B { };  // == struct D1 : B { };
class  D2 : public B { };  // явное указание обязательно
```

### 3. Что НЕ отличается

Распространённое заблуждение — что `struct` «не умеет» методы или наследование. Это неверно:

```cpp
struct Shape {                 // struct с виртуальной функцией
    virtual double area() const = 0;
    virtual ~Shape() = default;
};

struct Circle : Shape {        // public-наследование
    double r;
    Circle(double r) : r(r) {} // конструктор
    double area() const override { return 3.14159 * r * r; }
};

struct Square : Shape {        // тоже struct
    double side;
    Square(double s) : side(s) {}
    double area() const override { return side * side; }
};
```

Всё это — корректный C++: `struct` может иметь конструкторы, деструкторы, виртуальные функции, наследование, шаблоны и перегрузку операторов.

## Практические рекомендации по стилю

Хотя формально различие минимально, в сообществе C++ (в т.ч. в рекомендациях C++ Core Guidelines) принято разделять **назначение**:

| Ситуация | Что использовать |
|---|---|
| Простая структура данных: только открытые поля, без инвариантов | `struct` |
| Тип с инкапсуляцией, инвариантами, приватными членами | `class` |
| Абстрактный интерфейс / полиморфный базовый тип | `class` |
| «Кортеж» значений, POD-тип, tag-типы | `struct` |

Пример «правильного» использования `struct`:

```cpp
struct Vec2 {
    double x = 0.0;
    double y = 0.0;
};
```

Пример «правильного» использования `class`:

```cpp
class BankAccount {
private:
    double balance_ = 0.0;   // инвариант: balance_ >= 0
public:
    void deposit(double amount) {
        if (amount <= 0) throw std::invalid_argument("amount");
        balance_ += amount;
    }
    double balance() const { return balance_; }
};
```

## Итоговая таблица

| Свойство | `struct` | `class` |
|---|---|---|
| Доступ к членам по умолчанию | `public` | `private` |
| Доступ при наследовании по умолчанию | `public` | `private` |
| Методы, конструкторы, деструкторы | ✅ | ✅ |
| Наследование, полиморфизм | ✅ | ✅ |
| Шаблоны, перегрузка операторов | ✅ | ✅ |
| Дружественные функции/классы | ✅ | ✅ |

**Вывод:** в C++ `struct` и `class` — это почти синонимы, различающиеся только доступом по умолчанию. Выбор между ними — вопрос **соглашения о стиле и семантики** (структура данных vs. инкапсулированный тип), а не возможностей языка.
