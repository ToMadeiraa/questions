# 53. Размер union в C++

## Краткий ответ

Размер `union` равен размеру **наибольшего** из его членов (с учётом требований выравнивания — alignment). При этом `union` может быть больше этого размера из-за выравнивания (padding).

## Формальное правило

Согласно стандарту C++, `sizeof(union)` должен быть достаточным, чтобы вместить **любой** из его нестатических членов. То есть:

```
sizeof(union U) >= max(sizeof(член_1), sizeof(член_2), ..., sizeof(член_N))
```

На практике компиляторы выделяют ровно столько байт, сколько нужно для самого большого члена, округлённое вверх до кратности **наибольшего требования выравнивания** среди всех членов.

## Пример 1: простой случай

```cpp
union U {
    int    a;    // 4 байта
    double b;    // 8 байт
    char   c;    // 1 байт
};

// sizeof(U) == 8  — по размеру double
```

## Пример 2: влияние выравнивания

```cpp
union U {
    char  a[9];  // 9 байт, выравнивание 1
    int   b;     // 4 байта, выравнивание 4
};

// sizeof(U) == 12, а не 9!
// Нужно 9 байт для a, но размер должен быть кратен 4 (выравнивание int),
// поэтому округляется до 12.
```

## Пример 3: член с большим выравниванием

```cpp
#include <cstddef>

union U {
    char  a[5];
    alignas(16) int b;  // требует выравнивания 16
};

// sizeof(U) == 16
// 5 байт -> округление до 16 из-за alignas(16)
```

## Важные нюансы

1. **Выравнивание важнее размера.** Даже если самый большой член занимает, скажем, 5 байт, но другой член требует выравнивания 8, итоговый размер будет кратен 8 (то есть 8).

2. **Пустой union.** В C++ `union` не может быть пустым по стандарту, но если убрать все члены (что запрещено), размер был бы не менее 1. Однако `union` без членов запрещён.

3. **Анонимный union и вложенность.** Размер считается по фактическим членам, включая вложенные структуры/unions.

4. **`union` с нетривиальными типами.** Если член — класс с нетривиальным конструктором/деструктором, размер всё равно определяется по правилам выше, но добавляются ограничения на использование (нужно явно управлять временем жизни членов).

5. **Padding в конце.** Как и у структур, у union может быть «хвостовой» padding для соблюдения выравнивания массива таких union (чтобы `sizeof` был кратен выравниванию).

## Как проверить на практике

```cpp
#include <iostream>

union U {
    char  a[9];
    int   b;
};

int main() {
    std::cout << "sizeof(U)  = " << sizeof(U)  << '\n';
    std::cout << "alignof(U) = " << alignof(U) << '\n';
}
```

Вывод (типичный):

```
sizeof(U)  = 12
alignof(U) = 4
```

## Итоговая формула

```
sizeof(union) = align_up( max(sizeof(член_i)), max(alignof(член_i)) )
```

где `align_up(x, a)` — округление `x` вверх до ближайшего кратного `a`.
