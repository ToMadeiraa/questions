# 69. Константные объекты и методы в C++

## Основное правило

Из константного объекта (`const`) можно вызывать **только константные методы** (методы с квалификатором `const`), а также:

- конструкторы и деструктор (они работают с объектом при его создании/уничтожении),
- статические методы-члены (они не имеют неявного `this` и не привязаны к конкретному объекту).

## Почему так

При вызове неконстантного метода в него неявно передаётся указатель `this` типа `T*` (неконстантный). Из константного объекта вы можете получить только `const T*`, который нельзя неявно преобразовать в `T*`. Поэтому компилятор запрещает вызов неконстантных методов у константных объектов — иначе метод мог бы изменить состояние объекта, нарушив `const`-контракт.

Константный метод получает `this` типа `const T*`, поэтому может вызываться и у константного, и у неконстантного объекта.

## Что именно можно вызвать

| Тип метода | Можно ли вызвать из `const`-объекта |
|---|---|
| Константный метод (`void f() const;`) | ✅ Да |
| Неконстантный метод (`void f();`) | ❌ Нет |
| Статический метод (`static void f();`) | ✅ Да |
| Конструктор / деструктор | ✅ (при создании/уничтожении) |
| `const`-перегрузка метода | ✅ Да (выбирается именно она) |

## Пример

```cpp
class Foo {
public:
    void nonConst() {}        // неконстантный
    void constMethod() const {} // константный
    static void staticMethod() {} // статический
};

const Foo cf;
cf.constMethod();   // OK
cf.staticMethod();  // OK
// cf.nonConst();   // ошибка компиляции

Foo f;
f.nonConst();       // OK
f.constMethod();    // OK — константный метод доступен и у неконстантного объекта
```

## Тонкости

**1. Перегрузка по `const`.** Метод можно перегрузить по константности, и для константного объекта выберется константная версия:

```cpp
class Array {
    int data[10];
public:
    int& operator[](int i)       { return data[i]; } // для неконстантного объекта
    const int& operator[](int i) const { return data[i]; } // для константного
};

const Array a;
// a[0] = 5;   // ошибка — вернулась const-ссылка
```

**2. `mutable`-поля.** Константный метод может изменять поля, помеченные `mutable` (например, кэш или счётчик вызовов), не нарушая логическую константность:

```cpp
class Cache {
    mutable int hits = 0; // можно менять даже в const-методе
public:
    int get() const { ++hits; return 42; }
};
```

**3. `const`-объект и указатели/ссылки.** Если у вас `const Foo* p`, через него тоже доступны только константные методы (`p->constMethod()`).

**4. Не путать с `const`-возвращаемым значением.** Квалификатор `const` после списка параметров (`void f() const`) делает метод константным; `const` перед типом возврата (`const int f()`) к этому отношения не имеет.

## Итог

Из константного объекта вызываются: **константные методы**, **статические методы**, а также конструкторы/деструктор. Неконстантные методы недоступны, если только они не помечены `mutable`-полями (сам метод всё равно должен быть `const`) или не снят `const` через `const_cast` (что обычно свидетельствует о плохом дизайне).
