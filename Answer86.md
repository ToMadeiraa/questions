## 86. Что делает ключевое слово `auto` в C++?

Ключевое слово `auto` в современном C++ (начиная с C++11) — это **спецификатор типа-заполнителя** (placeholder type specifier). Его основное назначение — **поручить компилятору вывести (deduce) точный тип переменной или возвращаемого значения функции на основе контекста**, вместо того чтобы программист указывал его вручную.

Исторически (до C++11) `auto` означал «автоматическую продолжительность хранения» (automatic storage duration), но эта семантика была упразднена, и в современном C++ `auto` используется исключительно для вывода типов .

---

### 1. Вывод типа переменной (основное использование)

При объявлении переменной с `auto` тип выводится из **выражения инициализации** с использованием правил вывода аргументов шаблона (template argument deduction) .

```cpp
auto x = 42;          // x имеет тип int
auto y = 3.14;        // y имеет тип double
auto z = x + y;       // z имеет тип double (обычные арифметические преобразования)

std::vector<int> v = {1, 2, 3};
auto it = v.begin();  // it имеет тип std::vector<int>::iterator — удобно!
```

**Важные нюансы вывода:**
- `auto` **отбрасывает** ссылки и cv-квалификаторы (const/volatile) верхнего уровня, если они не указаны явно .
- Модификаторы можно комбинировать: `const auto&`, `auto*`, `auto&&` и т.д.
- `auto` **нельзя** использовать без инициализатора: `auto x;` — ошибка компиляции .

---

### 2. `auto` и возвращаемый тип функции

Здесь есть два принципиально разных механизма, которые часто путают.

#### 2.1. Trailing return type (C++11)

В C++11 `auto` в позиции возвращаемого типа **сам по себе ничего не выводит**. Он лишь служит синтаксическим заполнителем, который позволяет указать настоящий возвращаемый тип **после** списка параметров с помощью `->` .

```cpp
// C++11: возвращаемый тип указывается справа
auto add(int a, int b) -> int {
    return a + b;
}

// Часто используется с decltype, когда тип зависит от параметров
template<typename T, typename U>
auto add(T t, U u) -> decltype(t + u) {
    return t + u;
}
```

Этот синтаксис особенно полезен в шаблонах, где возвращаемый тип зависит от типов аргументов, и в случаях, когда тип находится в области видимости класса.

#### 2.2. Вывод возвращаемого типа из тела функции (C++14)

Начиная с C++14, если после `auto` **нет** `->`, компилятор выводит возвращаемый тип из выражений в `return` внутри тела функции .

```cpp
// C++14 и новее: тип выводится из return
auto multiply(int a, double b) {
    return a * b;  // возвращаемый тип выводится как double
}

auto make_vector() {
    return std::vector<int>{1, 2, 3};  // возвращаемый тип: std::vector<int>
}
```

**Ограничение:** в функции может быть несколько `return`, но все они должны выводить **один и тот же** тип. Если типы различаются, компилятор выдаст ошибку (кроме случаев, когда тип может быть однозначно приведён, но это работает не всегда так, как ожидается).

### 3. `auto` для аргументов функции

Этот вопрос требует уточнения, потому что ситуация менялась между стандартами.

#### 3.1. До C++20: `auto` в параметрах обычных функций **запрещён**

В C++11/14/17 объявление вида `void f(auto x)` в обычной (не лямбда) функции **не допускается** стандартом. MSVC, GCC и Clang в строгом режиме выдают ошибку .

**Исключение — лямбда-выражения:** с C++14 параметры обобщённых лямбд могут быть объявлены с `auto`, что фактически превращает лямбду в шаблон с оператором вызова:

```cpp
// C++14: обобщённая лямбда
auto lambda = [](auto a, auto b) { return a + b; };
lambda(1, 2);     // инстанцируется с int, int
lambda(1.0, 2.0); // инстанцируется с double, double
```

#### 3.2. C++20: сокращённые шаблоны функций (abbreviated function templates)

C++20 ввёл концепцию **сокращённых шаблонов функций**. Запись `auto` в параметре обычной функции теперь легальна и означает, что функция является шаблоном, а тип каждого параметра с `auto` выводится при вызове .

```cpp
// C++20: это шаблон функции, эквивалентный template<typename T> void f(T x)
void f(auto x) {
    // ...
}

f(42);    // T = int
f(3.14);  // T = double
```

С концепциями C++20 это можно ограничивать:

```cpp
void print_number(std::integral auto n) { /* ... */ } // только целочисленные типы
```

### Краткая сводная таблица

| Контекст | Поведение `auto` | Стандарт |
|---|---|---|
| Переменная с инициализатором | Выводит тип из инициализатора | C++11 |
| Возвращаемый тип с `->` | Синтаксический заполнитель для trailing return type; сам не выводит | C++11 |
| Возвращаемый тип без `->` | Выводит тип из `return` в теле | C++14 |
| Параметр лямбды | Обобщённая лямбда (шаблонный `operator()`) | C++14 |
| Параметр обычной функции | **Запрещено** (кроме C++20) | до C++20 |
| Параметр обычной функции | Сокращённый шаблон функции | C++20 |

Таким образом, `auto` — это не «универсальная замена любого типа», а инструмент, который **перекладывает вывод типа на компилятор** там, где это безопасно и повышает читаемость/надёжность кода (особенно при работе с итераторами, лямбдами и шаблонами).
