# 182. Удалите из unordered_map элементы, которые делятся на 2 и выведите ключи этих элементов.

## Постановка задачи

Дан `std::unordered_map`. Требуется:

1. Найти элементы, **ключи** которых делятся на 2 (то есть чётные ключи).
2. Вывести эти ключи (например, в консоль).
3. Удалить соответствующие элементы из контейнера.

Важно: под «элементы, которые делятся на 2» в контексте `unordered_map` обычно понимаются элементы, **ключ** которых делится на 2, поскольку именно ключ идентифицирует элемент. Ниже разобран именно этот вариант, но в конце показано, как адаптировать решение под значение.

## Ключевой момент: корректное удаление при обходе

При удалении элементов во время итерации по контейнеру нельзя просто делать `erase(it)` и затем `++it` — итератор становится невалидным. Правильный приём в C++11 и новее:

```cpp
it = map.erase(it);
```

Метод `erase` возвращает итератор на следующий элемент, поэтому цикл `while` с таким присваиванием безопасен.

Также важно: **нельзя** удалять элементы по значению через `erase(key)` внутри range-based for по самому контейнеру — это инвалидирует итераторы.

## Пример решения

```cpp
#include <iostream>
#include <unordered_map>

int main() {
    std::unordered_map<int, std::string> m = {
        {1, "one"}, {2, "two"}, {3, "three"},
        {4, "four"}, {5, "five"}, {6, "six"}
    };

    std::cout << "Удаляемые ключи (делятся на 2): ";
    for (auto it = m.begin(); it != m.end(); ) {
        if (it->first % 2 == 0) {
            std::cout << it->first << " ";
            it = m.erase(it);   // erase возвращает следующий итератор
        } else {
            ++it;
        }
    }
    std::cout << "\n";

    std::cout << "Оставшиеся элементы:\n";
    for (const auto& [key, value] : m) {
        std::cout << key << " -> " << value << "\n";
    }
    return 0;
}
```

Вывод:

```
Удаляемые ключи (делятся на 2): 6 4 2 
Оставшиеся элементы:
5 -> five
3 -> three
1 -> one
```

Порядок вывода ключей может отличаться — `unordered_map` не гарантирует порядок обхода.

## Альтернатива: удаление по значению

Если под «элементами, которые делятся на 2» понимаются **значения** (например, `map<int,int>`), логика та же, только проверяется `it->second`:

```cpp
for (auto it = m.begin(); it != m.end(); ) {
    if (it->second % 2 == 0) {
        std::cout << it->first << " ";   // выводим ключ удаляемого элемента
        it = m.erase(it);
    } else {
        ++it;
    }
}
```

Здесь по-прежнему выводится **ключ**, но условие проверяет значение — это соответствует буквальной формулировке «удалите элементы, которые делятся на 2, и выведите ключи этих элементов».

## Альтернатива: `std::erase_if` (C++20)

В C++20 задача решается короче, но с оговоркой — нужно сначала собрать ключи, так как `erase_if` не даёт доступа к удаляемым элементам:

```cpp
#include <unordered_map>
#include <vector>
#include <iostream>

std::vector<int> keys;
for (const auto& [k, v] : m)
    if (k % 2 == 0) keys.push_back(k);

for (int k : keys) std::cout << k << " ";

std::erase_if(m, [](const auto& p) { return p.first % 2 == 0; });
```

## Типичные ошибки

| Ошибка | Последствие |
|---|---|
| `for (auto it = m.begin(); it != m.end(); ++it) if (...) m.erase(it);` | Инвалидация итератора, UB |
| `for (auto& p : m) if (...) m.erase(p.first);` | Инвалидация итераторов диапазона, UB |
| Забыть про `it = m.erase(it)` без `++it` в ветке удаления | Пропуск элементов или зацикливание |
| Вывод ключа после `erase` через сохранённый итератор | Обращение к удалённому элементу |

## Итог

Правильный шаблон удаления из `unordered_map` при обходе:

```cpp
for (auto it = m.begin(); it != m.end(); ) {
    if (/* условие на *it */) {
        /* вывод it->first */;
        it = m.erase(it);
    } else {
        ++it;
    }
}
```

Он корректен для любого ассоциативного контейнера STL и не требует копирования ключей во вспомогательный контейнер.
