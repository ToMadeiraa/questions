# 59. Как соотносится класс и объект?

## Краткий ответ

**Класс** — это шаблон (описание), а **объект** — это конкретный экземпляр, созданный по этому шаблону. Класс описывает *что* будет у объекта (поля и методы), а объект — это *реальная сущность* в памяти с конкретными значениями этих полей.

## Подробное объяснение

### Класс — это тип, объект — это значение

Класс в C++ — это пользовательский тип данных, по аналогии со встроенными типами:

```cpp
int a = 42;      // int — тип, a — переменная (значение)

class Point {    // Point — класс (тип)
    int x, y;
};

Point p;         // p — объект (переменная, экземпляр класса)
```

Здесь `int` соотносится с `a` так же, как `Point` соотносится с `p`.

### Класс задаёт структуру и поведение

Класс определяет:
- **поля** (данные) — какие характеристики есть у объекта;
- **методы** (функции) — какие действия объект умеет выполнять;
- **модификаторы доступа** — что видно снаружи (`public`, `private`, `protected`).

```cpp
class Point {
private:
    int x, y;            // состояние объекта
public:
    void moveTo(int nx, int ny) { x = nx; y = ny; }  // поведение
    int getX() const { return x; }
};
```

Объект `p` получает **собственную копию** всех нестатических полей и доступ к методам класса.

### Один класс — много объектов

Из одного класса можно создать сколько угодно независимых объектов, каждый со своим состоянием:

```cpp
Point a, b, c;      // три разных объекта одного класса
a.moveTo(1, 2);
b.moveTo(10, 20);   // состояние a и b независимо
```

Класс существует только во время компиляции (описание), объекты же занимают память во время выполнения программы.

### Объекты — это экземпляры класса

Термины «объект» и «экземпляр класса» (*instance*) в C++ синонимичны. Создание объекта называется **созданием экземпляра** (*instantiation*).

При создании объекта вызывается **конструктор** — специальный метод, который инициализирует его поля:

```cpp
class Point {
public:
    Point(int x, int y) : x(x), y(y) {}   // конструктор
private:
    int x, y;
};

Point p(3, 4);   // объект p создан, конструктор вызван
```

При уничтожении объекта вызывается **деструктор**.

## Аналогии для запоминания

- **Класс = чертёж, объект = построенный по нему дом.** По одному чертежу можно построить много разных домов.
- **Класс = тип, объект = переменная.** Как `int` и конкретная переменная типа `int`.
- **Класс = формочка для печенья, объекты = испечённые печенья.**

## Что важно различать

| | Класс | Объект |
|---|---|---|
| Что это | Тип (шаблон, описание) | Экземпляр типа (значение) |
| Когда существует | На этапе компиляции | Во время выполнения |
| Занимает ли память сам по себе | Нет (только описание) | Да (есть в памяти) |
| Состояние | Описывает поля | Имеет конкретные значения полей |
| Сколько их | Один класс | Много объектов |

## Дополнительно: статические члены

Стоит отметить исключение — **статические поля** принадлежат не объекту, а самому классу и общие для всех объектов:

```cpp
class Counter {
public:
    static int count;   // одно поле на весь класс, а не на объект
};
int Counter::count = 0;
```

Это не меняет главного соотношения: класс — описание, объект — конкретный экземпляр, но показывает, что не все данные привязаны к отдельному объекту.

## Итоговая формулировка

Класс — это абстрактный тип, описывающий набор данных (полей) и операций (методов). Объект — это конкретный экземпляр этого класса, существующий в памяти и обладающий собственным состоянием. Объекты создаются по шаблону класса, поэтому один класс может порождать произвольное количество объектов, независимых друг от друга.
