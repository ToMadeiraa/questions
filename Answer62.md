# 62. Стандартные (неявно объявляемые) методы класса в C++

В C++ компилятор автоматически объявляет (генерирует) для класса ряд специальных функций-членов, если программист не объявил их явно. Эти методы называют **специальными функциями-членами** (special member functions). Традиционно к «стандартным» методам класса относят следующие шесть:

## 1. Конструктор по умолчанию

```cpp
T();  // конструктор без параметров
```

- Генерируется компилятором, если в классе **не объявлен ни один** конструктор.
- Инициализирует члены класса: члены классовых типов — своими конструкторами по умолчанию, встроенные типы (int, double и т. п.) остаются **неинициализированными**.
- Если объявлен хотя бы один конструктор с параметрами, конструктор по умолчанию автоматически **не создаётся** (можно вернуть его словом `= default`).

## 2. Конструктор копирования

```cpp
T(const T& other);
```

- Вызывается при инициализации объекта другим объектом того же типа (в том числе при передаче в функцию по значению и возврате по значению).
- Неявно генерируемый конструктор выполняет **почленное (поверхностное) копирование** — копирует каждый член.
- Для классов с указателями это опасно: копируется лишь значение указателя, а не сам ресурс (проблема «двойного удаления»).

## 3. Конструктор перемещения (C++11)

```cpp
T(T&& other);
```

- Вызывается при инициализации из rvalue (временного объекта, результата `std::move`).
- Неявно генерируется, если не объявлены конструктор копирования, оператор копирующего присваивания, оператор перемещающего присваивания или деструктор.
- «Забирает» ресурсы у источника, оставляя его в корректном, но неопределённом состоянии.

## 4. Оператор копирующего присваивания

```cpp
T& operator=(const T& other);
```

- Вызывается при присваивании уже существующему объекту: `a = b;`
- Неявная версия выполняет почленное присваивание.
- Должен корректно обрабатывать самоприсваивание (`a = a;`).

## 5. Оператор перемещающего присваивания (C++11)

```cpp
T& operator=(T&& other);
```

- Вызывается при присваивании из rvalue: `a = std::move(b);`
- Неявно генерируется при тех же условиях, что и конструктор перемещения.

## 6. Деструктор

```cpp
~T();
```

- Вызывается при разрушении объекта (выход из области видимости, `delete`).
- Неявный деструктор вызывает деструкторы членов класса и базовых классов.
- **Не освобождает** динамически выделенную память, на которую указывают члены-указатели, — для этого нужен явный деструктор.

## Сводная таблица

| Метод | Сигнатура | Когда генерируется неявно |
|---|---|---|
| Конструктор по умолчанию | `T()` | Не объявлен ни один конструктор |
| Конструктор копирования | `T(const T&)` | Не объявлен явно; не запрещён перемещающими операциями |
| Конструктор перемещения | `T(T&&)` | Не объявлены копирующие операции, перемещающее присваивание, деструктор |
| Оператор копирующего присваивания | `T& operator=(const T&)` | Не объявлен явно; не запрещён перемещающими операциями |
| Оператор перемещающего присваивания | `T& operator=(T&&)` | Те же условия, что для конструктора перемещения |
| Деструктор | `~T()` | Не объявлен явно |

## Правило пяти (Rule of Five) и правило нуля

- **Правило трёх** (C++98): если классу нужен собственный деструктор, конструктор копирования или оператор присваивания — скорее всего, нужны все три (класс управляет ресурсом).
- **Правило пяти** (C++11): то же плюс конструктор и оператор перемещающего присваивания.
- **Правило нуля**: лучше вообще не объявлять эти функции явно, а поручить управление ресурсами стандартным контейнерам и умным указателям (`std::string`, `std::vector`, `std::unique_ptr`, `std::shared_ptr`) — тогда корректные версии сгенерируются автоматически.

## Важные нюансы

1. **`= default` и `= delete`** позволяют явно указать компилятору сгенерировать метод по умолчанию или запретить его:
   ```cpp
   class NonCopyable {
   public:
       NonCopyable(const NonCopyable&) = delete;
       NonCopyable& operator=(const NonCopyable&) = delete;
   };
   ```
2. Объявление **перемещающих** операций **удаляет** неявные копирующие (и наоборот).
3. Объявление **деструктора** подавляет неявную генерацию перемещающих операций (но копирующие остаются, хотя их использование считается устаревшим).
4. Неявно генерируемые методы являются **public** и **inline**.
5. Помимо перечисленных шести, компилятор может неявно генерировать и другие операторы (например, `operator&`), но к «стандартным специальным» относят именно эти.

## Итог

Стандартными (неявно объявляемыми компилятором) методами класса в C++ являются: **конструктор по умолчанию, конструктор копирования, конструктор перемещения, оператор копирующего присваивания, оператор перемещающего присваивания и деструктор**. Понимание условий их генерации и правил взаимодействия (правило трёх/пяти/нуля) критично для корректного управления ресурсами и избежания утечек памяти и двойного освобождения.
