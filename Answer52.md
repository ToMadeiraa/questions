# 52. Что такое union?

## Определение

**`union`** (объединение) — это составной тип данных в C++, который позволяет нескольким переменным разных типов **разделять одну и ту же область памяти**. В каждый момент времени в объединении хранится значение только одного из его членов.

По сути, `union` — это способ «наложить» несколько типов на один и тот же блок памяти, размер которого равен размеру самого большого члена.

## Синтаксис

```cpp
union UnionName {
    тип1 имя1;
    тип2 имя2;
    // ...
};
```

Пример:

```cpp
union Value {
    int    i;
    float  f;
    char   c;
};
```

## Ключевые свойства

1. **Общая память.** Все члены `union` начинаются с одного и того же адреса. Размер объединения равен размеру его **наибольшего** члена (с учётом выравнивания).

```cpp
union Value v;
std::cout << sizeof(Value) << "\n"; // например, 4 (размер int/float)
```

2. **Одновременно активен только один член.** Запись в один член «затирает» значение другого. Читать нужно именно тот член, который был записан последним, иначе поведение не определено (за некоторыми исключениями, см. ниже).

```cpp
Value v;
v.i = 42;        // активен i
std::cout << v.i; // OK: 42
v.f = 3.14f;     // теперь активен f, значение i затёрто
std::cout << v.f; // OK: 3.14
std::cout << v.i; // неопределённое поведение (в общем случае)
```

3. **Все члены публичны по умолчанию** (в отличие от `class`/`struct`, где доступ по умолчанию — `private`/`public` соответственно; у `union` — `public`).

4. **Может содержать функции-члены**, конструкторы, деструкторы (но не виртуальные функции и не базовые классы).

```cpp
union Value {
    int i;
    float f;
    Value() : i(0) {}     // конструктор разрешён
    void print() const {} // метод разрешён
};
```

## Ограничения

- Нельзя содержать **статические** члены данных.
- Нельзя содержать члены со **ссылками** (`int&`).
- Нельзя наследоваться от `union` и иметь виртуальные функции.
- Член с нетривиальным конструктором/деструктором (например, `std::string`) требует **явного** определения конструктора и деструктора объединения — в противном случае они удаляются (см. «неограниченные объединения»).

## Применение

### 1. Экономия памяти

Когда известно, что в объекте в каждый момент хранится значение только одного из нескольких типов:

```cpp
union Number {
    int    asInt;
    double asDouble;
};
```

### 2. Низкоуровневая работа с представлением данных (type punning)

Просмотр одного и того же набора байт как разных типов:

```cpp
union FloatBits {
    float f;
    unsigned int bits;
};

FloatBits fb;
fb.f = 1.0f;
std::cout << std::hex << fb.bits; // побитовое представление float
```

> ⚠️ В C++ чтение «неактивного» члена в общем случае — **неопределённое поведение**. Легальный type punning в стандартном C++ обычно делают через `std::memcpy` или `std::bit_cast` (C++20). Однако чтение общего начального последовательного фрагмента нескольких `struct`-членов разрешено (common initial sequence).

### 3. Тегированные объединения (tagged union / discriminated union)

Классический паттерн: `union` + поле-«тег», указывающее, какой член активен.

```cpp
enum class Kind { Int, Float };

struct Variant {
    Kind kind;
    union {
        int   i;
        float f;
    };
};

void print(const Variant& v) {
    switch (v.kind) {
        case Kind::Int:   std::cout << v.i; break;
        case Kind::Float: std::cout << v.f; break;
    }
}
```

Именно так устроен `std::variant` из C++17 — безопасная альтернатива «ручному» тегированному объединению.

## union vs struct

| Свойство | `struct` | `union` |
|---|---|---|
| Память | каждый член — своя область | все члены делят одну область |
| Размер | сумма размеров членов (+выравнивание) | размер наибольшего члена |
| Одновременная активность | все члены | только один |
| Доступ по умолчанию | `public` | `public` |

## Анонимные объединения

`union` без имени, члены которого доступны напрямую в охватывающей области видимости:

```cpp
struct Point {
    union {          // анонимное объединение
        struct { float x, y; };
        float coords[2];
    };
};

Point p;
p.x = 1.0f;          // доступ через имя члена
p.coords[1] = 2.0f;  // те же байты, что и p.y
```

## Итог

`union` — это механизм **разделения памяти** между членами разных типов, где в любой момент активен только один член. Он применяется для экономии памяти, низкоуровневых манипуляций с битами и построения тегированных объединений. При работе с `union` программист сам отвечает за корректность активного члена — за это в современном C++ предпочитают безопасный `std::variant`.
