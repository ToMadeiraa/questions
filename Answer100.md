# 100. Типы наследования в C++

В C++ существует **три типа наследования**, которые определяют уровень доступа к унаследованным членам базового класса в производном классе:

## 1. Публичное наследование (`public`)

Самый распространённый тип. Открытые члены базового класса остаются открытыми, защищённые — защищёнными, а закрытые — недоступны (но наследуются).

```cpp
class Base {
public:    int a;
protected:  int b;
private:    int c;
};

class Derived : public Base {
    // a -> public
    // b -> protected
    // c -> недоступен
};
```

**Смысл:** отношение «является» (is-a). Объект `Derived` может использоваться везде, где ожидается `Base` (принцип подстановки Лисков).

## 2. Защищённое наследование (`protected`)

Открытые и защищённые члены базового класса становятся защищёнными в производном классе.

```cpp
class Derived : protected Base {
    // a -> protected
    // b -> protected
    // c -> недоступен
};
```

**Смысл:** отношение «реализован с помощью» (is-implemented-in-terms-of). Внешний код не видит, что `Derived` наследует `Base`.

## 3. Закрытое наследование (`private`)

Все члены базового класса (public и protected) становятся закрытыми в производном классе.

```cpp
class Derived : private Base {
    // a -> private
    // b -> private
    // c -> недоступен
};
```

**Смысл:** чистая реализация на основе базового класса. Наследование видно только внутри `Derived`. По умолчанию для `class` используется именно `private`, а для `struct` — `public`.

## Сводная таблица

| Член базового класса | `public` наследование | `protected` наследование | `private` наследование |
|----------------------|-----------------------|--------------------------|------------------------|
| `public`             | `public`              | `protected`              | `private`              |
| `protected`          | `protected`           | `protected`              | `private`              |
| `private`            | недоступен            | недоступен               | недоступен             |

## Важные замечания

- **Виртуальное наследование** (`virtual`) — это не отдельный тип доступа, а механизм, решающий проблему «ромба» (diamond problem) при множественном наследовании. Оно гарантирует, что общий базовый класс будет представлен в иерархии только одним экземпляром.
- **Множественное наследование** — возможность наследовать от нескольких базовых классов одновременно; тип доступа указывается для каждого базового класса отдельно.
- При `private`/`protected` наследовании можно вернуть отдельным членам исходный уровень доступа с помощью `using`:

```cpp
class Derived : private Base {
public:
    using Base::a; // снова делает a открытым
};
```

- **Нельзя** понизить уровень доступа закрытых членов — они недоступны в любом случае, независимо от типа наследования.
- Приведение `Derived*` к `Base*` (upcast) разрешено только при **публичном** наследовании; при `private`/`protected` — запрещено (кроме случаев внутри класса/друзей).
