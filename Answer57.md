# 57. Встроенные типы в C++

В C++ встроенные (фундаментальные) типы делятся на несколько категорий. Стандарт гарантирует лишь минимальные размеры и диапазоны, а точные размеры зависят от платформы и компилятора.

## 1. Целочисленные типы

| Тип | Минимальный размер | Примечание |
|-----|-------------------|------------|
| `bool` | — | Принимает `true`/`false` (обычно 1 байт) |
| `char` | 1 байт | Символьный тип, знаковость зависит от платформы |
| `signed char` | 1 байт | Гарантированно знаковый |
| `unsigned char` | 1 байт | Гарантированно беззнаковый |
| `short` / `short int` | ≥ 16 бит | — |
| `unsigned short` | ≥ 16 бит | — |
| `int` | ≥ 16 бит | Обычно 32 бита |
| `unsigned int` | ≥ 16 бит | — |
| `long` / `long int` | ≥ 32 бит | — |
| `unsigned long` | ≥ 32 бит | — |
| `long long` / `long long int` | ≥ 64 бит | Появился в C++11 |
| `unsigned long long` | ≥ 64 бит | — |

Каждый из типов `short`, `int`, `long`, `long long` может быть дополнен спецификаторами `signed` и `unsigned`.

## 2. Символьные типы

- `char` — обычный символ (может быть знаковым или беззнаковым, определяется реализацией);
- `wchar_t` — «широкий» символ (размер зависит от платформы, обычно 2 или 4 байта);
- `char8_t` — для UTF-8 (C++20);
- `char16_t` — для UTF-16 (C++11);
- `char32_t` — для UTF-32 (C++11).

## 3. Типы с плавающей точкой

| Тип | Примечание |
|-----|------------|
| `float` | Одинарная точность (обычно 32 бита) |
| `double` | Двойная точность (обычно 64 бита) |
| `long double` | Расширенная точность (размер зависит от платформы: 80, 96 или 128 бит) |

## 4. Специальные типы

- `void` — «пустой» тип, используется для функций без возвращаемого значения и для указателей на «что угодно»;
- `std::nullptr_t` — тип литерала `nullptr` (C++11);
- `std::byte` — тип для работы с «сырой» памятью (C++17).

## 5. Модификаторы типов

К базовым типам могут применяться модификаторы:

- `signed` / `unsigned` — знаковость целых;
- `short` / `long` — «длина» целых;
- `const` — неизменяемое значение;
- `volatile` — значение может меняться «извне» (оптимизации запрещены).

## Пример

```cpp
#include <iostream>

int main() {
    bool        b  = true;
    char        c  = 'A';
    short       s  = 42;
    int         i  = 1'000'000;
    long long   ll = 9'000'000'000LL;
    unsigned    u  = 42u;
    float       f  = 3.14f;
    double      d  = 3.14159;
    long double ld = 3.1415926535L;

    std::cout << sizeof(int) << " " << sizeof(double) << "\n";
    return 0;
}
```

## Важные замечания

1. **Размеры не фиксированы стандартом** — для переносимого кода, где важна точная разрядность, используйте типы из `<cstdint>`: `int8_t`, `uint16_t`, `int32_t`, `uint64_t` и т. п.
2. **Порядок размеров** гарантирован: `sizeof(char) <= sizeof(short) <= sizeof(int) <= sizeof(long) <= sizeof(long long)` и `sizeof(char) == 1`.
3. **Знаковость `char`** зависит от реализации: на x86 обычно `signed char`, на ARM — часто `unsigned char`.
4. **Переполнение знаковых целых** — неопределённое поведение (UB), а беззнаковых — корректное «заворачивание» по модулю 2^N.
