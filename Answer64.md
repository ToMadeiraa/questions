# 64. Сколько памяти занимает объект пустого класса `class A {};`?

## Краткий ответ

**1 байт** — именно столько занимает объект пустого класса в C++ (на большинстве платформ и компиляторов).

```cpp
#include <iostream>

class A {};

int main() {
    std::cout << sizeof(A) << std::endl;  // выведет 1
}
```

## Почему именно 1 байт, а не 0?

Стандарт C++ требует, чтобы **любые два различных объекта имели различные адреса в памяти**. Если бы размер пустого класса был равен 0, то при создании массива таких объектов все элементы располагались бы по одному и тому же адресу, что нарушило бы это правило.

Поэтому компилятор обязан выделить объекту хотя бы **минимально адресуемую единицу памяти — 1 байт**.

```cpp
A arr[10];
// &arr[0] != &arr[1] != &arr[2] ... — адреса должны различаться
```

## Важные нюансы

### 1. `sizeof(A) == 1`, но это не значит, что класс "содержит" байт

Байт — это «заполнитель» (padding), а не реальные данные. Компилятор просто резервирует адрес.

### 2. Пустой базовый класс и оптимизация EBO (Empty Base Optimization)

Если пустой класс используется как **базовый**, компилятор может применить оптимизацию и **не добавлять** его размер к производному классу:

```cpp
class Empty {};

class Derived : public Empty {
    int x;
};

// sizeof(Derived) == 4 (а не 5!), благодаря EBO
```

Это разрешено стандартом именно для базовых подобъектов (но не для полей-членов).

### 3. Пустой класс с виртуальными функциями — уже не пустой

Если добавить виртуальную функцию, появится указатель на таблицу виртуальных функций (vptr):

```cpp
class B {
    virtual void f();
};

// sizeof(B) == 8 на 64-битной платформе (размер указателя)
```

### 4. Пустой класс с несколькими пустыми базами

Из-за требования уникальности адресов подобъектов размер может вырасти:

```cpp
class E1 {};
class E2 {};

class D : public E1, public E2 {};
// sizeof(D) может быть 2 (EBO не всегда применима к нескольким базам
// одного типа/при отсутствии оптимизации)
```

## Итоговая таблица

| Класс | `sizeof` (типично) |
|---|---|
| `class A {};` | **1** |
| `class A { int x; };` | 4 |
| `class A { virtual void f(); };` | 8 (64-bit) |
| `class Empty {}; class D : Empty { int x; };` | 4 (EBO) |

## Формулировка для ответа

> Объект пустого класса занимает **1 байт**. Это связано с требованием стандарта C++, согласно которому два разных объекта должны иметь разные адреса в памяти. Если бы размер был равен 0, то, например, элементы массива пустых объектов совпадали бы по адресу, что недопустимо. Поэтому компилятор резервирует минимальную адресуемую единицу — 1 байт. При этом для пустого базового класса может применяться оптимизация Empty Base Optimization (EBO), позволяющая не увеличивать размер производного класса.
