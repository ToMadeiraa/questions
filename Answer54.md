# 54. Что такое класс?

## Определение

**Класс** — это пользовательский тип данных в C++, который описывает структуру объекта: набор данных (полей/членов-данных) и операций над ними (методов/функций-членов). Класс выступает «чертежом» (шаблоном), по которому создаются конкретные объекты — экземпляры класса.

Иными словами, класс объединяет **состояние** (данные) и **поведение** (функции) в единую сущность, что является основой объектно-ориентированного программирования (ООП).

## Ключевая идея: класс vs объект

- **Класс** — описание, тип (например, «автомобиль» как понятие).
- **Объект** — конкретный экземпляр класса, занимающий память (например, «мой автомобиль с номером А123БВ»).

```cpp
class Car {          // это класс — описание
    // ...
};

Car myCar;           // это объект — экземпляр класса
```

## Синтаксис объявления

```cpp
class ИмяКласса {
public:              // спецификатор доступа
    // члены-данные (поля)
    // функции-члены (методы)
private:
    // ...
};                   // ОБЯЗАТЕЛЬНА точка с запятой после закрывающей скобки
```

### Пример

```cpp
#include <iostream>
#include <string>

class Person {
private:
    std::string name;   // член-данное (поле)
    int age;            // член-данное (поле)

public:
    // Конструктор
    Person(const std::string& n, int a) : name(n), age(a) {}

    // Метод (функция-член)
    void introduce() const {
        std::cout << "Меня зовут " << name
                  << ", мне " << age << " лет\n";
    }

    // Метод-геттер
    int getAge() const { return age; }
};

int main() {
    Person p("Иван", 25);   // создание объекта
    p.introduce();          // вызов метода
    return 0;
}
```

## Состав класса

Класс может содержать:

1. **Члены-данные (поля)** — переменные, хранящие состояние объекта.
2. **Функции-члены (методы)** — функции, определяющие поведение.
3. **Конструкторы** — специальные методы инициализации объекта.
4. **Деструктор** — метод, вызываемый при уничтожении объекта (освобождение ресурсов).
5. **Специальные функции**: конструктор копирования, оператор присваивания, перемещающие конструкторы.
6. **Вложенные типы** (другие классы, перечисления, `using`-псевдонимы).
7. **Статические члены** — общие для всех объектов класса.
8. **Дружественные функции/классы** (`friend`).

## Инкапсуляция и спецификаторы доступа

Одна из трёх ключевых идей ООП, реализуемых классом, — **инкапсуляция**: сокрытие внутреннего устройства и предоставление контролируемого интерфейса.

| Спецификатор | Доступ |
|--------------|--------|
| `public`     | Доступен всем |
| `private`    | Доступен только членам класса и друзьям (`friend`) |
| `protected`  | Доступен членам класса, друзьям и производным классам |

**Важно:** в классе (`class`) по умолчанию доступ — `private`, а в структуре (`struct`) — `public`. В остальном `class` и `struct` в C++ практически идентичны.

## Класс и память

- Размер класса определяется суммой размеров его нестатических полей (с учётом выравнивания).
- Пустой класс в C++ имеет размер **не менее 1 байта** (чтобы разные объекты имели разные адреса).
- Методы не занимают места в каждом объекте — они общие для всех экземпляров.

## Основные принципы ООП, связанные с классом

1. **Инкапсуляция** — объединение данных и методов + сокрытие деталей реализации.
2. **Наследование** — возможность создавать производные классы на основе базового.
3. **Полиморфизм** — возможность работать с объектами разных классов через общий интерфейс (виртуальные функции).

## Краткий итог

**Класс в C++** — это определяемый программистом тип, который:
- объединяет данные и функции, работающие с этими данными;
- поддерживает инкапсуляцию через спецификаторы доступа;
- служит основой для создания объектов, наследования и полиморфизма;
- является фундаментальным понятием объектно-ориентированного программирования.
